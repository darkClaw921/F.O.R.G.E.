# pickRoot

Корень, подставляемый при открытии диалога переноса (js/tracker/to-todo.js). Правило двухступенчатое: (1) запомненный прошлый выбор из localStorage forge.tracker.push.root, если он ещё есть среди проектов — это критерий «выбранный корень подставляется в следующий перенос»; (2) иначе корень активной сессии tmux — умолчание из плана (currentTodosPath); (3) иначе первый доступный проект; (4) иначе null. Возврат null означает, что выбирать не из чего (не открыто ни одной сессии tmux) — на этом держится погашенная кнопка PUSH и внятная подсказка вместо заведомого 400 от POST /api/todos.

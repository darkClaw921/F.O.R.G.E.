# noiseSeed

`tmux-web/static/js/messenger/waveform-core.js` — «соль» ДЕТЕРМИНИРОВАННОГО шума-заглушки.

Сигнатура: `noiseSeed(messageId, index = null) -> number`.

# Зачем детерминированность

Заглушка рисуется, пока настоящей огибающей нет (у Битрикса — пока её не досчитал
бэкенд). Случайный шум заставлял бы карточку «дышать» при каждой перерисовке ленты, а
два голосовых в одном сообщении выглядели бы одинаково. Соль решает обе задачи:
`base = (messageId || 1) * 2654435761` (константа Кнута), а номер вложения подмешивается
как `base ^ ((index + 1) * 40503)`.

# ЛОВУШКА: `index` НЕОБЯЗАТЕЛЕН НЕ ДЛЯ КРАСОТЫ

Панели, у которых вложение в сообщении одно (Telegram), передают только `messageId`.
Подмешать им ноль было бы «эквивалентно» математически, но изменило бы рисунок ВСЕХ уже
нарисованных заглушек, которые человек видит каждый день. Поэтому у VK и Telegram соль
РАЗНАЯ, и сводить их нельзя.

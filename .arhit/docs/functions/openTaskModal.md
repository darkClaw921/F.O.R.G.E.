# openTaskModal

Карточка задачи трекера (tmux-web/static/js/tracker/modals.js).

Открывает модальное окно NODE: шапка с чекбоксом, приоритетом и заголовком, блок // FIELDS (список, статус, приоритет, оценка, срок, теги), заметки, блок // CHECKLIST — n/m с полосой прогресса и таймером у каждого пункта и блок // TIME со списком отрезков, кнопки DELETE · MARK DONE · SAVE и [→ tasks/todo].

Два контура перерисовки. Кадр WS обновляет ТОЛЬКО живые блоки (чек-лист и отрезки) и никогда не трогает форму: иначе первый же кадр стёр бы набранный текст. Блок с открытым inline-редактором пропускается до конца правки (local.busy). PATCH несёт только реально изменённые поля, а пустое поле уезжает как null — модель различает «не передали» и «передали null» (Option<Option<T>> в models.rs). Ошибки показываются в самой карточке, и карточка при ошибке не закрывается.

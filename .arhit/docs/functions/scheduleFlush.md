# scheduleFlush

Откладывает слив накопленных запросов состояний на один общий вызов. Таймер ставится ОДИН (повторный вызов при уже заведённом таймере выходит первой строкой), иначе быстрый скролл ленты дал бы по запросу на каждое сообщение. Часы берутся из подменяемых timers() — тест обязан двигать время сам, а не спать.

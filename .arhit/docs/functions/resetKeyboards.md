# resetKeyboards

tmux-web/static/js/telegram/botkb.js — полный сброс состояния клавиатур.

Сигнатура: resetKeyboards() -> void. Чистит карту «диалог → клавиатура», прячет полосу и ГАСИТ
все таймеры обратного отсчёта (429). Незагашенный таймер после логаута продолжал бы дёргать
несуществующие узлы и держал бы ссылку на них.

Зовётся из chat.js::resetChat (логаут, смена аккаунта).

# buildMemorySection

Строит редактируемую Markdown секцию {el,id} для файла {name,content,isIndex}. ctx содержит path, provider, endpoint, isCurrent и onSaved. Имя выводится textContent, тело — безопасным DOM renderer; data-memory-file используется для relative links, ID кодирует полное имя без коллизии slash/dash. Правка показывает textarea и Сохранить/Отмена. Перед открытием редактора и отправкой PUT проверяется актуальность ревизии. Endpoint и file фиксированы при создании секции: переключение Claude/Codex во время HTTP запроса не меняет адрес записи. После успешного PUT текущая модалка перечитывается; ответ или ошибка устаревшей секции не меняет DOM и не вызывает alert. Ошибка актуального сохранения оставляет введённый текст и снова включает действия. Сервер определяет допустимость и область файла.

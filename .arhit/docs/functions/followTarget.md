# followTarget

followTarget(nowMs) -> ?{dialogId: string, messageId: number} (tmux-web/static/js/telegram/follow.js) — текущая цель «следования» ленты Telegram С УЧЁТОМ СРОКА ГОДНОСТИ.

Единственная точка, где проверяется, живо ли следование. Возвращает null, если следования нет (untilMs===0) или окно истекло (now > untilMs); иначе — {dialogId, messageId}, где messageId===0 означает «следим за диалогом целиком» (кнопка reply-клавиатуры).

ПАРАМЕТР: nowMs — Date.now() вызывающего; не-число ⇒ 0 (то есть «ещё не истекло», следование считается живым — консервативный выбор, следование само погаснет по таймеру).

ЧАСЫ, ПРЫГНУВШИЕ НАЗАД (коррекция NTP, ноутбук вышел из сна), следование НЕ РВУТ: условие истечения — строго `now > untilMs`, то есть «now меньше» читается как «ещё не истекло», а не как ошибка. Тот же выбор, что у format.js::toastAllowed — единообразие важнее теоретической точности, потому что окно короткое и всё равно закрывается таймером.

ГРАНИЧНЫЙ СЛУЧАЙ: ровно `now === untilMs` — следование ЕЩЁ живо (строгое сравнение). Проверено тестом telegram_follow.test.mjs (секция «Регистрация и срок жизни»).

ПОТРЕБИТЕЛИ: isFollowing и followsMessage (строятся поверх); chat.js::renderHistory (переставить наблюдение на пересозданную строку), chat.js::onFollowResize (самопроверка срока — наблюдатель может пережить истечение на кадр), chat.js::_debugChatState (поле followActive).

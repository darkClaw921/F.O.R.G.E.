# meetButtonOf

Поиск кнопки встречи в строке ленты (messenger/meet-row.js) — ПО АТРИБУТУ data-action=meet, а не по классу. Тот же способ, которым обходит строку rowActionButton у Битрикса, и тот же атрибут, за который держатся e2e: класс — дело CSS и может смениться, атрибут — контракт. Принимает узел строки, возвращает узел кнопки или null.

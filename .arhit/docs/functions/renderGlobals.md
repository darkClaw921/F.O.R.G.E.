# renderGlobals

analytics.js::renderGlobals(summary) — карточка «Глобальные счётчики Claude Code» из блока summary.globals (данные ~/.claude.json: skillUsage, pluginUsage, toolUsage).

Рисует до трёх списков горизонтальных полос (навыки, плагины, инструменты), по GLOBALS_TOP = 10 строк в каждом, высота плота = 40 + ROW_H*строк (на живой приёмке 20 строк в фиксированной высоте налезали подписями на полосы).

Ключевое ограничение, вынесенное в подпись карточки: это ГЛОБАЛЬНЫЕ счётчики CLI за всё время, они не фильтруются ни периодом, ни проектом. Без явной подписи их числа неизбежно сравнивали бы с числами дашборда. Блока globals в ответе нет (файла нет или он битый) — карточка не рисуется вовсе, без ошибки.

# onReplyEscape

tmux-web/static/js/telegram/chat.js (private)

`onReplyEscape(e)` — Esc снимает выбранный ответ и возвращает фокус в поле ввода.

ГАРД НА ЛАЙТБОКС обязателен: этот обработчик регистрируется раньше лайтбоксного (initChat идёт до
initMedia), и без проверки `$tgLightbox.hidden` одно нажатие Esc снимало бы полосу ответа вместо
закрытия картинки.

`preventDefault` — только когда действительно что-то отменили, чтобы не глотать Esc у соседей.

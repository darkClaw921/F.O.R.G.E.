# formatMeetClock

Длительность записи в подпись кнопки (messenger/meet-row.js): до часа M:SS, дальше H:MM:SS. Постоянные ведущие нули (0:07:12) съедали бы ширину на строке, где кнопка висит поверх текста. Отрицательное значение (часы машины разъехались) даёт 0:00, а не минус. Считает Math.floor от миллисекунд; вход — результат elapsedMs, то есть ВЫЧИТАНИЕ от startedAtMs, а не инкремент.

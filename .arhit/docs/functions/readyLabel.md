# readyLabel

`tmux-web/static/js/messenger/voice-transcript-core.js` — подпись строки состояния для фазы `ready` (текст готов).

Называет движок, которым получен результат, и язык из кадра `done`. Подпись остаётся
видимой после завершения намеренно: человек должен понимать, локальная это расшифровка
или уехавшая в облако, — иначе смена движка во вкладке настроек была бы незаметна.

# sendFiles

Кладёт файлы в очередь отправки панели VK (tmux-web/static/js/vk/upload.js). Все принятые файлы одного вызова становятся ОДНИМ сообщением (пачкой) — так работает альбом VK; при более чем MAX_PER_MESSAGE=10 файлах пачек несколько, и каждая уедет своим сообщением. Подпись по умолчанию забирается из #vk-input и поле очищается (пользователь набрал текст и приложил файл — он ждёт одно сообщение с подписью), уходит только с первой пачкой. Цель ответа (conversation_message_id) читается из reply.js и фиксируется в пачке В МОМЕНТ ДЕЙСТВИЯ, а не перед отправкой: очередь последовательная, и полоса к тому времени может показывать другое сообщение. Файлы, отвергнутые uploadRejectReason (лимит по виду вложения, пустой файл), до сети не доходят вовсе и объявляются системной строкой. Полоса ответа снимается только если хоть один файл принят.

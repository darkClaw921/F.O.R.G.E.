# clearReplyTarget

tmux-web/static/js/telegram/reply.js

`clearReplyTarget() -> boolean` — была ли цель.

Снимает цель ответа. Возвращаемое значение нужно вызывающему, чтобы решить, гасить ли Esc
(preventDefault только когда действительно что-то отменили, иначе Esc перестанет доходить до
соседних обработчиков — лайтбокса, модалок).

Напрямую из upload.js НЕ вызывается: там гасится вся полоса через chat.cancelReply(), потому что
сброс половины (цель без DOM-узла) оставил бы полосу висеть над пустым состоянием.

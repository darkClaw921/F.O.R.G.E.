# balanceLine

settings/meet-tab.js (Ф16): остаток средств и лимит ключа одной строкой по телу GET /api/meet/cloud/balance. Возвращает {tone: ok|warn|wait, text}.

Ветки: null (ответа ещё нет) -> wait 'спрашиваем'; configured:false -> warn 'ключ не задан'; error -> warn с причиной; иначе строка вида 'Остаток: 461,89 руб (потрачено 138,72 руб). Лимит ключа: 288,73 руб из 300,00 руб, сброс ежемесячно.' Тон warn, если limit_remaining <= 0.

Суммы В РУБЛЯХ (валюта у polza.ai одна), формат даёт formatRub: три знака у сумм меньше рубля, иначе два — иначе цена 0,048 руб/мин превратилась бы в 0,05 и стёрла разницу втрое между моделями расшифровки. limit_reset остаётся строкой: у живого ключа там monthly, а не daily.

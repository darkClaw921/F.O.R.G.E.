# noteReplyMarkup

tmux-web/static/js/telegram/botkb.js — учесть разметку ОДНОГО сообщения.

Сигнатура: noteReplyMarkup(msg) -> boolean (изменилось ли состояние клавиатуры диалога).

Зовётся из chat.js на кадрах new_message и message_edited. Обновляет reply-клавиатуру ДАЖЕ ДЛЯ
НЕОТКРЫТОГО диалога: состояние клавиатуры принадлежит чату, и при переключении на него полоса
обязана быть уже правильной, а не «догоняться» после первого рендера.

inline-разметка здесь игнорируется — она живёт со своим сообщением и рисуется
buildMessageKeyboard.

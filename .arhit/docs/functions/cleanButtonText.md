# cleanButtonText

tmux-web/static/js/telegram/botkb.js — вычистка и обрезка подписи кнопки бота.

Сигнатура: cleanButtonText(raw, max) -> string. Пустая строка означает «подписи нет» и кнопку
рисовать НЕЛЬЗЯ (normalizeButton вернёт null).

Что делает и зачем: подпись приходит от ЧУЖОГО бота. Вырезаются управляющие символы и
bidi-override (U+202E RLO переворачивает отображение строки — это готовый спуфинг «Удалить» ↔
«Оставить»). ZWJ (U+200D) СОХРАНЯЕТСЯ: без него составные эмодзи рассыпаются на части.
Обрезка идёт по CODE POINTS, а не по .length — иначе обрезание пополам суррогатной пары даёт
битый символ.

Парная функция для ответа бота — cleanAnswerText (там переводы строк сохраняются).

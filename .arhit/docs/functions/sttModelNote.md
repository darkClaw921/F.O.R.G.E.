# sttModelNote

settings/meet-tab.js (Ф16): пригодность выбранной облачной модели расшифровки. Читает флаг timestamps, который приходит С СЕРВЕРА (routes::cloud + cloud::stt_gives_timestamps).

timestamps === false -> warn: модель НЕ ДАЁТ ТАЙМКОДОВ вообще, расшифровку нечем положить на таймлайн, атрибуция спикеров сломается целиком, реплики достанутся не тем людям. Такая модель (openai/whisper-large-v3-turbo) втрое дешевле, и без явной пометки её выбрали бы ради экономии.
Модель вне каталога -> warn: облачная расшифровка упадёт на первой встрече.
Иначе ok: таймкоды посегментные; пословных в облаке не даёт ни одна модель, поэтому сегмент с низкой уверенностью помечается наложением, а не режется по границе слова.

Рядом живут modelPrice (цена из top_provider.pricing; отсутствие цены — 'цена не указана', а НЕ 'бесплатно'), modelOptionLabel (подпись пункта списка с ценой и меткой), summaryModelNote и summaryCostEstimate (оценка стоимости саммари часовой встречи: 30 тыс. токенов входа и 2 тыс. выхода, у gemini-3.5-flash около 7 руб).

# buildWave

`tmux-web/static/js/messenger/waveform-core.js` — собирает готовый узел звуковой дорожки.

Сигнатура: `buildWave({ waveform, seed = 1, className, doc = globalThis.document }) -> node`.
Контейнер получает `className` панели (у каждой свой), внутрь кладётся по `<span>` на
каждую высоту из `waveHeights`.

# ДВЕ ВЕЩИ, КОТОРЫЕ ЛЕГКО ПОТЕРЯТЬ

1. **`aria-hidden="true"` на контейнере.** Волна — картинка, а не текст: скринридеру она
   не даёт ничего, а сорок пустых `span` в озвучке — это сорок пауз посреди карточки.
   Атрибут ставится через `typeof setAttribute === 'function'`, потому что фейковые
   документы тестов его не всегда имеют.
2. **`doc` — параметр, а не глобальный `document`.** Разметку карточек Битрикса строит
   `js/bitrix/attachments.js` на фейковом документе фронт-тестов (`bitrix_dom_stub.mjs`),
   где из всего DOM есть `createElement`/`appendChild`. Модуль обязан работать и там —
   иначе одна из трёх панелей осталась бы без теста разметки.

Модуль появился в Ф2 фичи голосовых: до неё волну умел рисовать только VK
(`js/vk/media.js`), Telegram всегда рисовал шум, у Битрикса ветки настоящей огибающей не
было вовсе. Копировать двадцать строк в третий раз значило бы завести три расходящихся
вида одной карточки.

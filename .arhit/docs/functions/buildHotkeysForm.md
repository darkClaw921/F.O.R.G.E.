# buildHotkeysForm

settings/hotkeys-tab.js — форма вкладки «Горячие клавиши»: тумблер telegram_hotkeys_enabled (инициализация '!== false', дефолт ВКЛЮЧЕНО — идиома соседей из interface-tab.js здесь неприменима), таблица действий с текущими комбинациями, запись новой комбинации по нажатию, сброс одного действия и всех сразу. Черновик правок живёт в локальной Map до Save: закрытая без сохранения модалка ничего не меняет. Слушатель записи снимается при первом же событии, Escape отменяет запись, а не назначается. Save шлёт telegram_hotkeys_enabled и telegram_hotkeys (только отличия от дефолтов) и дёргает ForgeApp.telegramKeys.invalidate().

# initTelegramMobile

Навешивает обработчики мобильной раскладки вкладки Telegram: клик по ☰, клик по подложке, Esc (реагирует только при открытой панели, поэтому не конфликтует с Esc лайтбокса медиа) и matchMedia 'change' для закрытия при переходе на десктопную ширину. Идемпотентна, зовётся из initTelegram().

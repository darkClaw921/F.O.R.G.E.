# buildScope

Блок «В каких чатах разбирать автоматически» в секции голосовых сообщений (tmux-web/static/js/settings/voice-tab.js, приватная функция секции).

## Что делает

Собирает на общей форме выбора (buildPeerPicker) белый список бесед, в которых голосовые расшифровываются АВТОМАТИЧЕСКИ, и добавляет к ней подпись, строку-итог и свою кнопку «Сохранить выбор». Возвращает {node, setEnabled(v)} — второй метод зовёт секция при переключении тумблера авторазбора.

## Ключевое решение: ПУСТО = РАЗБИРАТЬ ВЕЗДЕ

Отдельного тумблера включения у скоупа НЕТ. Пустой список означает «во всех беседах», и поэтому появление фичи не меняет поведение уже работающих установок ни на шаг. Сказать это надо вслух (константа SCOPE_HINT): белый список, который человек ни разу не открывал, читается как «ничего не выбрано», то есть как «ничего и не разбирается», — настройка работает ровно наоборот.

## Поля и словарь площадки

Пишет ровно два поля user_settings, взятые из cfg.scope: vk_voice_scope_kinds/vk_voice_scope_peers, telegram_voice_scope_folders/telegram_voice_scope_dialogs, bitrix_voice_scope_kinds/bitrix_voice_scope_peers. Гранулярность та же, что у видимости: у VK группы — ТИПЫ бесед, у Telegram — ПАПКИ аккаунта, у Битрикс24 — ВИДЫ диалогов. Селект движка по-прежнему пишет voice.toml через роут …/voice/settings и этим блоком не затрагивается.

## Связи и поведение

Источники списков приходят в api (listScopeGroups/listScopePeers) из settings/voice-scope-sources.js, подключает их modal.js. Сохранение — своей кнопкой, а не по каждой галочке: выбор собирается из десятков отметок. Списки уходят ЦЕЛИКОМ (снять галочку иначе нечем) и вместе с выбранными, но не загруженными id.

Блок доступен только при включённом чекбоксе авторазбора; доступность меняется СРАЗУ при щелчке, ещё до ответа бэкенда (иначе человек решил бы, что модалку надо переоткрыть), а отказ PATCH возвращает и чекбокс, и доступность блока.

## Ограничение

Скоуп НЕ отменяет белый список ВИДИМОСТИ: скрытая беседа не разбирается, даже если попала в скоуп (порядок ступеней — forge_voice::auto::decide). У Битрикс24 чат задачи по DIALOG_ID неотличим от обычного, поэтому вид task — такая же группа в этом же списке, отдельного выбора «только чаты задач» нет.

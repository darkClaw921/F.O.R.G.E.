# dialogIdVisible

visibility.js — виден ли чат, о котором известен только id. Точка входа для WS-кадров: new_message приходит по всему аккаунту, и диалога может не быть в загруженном списке. Если он там есть — решение по полному DTO; иначе действует строгое правило: неизвестный чат при действующем фильтре СКРЫТ, если не отмечен поимённо. Без этой строгости фильтр протекал бы уведомлениями ровно от тех чатов, ради которых он включён. Числовой id приводится к строке — id приходят и числом, и строкой.

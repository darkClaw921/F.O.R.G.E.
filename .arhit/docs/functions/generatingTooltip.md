# generatingTooltip

Строит tooltip task-backed синей звезды. Аргумент — DTO с name, working_agent_count, agent_providers и generating_since_secs. Провайдеры дедуплицируются и форматируются общим providerName, возраст выводится в секундах/минутах/часах от начала задачи. Для нескольких основных агентов уточняется, что возраст относится к самой ранней задаче. Старые remote DTO без новых полей остаются совместимыми. Проверка конечных чисел предотвращает NaN, и утверждений про hash/50 строк/поток вывода больше нет.

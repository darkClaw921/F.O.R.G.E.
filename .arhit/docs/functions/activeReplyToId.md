# activeReplyToId

tmux-web/static/js/telegram/upload.js (private)

`activeReplyToId(dialogId) -> ?number`

Читает текущую цель ответа из reply.js (replyTargetId) с защитой от отсутствующей функции: статика
отдаётся без сборщика и без хеша, и старый закешированный reply.js мог бы не иметь этого экспорта —
тогда медиа просто уйдёт без цитаты, а не свалит отправку целиком.

Проверку «цель из ЭТОГО диалога» делает сам reply.js: пока файл стоял в очереди, пользователь мог
уйти в другой чат.

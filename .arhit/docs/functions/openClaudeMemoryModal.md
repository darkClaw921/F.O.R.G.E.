# openClaudeMemoryModal

Совместимый экспорт обработчика кнопки 🧠 из bootstrap. Создаёт стандартный overlay/card с заголовком «Память агентов», двумя кнопками выбора Claude/Codex, scope-подписью, телом Markdown, кнопками назад/закрыть. По умолчанию открывает Claude для cwd выбранной tmux-сессии; Codex отображает общую память профиля и субагентов. Состояние принадлежит одному экземпляру окна: provider, path, revision, closed и AbortController. Смена источника обновляет aria-pressed и подпись, сбрасывает внутреннюю навигацию и отменяет старое чтение. Закрытие кнопкой либо фоном помечает экземпляр closed и abort pending GET. Начальная загрузка await для обратной совместимости вызовов. Само открытие не записывает память и не запускает модели.

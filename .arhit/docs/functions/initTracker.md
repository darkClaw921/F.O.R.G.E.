# initTracker

Точка входа панели трекера (tmux-web/static/js/tracker/main.js).

Поднимает вкладку при первом открытии: навешивает сайдбар (директории, списки, теги), форму prompt'а, переключатель режимов list · kanban · gantt · report, титлбар и статусбар, открывает сокет, читает снимок и восстанавливает режим из localStorage (только если он реализован). suspendTracker/resumeTracker гасят и возвращают сокет и тикер при уходе с вкладки, teardownTracker снимает всё целиком. Панель ленива: модуль грузится динамическим import'ом из js/tabs/tabs.js только после клика по кнопке ✇.

# buildDescription

Текст описания TODO-карточки, создаваемой переносом задачи трекера (js/tracker/to-todo.js). Формат ЗАФИКСИРОВАН и проверяется тестом tracker_push.test.mjs: заметки задачи первыми и без заголовка, пустая строка, блок «// TRACKER NODE <8 знаков id>» с полями приоритет/статус/список/теги/оценка/начало/срок/потрачено, затем «// CHECKLIST done/total» и пункты [x]/[ ]. Пустые поля строк не занимают. Принимает (task, ctx), где ctx = {listName, seconds, items} собирается contextOf() из снимка /api/tracker/state — отдельного запроса ради описания нет. Обратной ссылки на созданный todo в тексте нет намеренно: перенос это копия, связи между задачей и todo не существует.

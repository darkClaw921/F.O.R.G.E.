# runningLabel

`tmux-web/static/js/messenger/voice-transcript-core.js` — подпись строки состояния для фазы `running` (идёт расшифровка).

Собирает текст из состояния ключа: движок (`local` -> «локально», `cloud` -> «облако»,
таблица `ENGINE_LABEL` — те же два слова, что в селекте вкладки настроек) и процент из
кадра `voice_transcribe_delta`.

ЛОВУШКА КОНТРАКТА: кадр `delta` несёт ТОЛЬКО `percent`, текста в нём нет — текст приезжает
целиком в `done`. Поэтому строка состояния во время прогона показывает движок и проценты,
а не растущий текст.

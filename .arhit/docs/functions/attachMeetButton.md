# attachMeetButton

meet-row.js: вешает кнопку встречи на строку ленты. Гейт первой строкой (плагин выключен — ни детекта, ни узла). С фазы 10 добавлен второй выход: `hit.audio === false` — кнопки нет вовсе. Флаг реестра означает измеренный факт «звук с этой площадки забрать не умеем» (кандидат — Zoom с WASM-пайплайном), а не «пока не проверяли»; нарисованная кнопка обещала бы запись, которая гарантированно вышла бы пустой, и человек узнал бы об этом через полчаса после встречи. Сегодня audio=false не стоит ни у одной платформы. Дальше: панель→префикс класса, ключ meetKey(panel,chatId,messageId), состояние на узле в `_meet`, клик через onMeetClick с preventDefault+stopPropagation.

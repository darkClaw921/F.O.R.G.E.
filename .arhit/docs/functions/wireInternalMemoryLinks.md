# wireInternalMemoryLinks

Подключает внутреннюю навигацию Markdown в пределах уже загруженных секций модалки памяти. Принимает body, Map относительных имён файлов на ID заголовка, backStack позиций прокрутки и onNavigate для показа кнопки «↑ Назад». У каждой секции data-memory-file хранит полное имя относительно корня API. Ссылка разрешается URL относительно этого имени: memories/MEMORY.md → rollout_summaries/x.md, либо memories/rollout_summaries/x.md → ../MEMORY.md. Percent-encoded имена декодируются, query/fragment не мешает определению .md; внешние URL, абсолютные пути и чистые anchors не перехватываются. Найденная секция прокручивается внутри окна и сохраняет предыдущую позицию. Неизвестный файл получает класс missing, подсказку и preventDefault, чтобы браузер не уходил на отсутствующий URL FORGE. Не читает файловую систему и не загружает ссылки автоматически.

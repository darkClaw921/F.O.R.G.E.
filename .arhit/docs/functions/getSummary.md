# getSummary

Клиент GET /api/meet/meetings/:id/summary в static/js/meet/api.js. Ответ — {meeting_id, status, text}: отсутствие текста НЕ 404. 404 означал бы «нет такой встречи», а саммари могло не считаться вовсе (выключено конфигом), считаться сейчас или не получиться — и карточка показывает это по-разному. Различить случаи можно только по status (none/pending/ready/failed), поэтому сервер отвечает 200 с text=null.

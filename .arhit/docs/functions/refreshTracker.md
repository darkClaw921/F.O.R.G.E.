# refreshTracker

Перечитывание состояния панели трекера (tmux-web/static/js/tracker/main.js).

Забирает GET /api/tracker/state (задачи, списки, пункты, вехи, отрезки, активные отрезки и посчитанные СЕРВЕРОМ агрегаты task_seconds, item_seconds, totals, progress) и перерисовывает текущий режим. Агрегаты никогда не считаются в JS: любое изменение отрезка ведёт к перезапросу снимка, иначе фронт разъехался бы с report.rs, где время пункта чек-листа входит в сумму задачи ровно один раз. Вызывается после каждой собственной мутации и по кадрам WS, а во время активного drag откладывается.

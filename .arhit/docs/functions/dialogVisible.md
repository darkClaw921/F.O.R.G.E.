# dialogVisible

visibility.js — виден ли диалог при действующем белом списке. Порядок: поимённый выбор сильнее папок (отмеченный чат виден, даже если его папка не отмечена), затем папки, где 'inbox' = все неархивные, 'archive' = весь архив, 'folder:<id>' = правила dialogFilter через format.js::dialogInFolder. Выключенный фильтр → всегда true. null-диалог при действующем фильтре скрыт. Исчезнувшая или не загруженная папка совпадений не даёт.

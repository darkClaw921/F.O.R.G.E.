# truncatePreview

tmux-web/static/js/telegram/reply.js

`truncatePreview(text, max = REPLY_PREVIEW_CHARS) -> string`

Обрезка превью цитаты с многоточием ПО CODE POINTS. Возвращает пустую строку, если текста нет.

Три обязательных свойства (те же, что у серверного dto::reply_preview_text):
- режем по code points, а не по UTF-16-юнитам: `slice()` разрубает суррогатную пару, и от emoji
  остаётся одинокий «�»;
- любые пробелы и переводы строк схлопываются в один пробел — иначе многострочный оригинал раздул
  бы строку ленты на пол-экрана;
- многоточие ВХОДИТ в лимит, поэтому результат никогда не длиннее `max`.

Обрезка повторяется на фронте, хотя сервер уже обрезал: превью собирается и локально
(mergeReplyFromMessage из загруженной ленты), где серверные ограничения не действуют.

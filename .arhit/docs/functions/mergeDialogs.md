# mergeDialogs

tmux-web/static/js/telegram/format.js — слияние догруженной страницы диалогов с текущим списком.

Сигнатура: mergeDialogs(current, fresh) -> Array<object>. Дедупликация по String(id).

Свежий ответ АВТОРИТЕТЕН и идёт ПЕРВЫМ: в нём порядок Telegram и актуальные muted/unread.
Диалоги, которых в свежей странице нет, дописываются В ХВОСТ — иначе выбор пользовательской
папки стирал бы ранее подтянутый архив и другие страницы, то есть догрузка ломала бы список
вместо того, чтобы его дополнять.

Парная константа FOLDER_LIST_LIMIT = 300 — сколько диалогов просить у сервера под
пользовательскую папку; совпадает с backend DEFAULT_FOLDER_DIALOGS.

Используется dialogs.js::ensureFullList.

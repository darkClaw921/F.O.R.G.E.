# resolveCardClick

tmux-web/static/js/telegram/media.js — что делать при клике, запускающем воспроизведение в
медиа-карточке. ЧИСТАЯ функция, единственная точка истины «пересоздавать ли плеер».

Сигнатура: resolveCardClick(cardKey, activeKey, fromPlayer) -> 'ignore'|'toggle'|'start'.
cardKey — '<dialog_id>/<message_id>' карточки; activeKey — ключ карточки активного плеера или
null; fromPlayer — клик пришёл изнутри плеера.

- 'ignore' — клик из нативных controls активного плеера: карточка его НЕ трогает. Без этой
  ветки любая перемотка или пауза пересоздавали бы элемент и сбрасывали currentTime в 0, то есть
  перемотка была бы физически невозможна;
- 'toggle' — плеер ЭТОЙ карточки уже открыт: play/pause без пересоздания, позиция сохраняется;
- 'start'  — плеера нет или он на другой карточке: создать новый, старый погасить (инвариант
  «играет ровно один» — иначе голосовое и видео накладываются и перекрикивают друг друга).

Вынесена из playInCard именно ради тестируемости: решение проверяется node-тестом без DOM.
Парная функция — isPlayerClick.

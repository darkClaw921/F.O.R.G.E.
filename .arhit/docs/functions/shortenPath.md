# shortenPath

Сокращение домашнего префикса пути до ~ для подписей корней в диалоге переноса (js/tracker/to-todo.js). Настоящего $HOME у браузера нет и спрашивать его у сервера ради подписи не стоит, поэтому сокращается ТОЛЬКО заведомо домашний префикс /Users/<кто-то> и /home/<кто-то>; всё остальное (/opt/..., /srv/... и прочее) показывается как есть — длинный честный путь лучше короткого неверного.

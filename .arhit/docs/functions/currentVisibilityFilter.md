# currentVisibilityFilter

state.js — действующий фильтр видимости чатов (белый список из настроек). Настройки читаются лениво через публичный контракт window.ForgeApp, тем же приёмом, что в keynav.js и hotkeys.js: модули панели грузятся раньше ответа /api/user-settings, и снимок, взятый на старте, застыл бы навсегда. Отсутствие настроек = фильтр выключен (совпадает с backend-дефолтом и с поведением до фичи).

Результат кэшируется по СОДЕРЖИМОМУ трёх полей настроек: dialogRings-путь зовёт эту функцию на каждое входящее сообщение, а пересобирать два Set'а ради каждого кадра незачем. Ключ по содержимому (а не по ссылке на объект) даёт нужное свойство: сохранённые настройки действуют сразу, без перезагрузки страницы. Явный сброс — invalidateVisibilityFilter().

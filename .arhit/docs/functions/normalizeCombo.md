# normalizeCombo

keys.js — приводит записанную строку к каноническому виду. Терпит пользовательский порядок модификаторов и синонимы (cmd/command/super/win → Meta, control → Ctrl, option/opt → Alt), потому что комбинация может приехать из настроек, написанных руками в JSON. Возвращает null для пустой строки, строки из одних модификаторов, двух клавиш ('a+b'), неизвестного модификатора и неизвестного имени клавиши. Идемпотентна на выходе comboFromEvent — иначе переназначенная клавиша не сработала бы никогда.

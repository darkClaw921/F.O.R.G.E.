# replyTargetId

tmux-web/static/js/telegram/reply.js

`replyTargetId(dialogId) -> ?number`

`reply_to_id` для отправки в активном диалоге (или null). Тонкая обёртка над replyTarget.

Главный потребитель — upload.js::sendFiles: медиа обязано уходить с тем же reply_to_id, что и
текст. Цель читается ОДИН раз при постановке файлов в очередь и фиксируется в item'е, а не перед
самой отправкой: очередь последовательная, и пока до файла дойдёт ход, полоса уже может показывать
другое сообщение.

# getMeeting

Клиент GET /api/meet/meetings/:id в static/js/meet/api.js — карточка встречи. Ответ — обёртка {meeting, participants, segments_total}, а не голая строка: карточке нужны оба списка, и второй запрос за участниками стоил бы лишнего похода в базу на каждое открытие попапа. Попап терпим к обеим формам (dto.meeting || dto). Роут реализован в Ф6 (долг Ф5).

# repaintMeetButtons

Перерисовка кнопок встречи по кадрам стора (messenger/meet-row.js). Обходит зарегистрированные ленты (registerMeetRoot), находит в них .meet-btn и красит каждую по текущему состоянию из кэша. Зовётся из единственной подписки на стор по событиям states, meeting, snapshot, resync и tick; progress и transcript_delta намеренно НЕ вызывают перерисовку — они содержимое попапа, на кнопке не видны, а приходят по несколько раз в секунду. Всё нужное для перерисовки лежит НА УЗЛЕ (btn._meet): поиск по классу иначе не знал бы, к какой строке относится кнопка.

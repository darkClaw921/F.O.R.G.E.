# meetViewFor

Чистая функция «состояние встречи -> внешний вид кнопки» (messenger/meet-row.js). Принимает запись стора (или null, когда кэш ещё пуст) и метку времени, возвращает {status, glyph, label, tone, pinned, pulse, title, aria}. Таблица видов MEET_VIEWS покрывает 12 статусов MeetStatus плюс псевдостатус none («можно записать»); полнота таблицы проверяется контрактным тестом ПРОТИВ status.rs, поэтому новый статус на бэкенде ломает тест, а не рисуется пустой кнопкой. Две особые ветки: у recording подпись заменяется живым таймером elapsedMs(startedAtMs, now), а у ready с summaryStatus=failed тон становится warn — на бэкенде переход summarizing -> failed запрещён намеренно (час расшифровки не имеет права пропасть из-за неответившего саммаризатора), поэтому провал саммари виден ТОЛЬКО по этому полю. Незнакомый статус не роняет кнопку: сохраняется как есть, вид берётся от none. Поле aria отличается от title намеренно — подпись для скринридера стабильна, иначе фокус на кнопке во время записи давал бы посекундное бормотание.

# latestReplyMarkup

tmux-web/static/js/telegram/botkb.js — актуальная reply-клавиатура диалога по загруженной истории.

Сигнатура: latestReplyMarkup(messages) -> ?{markup: object, messageId: number}.
Вход — лента по возрастанию id.

Клавиатура это СОСТОЯНИЕ ЧАТА: берётся ПОСЛЕДНЕЕ ВХОДЯЩЕЕ сообщение, у которого есть
keyboard / hide / force_reply. inline-разметка пропускается (она рисуется под своим сообщением).

hide означает «клавиатуры нет» ⇒ возвращается null, а НЕ объект: иначе полоса осталась бы на
экране после того, как бот её убрал.

Свои сообщения (out) игнорируются: reply_markup у них не бывает, а если бы и был — это была бы
наша собственная разметка, а не бота.

Зовётся из applyHistoryKeyboard (renderHistory): страница вверх приносит СТАРЫЕ сообщения, и
актуальной обязана остаться нижняя — поэтому пересчёт идёт по всей ленте, а не по приращению.

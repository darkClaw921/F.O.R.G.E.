# resolveBindings

keys.js — итоговые привязки с учётом переопределений: {bindings: Map id→combo, byCombo: Map combo→id, conflicts, unbound}. ДВА ПРОХОДА по реестру: сначала все переопределения, затем дефолты нетронутых действий. Один проход дал бы дефолту раннего действия победу над переопределением позднего. Конфликт разрешается 'переопределение сильнее дефолта, среди переопределений — то, что раньше в реестре', поэтому результат не зависит от порядка ключей в пришедшем JSON. Проигравшее действие остаётся БЕЗ клавиши и честно показывается таким в настройках: молчаливый возврат дефолта соврал бы пользователю, который этот дефолт только что занял.

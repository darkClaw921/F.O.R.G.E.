# replySourceLine

tmux-web/static/js/telegram/reply.js

`replySourceLine(msg, dialog?) -> '#7 sofia: текст'`

Однострочное описание сообщения для СИСТЕМНОЙ строки лога. Используется chat.js::jumpToMessage,
когда оригинал цитаты не удалось показать в ленте (он далеко за пределами загруженной истории) и
его пришлось запросить роутом GET /dialogs/:id/messages/:mid: пользователь всё равно видит, на что
именно отвечали, хотя строки в ленте нет.

Формат: `#<id> <автор>: <превью>`; части отсутствуют, если их нет (например, у ответа на сторис
нет id).

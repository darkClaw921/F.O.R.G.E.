# flashRow

tmux-web/static/js/telegram/chat.js (private)

`flashRow(messageId)` — кратковременно подсвечивает строку (класс `tg-msg-highlight`, REPLY_FLASH_MS = 2000 мс).

Подсвеченная строка запоминается ПО ID (`local.flashId`), а не по узлу: подгрузка истории вверх
перерисовывает ленту целиком и убила бы и ссылку на узел, и класс. Поэтому renderHistory в конце
переприменяет класс к строке с сохранённым id, а таймер снимает его один раз (clearFlash).

Подсветка сбрасывается также при смене диалога, logout и удалении подсвеченного сообщения.

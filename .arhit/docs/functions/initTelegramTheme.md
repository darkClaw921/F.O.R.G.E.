# initTelegramTheme

Инициализация темы вкладки Telegram: восстанавливает режим из localStorage, навешивает обработчик тумблера ◐, ставит MutationObserver на атрибуты style/class/data-theme элемента <html> (единственная развязка, не тянущая плагин в модуль тем — обратный импорт замкнул бы граф модулей) и применяет тему. Идемпотентна. Зовётся из js/core/bootstrap.js ДО initTelegramGate, чтобы вкладка не мигнула чужой палитрой.

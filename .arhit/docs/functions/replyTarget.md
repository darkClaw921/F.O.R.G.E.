# replyTarget

tmux-web/static/js/telegram/reply.js

`replyTarget(dialogId) -> ?target`

Цель ответа ДЛЯ УКАЗАННОГО диалога. Сверка диалога — это и есть сброс при переключении чата: цель,
выбранная в другом диалоге, невидима, и ответ туда не уйдёт, даже если полосу забыли убрать. Такая
защита нужна именно из-за асинхронности: между выбором цели и отправкой (особенно медиа, стоящего в
очереди) пользователь успевает уйти в другой чат.

Потребители: chat.js::send (reply_to_id + цитата оптимистичной строки), chat.js::onReplyEscape,
chat.js::cancelReplyTo, upload.js::activeReplyToId (через replyTargetId).

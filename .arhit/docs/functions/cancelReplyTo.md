# cancelReplyTo

tmux-web/static/js/telegram/chat.js (private)

`cancelReplyTo(dialogId, messageId) -> boolean`

Сбрасывает полосу ответа, только если она указывает ИМЕННО на это сообщение в этом диалоге.

Точечность обязательна в двух местах:
- после успешной отправки — пока летел POST, пользователь мог выбрать другую цель, и безусловный
  сброс стёр бы её;
- при удалении сообщения (onDeleted) — отвечать на удалённое нечем: Telegram отверг бы такой
  reply_to_id, а пользователь до отправки видел бы живую полосу.

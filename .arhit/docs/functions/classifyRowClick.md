# classifyRowClick

tmux-web/static/js/telegram/reply.js

`classifyRowClick(target) -> 'reply' | 'ignore'`

Что означает двойной клик по ленте. От DOM нужен только `closest`, поэтому функция чистая и покрыта
node-тестами (тот же приём, что у media.js::isPlayerClick).

СТОП-ЛИСТ REPLY_CLICK_IGNORE и почему каждый пункт:
- `.tg-media-player` — нативные controls ретаргетят события на сам `<video>`; двойной клик по
  ползунку перемотки не должен открывать ответ;
- `.tg-media-card` — карточка открывает медиа ОДИНАРНЫМ кликом, поэтому двойной уже запустил
  лайтбокс/плеер дважды, и третьим действием ещё и поймать ответ — перебор;
- `.tg-kb` — кнопки бота отправляют callback на каждый клик;
- `.tg-reply-quote` — у цитаты своё действие «перейти к оригиналу»;
- `button` / `a[href]` — любой прочий интерактив строки, включая кнопку «ответить» с собственным
  обработчиком.

Двойной клик мимо строк (по спейсеру, по разделителю дат) — тоже `'ignore'`: требуется попадание в
`.tg-line`.

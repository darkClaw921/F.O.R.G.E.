# parsePrompt

Разбор строки нижнего prompt'а трекера (tmux-web/static/js/tracker/parse.js).

Грамматика: !N приоритет 0..4, #тег (сколько угодно), ~2ч оценка (ч/h/час, м/m/мин, д/day; голое число — минуты), @список, due:HH:MM | ГГГГ-ММ-ДД | ГГГГ-ММ-ДДTЧЧ:ММ | today/tomorrow/сегодня/завтра. Остаток строки — заголовок.

Четыре зафиксированных решения: неизвестный токен ОСТАЁТСЯ в заголовке (C# в названии обязан выжить); токен — это целое слово (x!1 приоритетом не становится); повтор побеждает последним (!2 … !0 даёт 0); @список создаётся, если его нет (молча положить задачу в inbox значит выполнить не то, что написал человек) — сам вызов делает main.js, разбор возвращает только имя. Модуль чистый: ни DOM, ни fetch — полностью покрыт tests/frontend/tracker_parse.test.mjs.

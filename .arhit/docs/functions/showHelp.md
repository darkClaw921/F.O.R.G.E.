# showHelp

keynav.js — оверлей-шпаргалка со списком действующих комбинаций (класс .tg-keys-help внутри #telegram). Строится ЗАНОВО на каждый показ: пользователь мог переназначить клавиши в настройках, и закэшированная карточка врала бы. Группы и подписи берутся из keys.js::groupedRows, действие без клавиши (проигравшее конфликт) рисуется прочерком.

# refreshActive

chat.js (панель VK): ДОГОН открытой беседы — перечитывает свежую страницу истории и доклеивает пропущенное (forge-oy0c).

Зачем: лента открытой беседы живёт кадрами WS new_message, и кадр, которого не было, ей не восполняется ничем. Окна без кадров: фон вкладки (suspendVk РВЁТ соединение), обрыв связи, кадр resync. До forge-oy0c ни одна из веток историю открытой беседы не перечитывала, и сообщение появлялось только после ухода в другую беседу и возврата (это openDialog, то есть чтение по REST).

Как склеивает: страница VK — последние PAGE_SIZE сообщений. Есть пересечение с загруженным — новые доклеиваются через format.js::insertMessage, совпавшие по id ЗАМЕНЯЮТСЯ свежей версией. Пересечения нет — лента заменяется страницей целиком и взводится hasMore (дыру посреди истории показывать нельзя).

Прокрутка: решение принимается ДО перерисовки — стоял внизу, уезжает вниз к новому; читал историю, остаётся на прежнем scrollTop. Отметка о прочтении (local.onRead) уходит только когда лента прижата к низу И что-то добавилось.

Защиты: поколение (local.gen) отбрасывает ответ, если беседу успели переключить; local.loading не даёт наложиться на другую загрузку; лимитер 3 rps и коалесцер ключа history — общие с openDialog/loadOlder. Ошибки молчаливые (console.debug): это фоновое действие без пользовательского намерения.

Возвращает число добавленных строк. Зовётся из main.js: обработчик resync и обработчик кадра open при ПОВТОРНОМ подключении (local.everConnected). Подробности — на странице vk-catchup-open-dialog.

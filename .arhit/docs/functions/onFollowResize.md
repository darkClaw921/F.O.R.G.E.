# onFollowResize

onFollowResize() (tmux-web/static/js/telegram/chat.js, внутренняя) — колбэк ResizeObserver: строка досчиталась в высоте.

КОГДА СРАБАТЫВАЕТ: догрузилось медиа (картинка получила реальные размеры), подменился шрифт, бот перерисовал inline-клавиатуру и она заняла лишний ряд, изменилась ширина окна и текст перенёсся иначе. Это и есть закрытие требования «рост может произойти НЕ сразу»: одного доскролла в момент замены строки для таких случаев не хватает.

ЧТО ДЕЛАЕТ: перепроверяет живость следования через `followTarget(Date.now())`; если окно истекло — зовёт stopFollow() и выходит; иначе — scrollBlockIntoView(local.followRow).

ЗАЧЕМ ПОВТОРНАЯ ПРОВЕРКА СРОКА, ЕСЛИ ЕСТЬ ТАЙМЕР. Наблюдатель может пережить истечение следования на кадр: ResizeObserver доставляет колбэк на следующем кадре отрисовки, а таймер и часы расходятся при throttling фоновых вкладок и после сна машины. Поэтому срок стерегут ДВА независимых механизма — таймер (снимает наблюдение) и самопроверка здесь (не даёт «запоздалому» кадру дёрнуть ленту уже после отмены). Сценарий «запоздалое срабатывание наблюдателя после отмены» покрыт telegram_scroll_edge.test.mjs.

ЧЕГО НЕ ДЕЛАЕТ: не читает entries наблюдателя (какая именно строка изменилась — неважно, наблюдаемый узел ровно один — local.followRow) и не проверяет atBottom — раз следование живо, решение уже принято.

ГАРДЫ НИЖЕ ПО СТЕКУ: scrollBlockIntoView сам молчит при отсутствии $tgLog, при local.loading === true (идёт подгрузка истории вверх с якорем) и когда scrollTargetForRow вернул null (двигать не нужно / это было бы движением вверх).

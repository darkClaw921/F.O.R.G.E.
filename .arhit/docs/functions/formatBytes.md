# formatBytes

Человеческий размер файла (js/telegram/format.js): десятичные единицы (1000), одна цифра после запятой при v<10. Обрабатывает перекат тысячи при округлении: 999 950 Б без поправки давал «1000 KB» — toFixed() довершает перекат уже после выбора единицы, поэтому такой случай вручную переносится в следующую единицу (→ «1.0 MB»). null/undefined/пустая строка/отрицательное → пустая строка (неизвестный размер не рисуется как 0 B).

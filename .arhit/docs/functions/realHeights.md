# realHeights

`tmux-web/static/js/messenger/waveform-core.js` — высоты столбиков НАСТОЯЩЕЙ огибающей в пикселях.

Сигнатура: `realHeights(waveform) -> Array<number>`; пустой массив на входе даёт пустой
на выходе (вызывающий переключается на шум).

# Две неочевидные вещи

1. **Нормализация по максимуму самого массива**, а не по потолку шкалы (255): тихая
   запись иначе рисовалась бы полоской у самого низа карточки. `peak` берётся редьюсом,
   ноль подменяется единицей, чтобы не делить на ноль на полной тишине.
2. **Прореживание шагом `ceil(len / WAVE_BARS)`**: с бэкенда приходит до 200 отсчётов
   (`forge_voice::waveform::MAX_WAVEFORM`), а столбиков в карточке сорок.

Источник массива зависит от панели: VK — от API, Telegram — распаковка 5-битного
`DocumentAttributeAudio.waveform`, Битрикс — расчёт бэкендом через ffmpeg.

# replyAuthorLabel

tmux-web/static/js/telegram/reply.js

`replyAuthorLabel(reply, dialog?) -> string`

Имя автора оригинала для цитаты и для полосы ответа.

Опора на `out`, а не только на `sender`, обязательна: у СВОИХ сообщений в личке Telegram не
присылает отправителя вовсе (с layer 119 from_id в личных чатах отсутствует) — без этой ветки
собственная цитата осталась бы безымянной. Своё сообщение подписывается тем же ником, что и строка
в ленте (`you@local`), чтобы цитата и лог не расходились.

Недоступный оригинал без автора даёт ПУСТОЕ имя: рисовать «unknown» рядом с «сообщение недоступно»
значит сообщать одно и то же дважды.

`dialog` — фолбэк для постов от имени канала (там автора у сообщения нет, но есть название диалога).

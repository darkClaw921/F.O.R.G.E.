# hasHeat

view-core.js::hasHeat(matrix) → boolean — есть ли в матрице активности хоть одно ненулевое значение.

Нужна карточке «Когда вы работаете»: ровная карта нулей — валидное состояние (за период человек не писал), но передавать её в heatmap как данные нельзя. Карта равномерного цвета читается как равномерная активность, что прямо противоположно правде; вместо неё чарт должен показать заглушку «за период сообщений нет». Работает в паре с weekdayHourMatrix.

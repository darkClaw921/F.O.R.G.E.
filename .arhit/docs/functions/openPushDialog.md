# openPushDialog

Диалог переноса задачи в tasks/todo (tmux-web/static/js/tracker/to-todo.js).

Показывает подтверждение // COPY NODE → вкладка Tasks, колонка TODO: заголовок задачи, список корней (собран из открытых сессий tmux функцией collectRoots + вариант «корень активной сессии»), приписку про копию и кнопки CANCEL · PUSH ⏎.

Корень спрашивается потому, что задачи трекера ГЛОБАЛЬНЫЕ (в модели нет root_path), а TODO хоста живёт в корне проекта — сопоставить их автоматически нельзя. Выбранный корень запоминается в localStorage. Подтверждение создаёт карточку существующим POST /api/todos (описание собирает buildDescription: приоритет, статус, список, теги, оценка, срок, потрачено, чек-лист) и НИЧЕГО не меняет в трекере: это копия, таймеры и время остаются на месте. Крейт forge-tracker про TodoStore не знает вовсе — перенос целиком фронтовый.

# renderAll

dialogs.js — полная перерисовка колонки Telegram. Порядок: определить селектор активной папки (dirSelectorOf; если папка исчезла — откат на inbox), применить БЕЛЫЙ СПИСОК видимости из настроек (visibility.js::visibleDialogs), затем разбор по активной папке (dialogsForDir), разделение на узлы и каналы, отрисовка секции // DIRECTORIES, обоих списков и заголовка, восстановление счётчика онлайна и подсветки активного диалога.

Белый список и разбор по папкам — два независимых фильтра, их порядок на результат не влияет (пересечение коммутативно). Белый список стоит первым по смыслу: «этих чатов в devforge нет вовсе», а уже потом оставшееся раскладывается по папкам. Выключенный фильтр отдаёт список как есть.

# badgeUnread

main.js — непрочитанное для бейджа на кнопке ✈: без заглушённых, без архива и (с forge-c2dt) без чатов, скрытых белым списком настроек. Отдельно от format.js::unreadTotal СОЗНАТЕЛЬНО: та считает по переданному списку и используется ещё и для счётчика ~/archive, где архив как раз считать надо. Бейдж же обязан совпадать со счётчиком ~/inbox, иначе цифра на ✈ и цифра у ~/inbox расходятся ровно на непрочитанное в архиве — и пользователь ищет письмо, которого в ленте нет. По той же причине сюда добавлен белый список: бейдж не должен звать в чат, которого в колонке нет.

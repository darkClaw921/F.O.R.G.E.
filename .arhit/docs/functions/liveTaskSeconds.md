# liveTaskSeconds

Живое время задач панели трекера (tmux-web/static/js/tracker/timer.js).

Возвращает суммы секунд по задачам на текущий момент: к значениям task_seconds из снимка добавляется время идущих отрезков. Отсчёт ведётся ОТ ОПОРЫ — snap.now плюс разница монотонных клиентских миллисекунд, а не накоплением по тикам: накопление уезжает при заснувшей вкладке и при переводе часов. item_seconds — подмножество task_seconds (время пункта чек-листа входит в сумму задачи ровно один раз), складывать их нельзя.

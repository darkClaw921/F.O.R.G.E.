# startTicker

Общий секундный тикер панели трекера (tmux-web/static/js/tracker/timer.js).

ОДИН setInterval на всю панель, а не таймер на строку: он раз в секунду переписывает текст узлов [data-trk-task-time], [data-trk-item-time] и [data-trk-entry-time] и блок // RUNNING, не трогая остальную разметку. Благодаря этому время тикает во всех режимах сразу (лента, доска, карточка) бесплатно, а перерисовка ленты целиком — которая сбрасывала бы прокрутку и рвала drag — не нужна. Тикер запускается только когда есть хотя бы один идущий отрезок и останавливается вместе с уходом с вкладки (stopTicker), состояние видно из _debugTimerState().

# buildVisibilityForm

settings/telegram-visibility-tab.js — раздел «Видимость чатов» вкладки Telegram в модалке настроек. Тумблер telegram_filter_enabled, список папок аккаунта (плюс служебные ~/inbox и ~/archive) и список чатов с поиском; данные тянутся при первом показе из GET /api/telegram/folders и GET /api/telegram/dialogs?folder=all.

ВЫБРАННЫЕ, НО НЕ ЗАГРУЖЕННЫЕ ЧАТЫ. /dialogs отдаёт верхушку списка, а выбор может содержать чат, до которого руки не доходили полгода. Черновик хранит ВСЕ выбранные id, а не только нарисованные: иначе первое же открытие настроек молча вычёркивало бы такие чаты из белого списка. Они показываются отдельной группой («не в списке»), а вычистить их можно кнопкой «Убрать несуществующие» — нажимает её пользователь, а не форма за него.

Черновик живёт до Save: закрытая без сохранения модалка ничего не меняет. Save шлёт три поля (тумблер и оба списка целиком — семантика ПОЛНОЙ ЗАМЕНЫ, см. PatchUserSettingsReq) и дёргает window.ForgeApp.telegramFilter.refresh(), который сбрасывает кэш разбора, перерисовывает колонку и пересчитывает бейдж. Ошибка загрузки списков (плагин выключен, нет логина, not_connected) не теряет уже сохранённый выбор: он лежит в черновике и уйдёт обратно тем же составом.

Стили: .tg-visibility-* в static/css/settings-modal.css.

# runAction

keynav.js — выполняет действие по id. Возвращает true, только если действие реально что-то сделало: onKeyDown гасит событие (preventDefault + stopPropagation) исключительно по true, и ложное 'да' съело бы клавишу у соседних обработчиков, ничего не выполнив.

Диспетчер 19 действий: перемещение фокуса (focus.dialogs/log/input), контекстные nav.next/prev (чаты, лента или ряд кнопок бота — смотря где фокус), nav.activate, dialog.unread по кругу, dir.next/prev, msg.reply/quote/copy/buttons, log.bottom/older, ui.attach/theme/help/escape.

ВАЖНО про nav.activate и кнопки бота: если фокус УЖЕ на .tg-kb-btn, действие возвращает false и событие не гасится. <button> активируется Enter'ом силами браузера, и свой click() рядом с нативным мог бы отправить боту ДВА callback'а на одно нажатие (а у бота это бывает 'купить' или 'удалить'). Сами нажимаем кнопку только когда фокус на строке ленты: там приоритет — медиа, затем первая кнопка, затем цитата.

# clearFollow

clearFollow() -> boolean (tmux-web/static/js/telegram/follow.js) — снимает «следование» ленты Telegram за сообщением бота.

ПОВЕДЕНИЕ: обнуляет всё состояние модуля (dialogId='', messageId=0, untilMs=0). ИДЕМПОТЕНТНА — повторный вызов безопасен. Возвращает true, если следование действительно было живо (untilMs было ненулевым), иначе false; возврат нужен вызывающему, чтобы отличить «погасил» от «и так не следили» (в chat.js::stopFollow он пробрасывается наружу, а тесты по нему проверяют идемпотентность).

ВАЖНО: функция снимает ТОЛЬКО чистое состояние. Таймер истечения и ResizeObserver живут в chat.js, поэтому продуктовый код почти никогда не зовёт clearFollow напрямую — он зовёт chat.js::stopFollow, который гасит таймер, снимает наблюдение (unobserveFollowRow) и уже потом делегирует сюда. Прямой вызов clearFollow оставил бы висеть наблюдателя на строке.

КТО ГАСИТ СЛЕДОВАНИЕ (через stopFollow): истечение TTL по таймеру; ручная прокрутка вверх сверх FOLLOW_CANCEL_UP_PX (bindScroll); смена диалога (openDialog); удаление сообщения с кнопкой (onDeleted); переход к оригиналу по цитате (jumpToMessage); logout/сброс аккаунта (resetChat); уход страницы (teardownChat).

# groupByStatus

Чистая функция раскладки задач по колонкам доски forge-tracker (tmux-web/static/js/tracker/render-kanban.js).

Принимает уже отфильтрованную выборку задач (директория ~/today и соседи, выбранный список, выбранный тег — фильтрует filterTasks из render-list.js) и возвращает объект вида {inbox: [], today: [], doing: [], waiting: [], done: []}. Ключи берутся из COLUMNS, то есть из значений TaskStatus сервера.

Правила: внутри колонки порядок задаёт ручной order (sortTasks), а не приоритет и не done_at; пустая колонка присутствует в результате пустым массивом, а не отсутствует; задача с незнакомым статусом (стор новее фронта) уезжает в inbox, потому что потерянная задача хуже задачи не в той колонке.

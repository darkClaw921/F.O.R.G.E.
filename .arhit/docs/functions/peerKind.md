# peerKind

tmux-web/static/js/vk/format.js::peerKind(peerId) -> "user"|"chat"|"community".

Вид собеседника вычисляется ИЗ САМОГО ИДЕНТИФИКАТОРА, а не из загруженного DTO:
у VK peer_id < 0 — сообщество, peer_id >= 2000000000 — беседа, остальное —
пользователь (границы 1999999999 / 2000000000 / -1 закрыты тестом).

ПОЧЕМУ ЭТО ВАЖНО ДЛЯ БЕЛОГО СПИСКА. Кадр LongPoll может прийти по беседе,
которой нет в загруженной странице. Telegram в такой ситуации вынужден решать
консервативно (тип чата неизвестен), а VK решает ТОЧНО — тип выводится из id.
Поэтому фильтр по типам peer у VK работает и для неизвестных бесед, и это
единственное место, где панель VK строго сильнее телеграмной.

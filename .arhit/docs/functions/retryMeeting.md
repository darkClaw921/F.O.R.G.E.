# retryMeeting

Клиент POST /api/meet/meetings/:id/retry?from= в static/js/meet/api.js — повтор этапа пост-обработки. Допустимые значения from: transcoding, transcribing, summarizing (это as_str перечисления pipeline::run::Stage на бэкенде). Реализовано в Ф6, а не в Ф7 как значилось в первой редакции таблицы. Что разрешено, решает статус-машина по тому, что осталось на диске: из ready можно во все три этапа, из failed — только в transcoding/transcribing (транскрипта там нет по определению), из cancelled — никуда. Ответ 409 invalid_state означает «этап есть, но сейчас в него нельзя», 400 — «такого этапа не бывает», 409 whisper_unavailable/model_unavailable/metal_unavailable/summary_disabled — «не хватает окружения», и приходит он РАНЬШЕ 400, чтобы человек чинил окружение, а не опечатку.

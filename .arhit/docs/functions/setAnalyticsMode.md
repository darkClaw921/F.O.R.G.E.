# setAnalyticsMode

Переключает существующий полноэкранный экран между Агенты и Работа с Claude. По умолчанию выбран режим Агенты, последний выбор хранится отдельно в forge.analytics.mode. Смена инвалидирует старые запросы и выключает polling предыдущего режима; старые Claude-графики, API и собственные фильтры сохраняются. showAnalytics(range, mode) остаётся совместимым с прежним range аргументом и позволяет явно открыть нужный режим. hideAnalytics останавливает оба жизненных цикла. Режимы используют один общий back/Escape shell.

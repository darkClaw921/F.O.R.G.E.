# callbackRetrySecs

tmux-web/static/js/telegram/botkb.js — сколько секунд ждать до повтора нажатия.

Сигнатура: callbackRetrySecs(err) -> number; 0 означает «ждать не нужно».

Берётся err.retryAfterSecs (из заголовка Retry-After / поля retry_after_secs контракта ошибок),
округляется вверх и ограничивается 3600. Верхняя граница чисто косметическая: тикать сутки в
подписи кнопки бессмысленно — пользователь давно перезагрузит вкладку.

Число используется для обратного отсчёта ПРЯМО НА КНОПКЕ (.tg-kb-btn-wait). Автоповтора нет
принципиально: повторный запрос во время FLOOD_WAIT продлевает блокировку.

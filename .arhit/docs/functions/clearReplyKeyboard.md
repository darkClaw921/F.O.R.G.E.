# clearReplyKeyboard

tmux-web/static/js/telegram/botkb.js — спрятать полосу reply-клавиатуры, НЕ стирая состояние
диалогов.

Сигнатура: clearReplyKeyboard() -> void.

Зовётся из chat.js::openDialog при переключении чата: полоса чужого диалога обязана исчезнуть
немедленно, но запомненные клавиатуры ДРУГИХ диалогов должны пережить переключение — иначе
возврат в чат бота показывал бы пустое место до следующего сообщения.

Полный сброс (включая карту диалогов и таймеры обратного отсчёта) — resetKeyboards.

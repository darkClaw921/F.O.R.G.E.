# renderMemory

Асинхронно читает и рендерит выбранный источник памяти. Параметры: body, backBtn, общий backStack и modal{provider,path,revision,closed,controller}. Отменяет предыдущий GET и увеличивает revision. Claude получает path query активной сессии; Codex использует общий endpoint без path. Проверяет статус и JSON, отмену и устаревшую ревизию; сетевые ошибки показываются текстом внутри окна. После загрузки выводит notice при truncated, в том числе если все файлы пропущены. При отсутствии памяти показывает empty state без редактируемого выдуманного индекса. Claude традиционно имеет MEMORY.md; Codex рисует индекс только при index_name. Остальные Codex файлы группируются как автоматическая память memories/* и память субагентов agent-memory/*; путь dir показывается пользователю. Формирует ctx с фиксированным endpoint/revision для каждого редактора, затем подключает внутренние ссылки. После сохранения перечитывает только актуальный источник.

# safeUrl

tmux-web/static/js/telegram/botkb.js — белый список схем URL для кнопок ботов.

Сигнатура: safeUrl(raw) -> ?string. null означает «ссылка недопустима», кнопка станет
unsupported.

Разрешены РОВНО ТРИ схемы: http, https, tg. Всё остальное — включая javascript:, data:,
blob:, file: — отвергается.

КРИТИЧЕН ПОРЯДОК ОПЕРАЦИЙ: сначала вычистка управляющих и невидимых символов, ПОТОМ разбор
схемы. Браузер трактует "java\0script:" как javascript:, а наивная регулярка — как «схемы нет»
и пропустила бы такую ссылку в window.open, то есть дала бы XSS с правами вкладки.
Отвергаются также протокол-относительные "//evil.com" и "https:evil" (без //).

Применяется и к url кнопки (buttonAction), и к url в ответе бота (describeAnswer): «сервер
гарантирует, что это deep-link бота» — не повод доверять чужой стороне на клиенте.

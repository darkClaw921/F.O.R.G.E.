# telegramOwnsKeyboard

keynav.js — владеет ли вкладка Telegram клавиатурой прямо сейчас. Спрашивает static/hotkeys.js через window.ForgeApp.telegramKeys.owns(), чтобы решить, гасить ли свою vim-навигацию по сессиям (та занимает j/k/h/l/g/1/2/3/? глобально). Возвращает true только если панель видима (не hidden, оверлей логина закрыт), хоткеи включены настройкой И фокус либо внутри #telegram, либо нигде. Фокус в сайдбаре сессий означает 'не владеет' — иначе открытая вкладка Telegram отняла бы j/k у всего остального интерфейса.

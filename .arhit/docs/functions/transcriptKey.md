# transcriptKey

`tmux-web/static/js/messenger/voice-transcript-core.js` — ключ вложения для внутреннего индекса карточек расшифровки.

Сигнатура: `transcriptKey(plugin, dialogId, messageId, index) -> string`.

# ПОЧЕМУ ИМЯ ПЛАГИНА ВХОДИТ В КЛЮЧ ПЕРВЫМ

Две панели легко открыты на одной странице, и тройка «беседа 1, сообщение 1, вложение 0»
у них совпадает запросто. Без имени плагина кадр Telegram дорисовал бы карточку VK —
отказ, который в тестах на одной панели не воспроизводится никогда.

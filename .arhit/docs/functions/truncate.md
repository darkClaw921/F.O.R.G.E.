# truncate

Обрезка текста для тоста/превью (js/telegram/format.js). Схлопывает пробелы, режет до max символов с многоточием. Режет по code points (Array.from), а не по UTF-16-юнитам: slice() разрубал суррогатную пару emoji, оставляя одинокий суррогат «�» в тосте. Быстрый путь: строка короче лимита возвращается как есть.

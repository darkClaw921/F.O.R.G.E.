# maybeToast

main.js — тост о входящем сообщении. Гейты по порядку: своё сообщение не показываем; dialogRings (muted/archived из кадра сервера, с фолбэком на локальное знание); dialogShown — белый список видимости (forge-c2dt): спрятанный чат не должен дёргать уведомлением, и открыть его кликом по тосту было бы некуда; активный диалог на открытой вкладке; троттлинг 5 с на чат. Клик по тосту переключает на вкладку и открывает диалог; клик по кресту закрывает тост.

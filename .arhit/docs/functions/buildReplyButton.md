# buildReplyButton

tmux-web/static/js/telegram/chat.js (private)

`buildReplyButton(msg, dialog) -> ?HTMLElement` — кнопка «↰» на строке сообщения.

`<button>`, а не иконка на псевдоэлементе: действие обязано быть доступно с клавиатуры (таб) и
объявлять себя скринридеру (title + aria-label «Ответить: <ник>»). Появление по наведению — задача
CSS (`.tg-line:hover > .tg-reply-btn`, плюс `:focus-within`), и тем же правилом кнопка показывается
при фокусе.

Вставляется ПОСЛЕДНИМ потомком строки и позиционируется абсолютно: в потоке она разрывала бы
перенос текста и налезала на маркер «⋯ в пути» у неподтверждённых строк.

Кнопки НЕТ у строк без подтверждённого id (optimistic-отправка ещё в пути): Telegram отвергнет
ответ на несуществующий message_id.

Собственный обработчик клика вызывает startReply и делает stopPropagation, чтобы клик не всплыл в
делегированные обработчики ленты.

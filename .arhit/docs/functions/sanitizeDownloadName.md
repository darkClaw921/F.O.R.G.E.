# sanitizeDownloadName

Санитизация имени файла для сохранения на диск (атрибут download у <a>). Имя приходит от чужого Telegram-аккаунта — враждебный вход. Удаляет: сегменты пути (/ и \), C0- И C1-контролы (0x00-0x1F, 0x7F-0x9F → _), спецсимволы ФС (<>:"|?*), ведущие точки, а также bidi-override и невидимые символы (U+200B-200F, U+202A-202E, U+2066-2069, U+FEFF) — защита от спуфинга расширения через RTL-разворот (invoice\u202Efdp.exe читается как invoiceexe.pdf, оставаясь .exe). Обрезает результат до 255 байт UTF-8 (лимит ext4/APFS/NTFS) с сохранением расширения ≤16 байт, не разрывая code points (helper capUtf8Bytes). Пустой результат → fallback (download.bin). Закреплено тестами в telegram_format.test.mjs.

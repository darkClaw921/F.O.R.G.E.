# planOrder

Чистая функция пересборки глобального порядка задач forge-tracker (tmux-web/static/js/tracker/render-list.js).

planOrder(tasks, movedId, targetId, after) возвращает ПОЛНЫЙ список id всех задач снимка с перемещённой на новое место задачей — или null, если двигать нечего (нет соседки, соседки нет в снимке, соседка равна перемещаемой).

Зачем полный список. Порядок в трекере глобальный (поле order задачи), а видна всегда лишь выборка — лента одной директории или одна колонка доски. Сервер (POST /api/tracker/tasks/reorder) присваивает order по позиции в присланном списке и уводит недостающие id в хвост, поэтому отправка порядка одной лишь выборки молча перемешала бы невидимые задачи.

Общая для обоих режимов: ею пользуются и reorder() (перестановка строк ленты), и moveTask() (перенос карточки доски) в js/tracker/main.js. Покрыта tmux-web/tests/frontend/tracker_kanban.test.mjs.

# appBackgroundColor

Возвращает ВЫЧИСЛЕННОЕ значение CSS-переменной --bg приложения (getComputedStyle корневого элемента). Основа режима auto: глобального dark/light-флага в devforge нет, applyTheme просто расставляет переменные на :root. Пустая строка — штатный случай (стили ещё не применены), тогда resolveTgTheme берёт запасную тёмную тему.

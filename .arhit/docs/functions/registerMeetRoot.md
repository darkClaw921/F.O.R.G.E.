# registerMeetRoot

Регистрация ленты, кнопки которой надо перерисовывать по кадрам стора (messenger/meet-row.js). Регистрируется ЛЕНТА, а не кнопка: строки создаются и умирают сотнями, и подписка на каждую превратила бы прокрутку в утечку. Лент физически три, Set их дедуплицирует. Подписка на стор заводится ЛЕНИВО при первой регистрации и снимается в resetMeetRow — пережившая выгрузку подписка перерисовывала бы мёртвый DOM (этот дефект уже ловили в панелях VK и Битрикса). Тест держит инвариант: после ста пересборок ленты у стора РОВНО ОДИН подписчик.

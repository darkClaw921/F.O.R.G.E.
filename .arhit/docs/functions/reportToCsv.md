# reportToCsv

Сборка CSV сводки трекера (tmux-web/static/js/tracker/render-report.js).

Выгружает ровно то, что показано на экране сводки: строку периода, блок KPI, дни, списки и задачи. Разделитель «;», кодировка UTF-8 С BOM (иначе Excel читает кириллицу как мусор), время в колонке «Время» человеческое (Ч:ММ:СС) и рядом отдельная колонка целых минут — чтобы файл годился и для чтения глазами, и для формул. Пустой период файла не даёт вовсе. Скачивание идёт через Blob + createObjectURL, имя файла собирает csvFileName(win).

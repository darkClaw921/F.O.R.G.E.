# Ф16 forge-meet: фронт настроек облака — переключатели стадий, ключ, модели, баланс

Эпик forge-meet-f16-settings-ui-g3rtd. Бэкенд облака готов с Ф14-Ф15; здесь появилась половина, которую видит человек.

## Что сделано

| где | что |
|---|---|
| plugins/meet/src/routes/cloud.rs | НОВЫЙ: GET /api/meet/cloud/models и GET /api/meet/cloud/balance |
| plugins/meet/src/routes/mod.rs | оба роута в таблице-контракте и в build_router; планка разбора таблицы поднята с 19 до 25 |
| plugins/meet/src/cloud/mod.rs | TIMESTAMPED_STT_MODELS + stt_gives_timestamps |

| tmux-web/static/js/settings/meet-tab.js | переключатели стадий с живой подсказкой, поле ключа маской, списки моделей с ценами, строка остатка |
| тесты | settings_meet_tab.test.mjs (125 проверок), polza_stub.rs (+2 теста на роуты), meet_api_gate (25 роутов), meet_contract |

## Решения, которые стоит помнить

1. **Ключ не покидает сервер ни при каких условиях.** Каталог и баланс требуют Bearer-заголовка, поэтому ходит наш роут, а браузер видит только цифры. GET отдаёт ключ маской, а PUT с присланной обратно маской отвергается на бэкенде (config::apply_editable узнаёт MASK_CHAR); фронт вдобавок не отправляет такое значение вовсе — сравнения «значение не менялось» мало, потому что правка одного символа внутри маски оставляет её маской.
2. **Оба облачных роута отвечают 200 всегда.** Отказ — поле error. Вкладку настроек открывают тогда, когда что-то не работает, и роут, падающий вместе с polza.ai, отнял бы единственное место, где чинится ключ. Тот же принцип уже действует в облачном блоке GET /api/meet/status.
3. **Баланс НЕ встроен в статус.** Статус гейтит панель плагина целиком; второй сетевой вызов в чужой сервис внутри него подвесил бы встречи. Во вкладке остаток дозагружается отдельным промисом с catch уже поверх нарисованной формы.
4. **Цена берётся из top_provider.pricing.** Поля pricing верхнего уровня у записей каталога нет вовсе; наивный разбор не падает, а молча показывает «бесплатно». Во фронте отсутствие цены называет себя вслух («цена не указана»), а не превращается в ноль.
5. **Модель без таймкодов помечена в самом списке.** openai/whisper-large-v3-turbo втрое дешевле (0,048 против 0,432 руб/мин) и не даёт таймкодов вообще — атрибуция спикеров построена на пересечении интервалов и сломалась бы целиком. Флаг timestamps считает бэкенд, фронт его только рисует: третья копия имени модели разъехалась бы молча.
6. **Стадии независимы, обе по умолчанию облачные.** Любая из четырёх комбинаций допустима; умолчание cloud — прямое требование пользователя и менять его нельзя.

## Ловушки, на которые ушло время

- Инвариант герметичности (plugins/meet/tests/invariants.rs) узнаёт базу структуры ТОЛЬКО по началу выражения после двух точек: запись вида ..crate::testing::hermetic_config(dir.path()) он считает чужим конфигом и краснеет. Лечение — присвоить базу переменной base и писать ..base.
- Порядок MEET_ROUTES во фронте обязан ДОСЛОВНО совпадать с порядком строк таблицы в шапке routes/mod.rs: meet_contract сравнивает массивы, а не множества.
- Число роутов зашито ещё и в meet_api_gate.test.mjs (MEET_ROUTES.length), и в планке table.len() внутри routes/mod.rs.

## Расхождение задачи с исходниками

Задача Ф16.1 требовала: «пустое поле ключа означает не менять, а не стереть». В бэкенде Ф15 пустая строка — законное «убрать ключ» (config::apply_editable), и вкладка следует исходникам: нетронутое поле не отправляется вовсе (это и есть «не менять»), а осознанная очистка выключает облако. Подпись поля говорит об этом прямо.

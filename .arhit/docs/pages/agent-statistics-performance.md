Optimization round2026-10-28. Profiling the live Debug daemon identified agent ingestion availability and full folding as the dominant CPU paths; see [[forge-performance-baseline-2026-10-28]]. Implemented changes preserve configured sources,91-day default retention, polling cadence, cache version3 and indicator/task/usage semantics. SourceState now derives transient actual-owner IDs separately from parent polling links, recomputing only on cache load/contribution change/pruning. Idle ticks union cached IDs rather than serializing identities for every retained event. The full replay borrows source contributions using Cow, memoizes canonical session/profile encodings per fold and avoids a temporary parent-visited set for root events. Existing BTree key order, first-source selection, streaming maxima, cumulative/native suppression and interruption replay remain unchanged. Cache save serializes a borrowed source map and barrier slice instead of deep-cloning the complete metadata snapshot.

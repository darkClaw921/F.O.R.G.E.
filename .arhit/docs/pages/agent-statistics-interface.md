# Статистика агентов в Аналитике

Экран Аналитики имеет два самостоятельных режима. «Агенты» — режим по умолчанию для статистики CLI Codex, Claude, OpenCode и GitHub Copilot. «Работа с Claude» сохраняет прежнюю аналитику поведения человека и /api/analytics API. Параметр showAnalytics(range?,mode?), кнопки tablist и deep links выбирают режим; ?view=analytics&analyticsMode=claude ведёт явно в старую аналитику. Storage forge.analytics.mode и forge.agents.filters отделены от прежних forge.analytics.range/project.

## Компоненты и поток данных
agents/api.js адаптирует все /api/agents endpoints через существующий apiFetch с auth/remote/CSRF conventions. sessionId сохраняется точной JSONtuple строкой, bind/unbind передают её JSON body без преобразования. agents/core.js хранит provider names, безопасные formatters, периоды и generation-aware poller. agents/view.js создаёт сохраняемые filter controls и hosts live/history/settings; не пересоздаёт формы при poll. API и factories внедряются для тестов, production defaults всегда настоящие модули/API.

Видимый режим обновляет status/live/bindings каждые 2 секунды. status.profiles содержит полный исторический список профилей, отсутствующее поле старого remote имеет [] fallback. Периоды today/7/30/91/custom, provider/profile/project и pagination передаются серверу. today оставляет дневную границу серверу. Summary/projects/history повторно читаются при смене query/дня/updatedAtMs/runtime signature задач либо пока есть workingCount. Runtime signature включает состояния live/waiting/unknown, id/start/lastActivity, исключая nowMs; поэтому остановка/ошибка источника при неизменном file timestamp не оставляет историю в старом working состоянии.

hide/mode switch/document hidden останавливают poll и часы; generation guard игнорирует устаревшие ответы. Проверка isCurrent между стадиями fetch не выдаёт новые запросы history после скрытия. Настройки загружаются лениво только при раскрытии и никогда не перезапрашиваются каждым poll. Focus и drafts manual binding и settings сохраняются.

## Метрики и привязка
Live показывает workingCount, счётчики четырёх providers и строки working/waiting/unknown. Время вычисляется от server elapsedMs плюс монотонное локальное время после fetch, без предположения совпадения системных часов. Unknown не продолжает счёт. Inventory содержит безопасные pane/process кандидаты; linked aliases одной pane группируются. Ручная привязка и отвязка сохраняют exact sessionId, ошибки оставляют draft и активные retry controls. Успешная операция обновляет dashboard и sessions.

История включает KPI, дневные SVG charts tokens/cost/time, model/project разрезы и pagination. agentTimeMs — сумма длительностей агентов, wallTimeMs — объединение интервалов; показатели подписаны отдельно. Token total включает input/output/cacheRead/cacheWrite, reasoning показывается отдельно и повторно не добавляется. null tokens/cost — «Нет данных», а не ноль/NaN. Copilot может не сообщать tokens до shutdown всей сессии; пояснение показывает ограничение. Reported cost и API estimate разделены, partial estimate явно помечена. Нулевые, неизвестные и частичные цены не смешиваются, очень малая положительная стоимость отображается порогом, не фальшивым нулём. Theme/resize/show перерисовывают SVG.

## Настройки и индикаторы
Sources settings разрешают global enabled всех четырёх providers, discoverDefaults, additional roots provider/path/profile, historyDays, priceUpdates/priceUpdateUrl. Внутренние cache/config/price paths не редактируются. Root rows имеют постоянные labels «Агент», «Каталог журналов», «Папка профиля», natural mobile heights и input-aligned remove. Price date/source readonly; refresh использует сохранённый HTTPS URL. Ошибка config или price refresh сохраняет прежние значения/каталог. Sidebar generating tooltip сообщает elapsed/count/providers вместо terminal/hash/50-line эвристики; независимый orange attention не меняется. Настройки Аналитики имеют компактный live count и ссылку на полный agents режим, плюс прежний Claude блок. Modal lifecycle освобождает showcase polling на закрытии/смене вкладки.

Все пользовательские подписи выставляются textContent/DOM, source values не попадают в innerHTML. agents.css/history/settings используют существующие FORGE palette/fonts, focus-visible, responsive layout и не добавляют лишнюю анимацию. Native details/forms/select сохраняют клавиатурное поведение.

## Проверки
Node agent_stats_{core,live,view,history,settings}.test.mjs проверяют реальную business logic и actual DOM controllers с управляемыми API/timers: mode/filter lifecycle, полные профили, runtime cache invalidation, server clock, stale cancellation, binding drafts/errors, unknown/partial metrics, config lazy load/failed save/refresh, sidebar tooltip. Cargo agents_frontend_suite включает всё семейство agent_stats_*.test.mjs, отдельно проверяет обязательные файлы и node invocation. Старые analytics/settings/sidebar/PWA regression tests продолжают работать.

agent_stats_browser.test.mjs отдаёт production HTML/CSS/modules локальным static server и подключает тестовый fixture API probe. Собственный Chrome CDP запускается с временным профилем, встроенный Node WebSocket ожидает настоящие DOM assertions; dark/light/mobile screenshot artifacts создаются через Page.captureScreenshot. Тест проверяет mode/manual binding/hidden polling/settings/null/viewport, дополнительно captures раскрытой sources формы. Daemon пользователя, реальные CLI/LLM и журналы не запускаются. Приёмка включила реальные три Chrome варианта, Cargo frontend suites, backend replay четырёх providers и root cargo build --workspace; git diff --check чистый.

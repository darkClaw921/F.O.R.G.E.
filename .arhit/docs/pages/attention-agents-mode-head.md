Полоса фоновых агентов с заголовком-строкой режима (живой кейс 07.09.2026).

СИМПТОМ. Авто-апрув не срабатывал на разрешении MCP-инструмента, поднятом
агентом workflow (`Tool use · from the "apistend-research" workflow` →
`❯ 1. Yes / 2. Yes, and don't ask again for … / 3. No`). Свечение по этой
сессии тоже не загоралось.

ЧТО ОКАЗАЛОСЬ НИ ПРИ ЧЁМ (проверено на живой панели):
* классификация — `classify_prompt` даёт `Permission3`, `decide` даёт
  `Press("2")` при `auto_approve_broad = true`;
* блоклист — у пользователя пуст, `is_dangerous` = false;
* необычный заголовок `Tool use · …` — на детекторы формы не влияет;
* нестабильность панели — хвост не менялся между тиками.

ПРИЧИНА. `attention::agents_widget_start` считал заголовком полосы фоновых
агентов ТОЛЬКО строку `⏺ main`. В 2.1.26x полоса, поднятая агентами workflow,
рисуется без неё: над строками `◯ <агент>  <задача>` идёт сама строка режима
со счётчиком — `⏸ plan mode on · 1 shell · ← 2 agents` (или `⏵⏵ auto mode on
… · ← 2 agents · /diff to hide diff`). Полоса не срезалась, footer prompt'а
уезжал за окно из четырёх хвостовых непустых строк, и `prompt_at_bottom`
отвечал `false`. Замер на реальной панели сессии `main` (apistend):
`agents_widget_start = None`, `prompt_at_bottom = false`,
`detect_claude_prompt = false` — то есть молчали ОБА потребителя гейта.

ЛЕЧЕНИЕ. `is_agents_head` принимает заголовком и строку режима, но только со
счётчиком агентов: строка режима без слова `agents` — обычный статус-бар, и
срезать его нельзя, иначе за виджет принимается любой низ экрана и
процитированный в diff'е prompt снова становится «нижним». Требование «под
заголовком уже нашлась хотя бы одна строка `◯`» сохранено.

Тесты: `the_agents_strip_is_trimmed_when_the_mode_line_heads_it` (фикстура —
дословный хвост живой панели) и `a_mode_line_without_agents_is_not_a_widget_head`
(защита от среза обычного статус-бара). Мутационно проверено: возврат старого
условия роняет первый тест.

Это третий случай одного класса: TODO-виджет (2026-08-12), полоса агентов с
`⏺ main` (2026-08-28) и теперь полоса со строкой режима. Общее правило: любой
блок, который Claude Code рисует ПОД prompt'ом, выталкивает footer из окна
гейта, и каждый такой блок приходится учить срезать отдельно.

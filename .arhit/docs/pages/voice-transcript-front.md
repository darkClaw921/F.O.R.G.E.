# Текст расшифровки под голосовым (ГС-Ф5)

Общий фронт-модуль `tmux-web/static/js/messenger/voice-transcript-core.js` и три тонких подключения.

## Где что лежит

| файл | роль |
|---|---|
| `static/js/messenger/voice-transcript-core.js` | вся логика: состояния, разметка, кадры, запросы |
| `static/js/vk/media.js` | инстанс `voiceTranscript` (`vk-voice`), `attach` из `buildMediaCard`, объявление `VOICE_FRAME_EVENT` |
| `static/js/telegram/media.js` | то же, префикс `tg-voice`, индекс всегда 0 (вложение в сообщении одно) |
| `static/js/bitrix/media.js` | то же, префикс `b24-voice`, `attach` в `renderMediaGroup` рядом с `wireCard` |
| `static/css/{vk,telegram,bitrix}.css` | стили блока на токенах панели, без единого литерала цвета |

Имя DOM-события объявлено в `media.js` каждой панели, а `main.js` его переэкспортирует: карточку рисует media.js, и обратный импорт замкнул бы цикл.

У Bitrix подключение живёт в `media.js`, а НЕ в `attachments.js`, который строит саму разметку: attachments.js не делает ни одного запроса и не вешает ни одного обработчика — ровно поэтому он проверяется в голом Node.

## Что решено и почему

* **Блок только у звука** (`voice`, `audio`, `voice_message`, `audio_message`) — то же множество, что у авторазбора Ф4.
* **Ничего не запускается само.** GET читает уже посчитанное с диска, POST делает только нажатие. Автоматический разбор входящих — дело бэкенда (Ф4) и своего тумблера.
* **Сотня голосовых не даёт сотни запросов**: наблюдатель видимости, а без него — потолок 12 запросов на пачку отрисовки.
* **Причина отказа — по коду**, а не по тексту кадра: в тексте хвост stderr движка с путями до бинарей.
* **Сворачивание рисованное**: в DOM всегда полный текст, обрезает CSS (`-webkit-line-clamp`).

## Живая проба

`tests/frontend/voice_transcript_live.test.mjs` поднимает статический сервер и гоняет карточку в headless Chrome for Testing: `isConnected`, настоящий line-clamp, ширина полосы, фокус кнопок, контраст в тёмной и светлой теме. Нет браузера — пропуск, а не падение.

Именно эта проба нашла дефект, невидимый на фейковом документе: модуль выбрасывал ещё не вставленную в документ карточку как «отцепленную», и расшифровка не появлялась на экране никогда. Два грабля мимоходом: `spawnSync` блокирует цикл событий Node и сервер не принимает соединений; `--user-data-dir` заставляет Chrome for Testing на macOS молчать в `--dump-dom`.

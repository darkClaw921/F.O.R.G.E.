# Название чата в панелях мессенджеров: имя + приглушённый @ник

Приёмка пользователя: «пусть что в телеграмм плагине что в вк ники
пользователей будут второстепенными, а мы должны показывать в названиях чатов
имена — например сначала пишется его имя фамилия как сейчас при наведении, а
потом его ник немного серым».

## Что было

Строка списка и шапка сессии показывали ТЕРМИНАЛЬНЫЙ СЛАГ `slugName`:
`ivan_petrov@node` / `durov@node`. Слаг приводил имя к нижнему регистру и
сжимал в `_` всё, что не `[a-z0-9_.-]`, а пустой результат заменял на `anon`.
Следствия:
  * кириллическое имя гибло целиком: «Иван Петров» -> `anon@node`, «Тестовое
    сообщество» -> `anon@club`;
  * при отсутствии username слаг лепился ИЗ ИМЕНИ, и рядом с именем стояло то
    же имя, только испорченное;
  * настоящее имя жило только в подсказке при наведении (`li.title`).

## Что стало (обе панели, две честные копии)

  * `format.js::displayName(d)` — имя КАК ЕСТЬ: title -> '@'+username -> id ->
    'anon'. Юникод не трогается (кириллица, emoji, флаги, ZWJ-графемы),
    единственная правка — схлопывание пробелов ради однострочной шапки.
    Обрезки по символам нет: длину режет CSS (ellipsis), обрезка по кодовым
    точкам рвала бы суррогатные пары.
  * `format.js::displayNick(d)` — '@ник' либо ПУСТАЯ строка. Нет username —
    нет приписки. Пустой title — ник уже стал именем, и вторым не повторяется.
  * `format.js::sessionHeadParts` -> `{name, nick, tail}`; `sessionHeadText`
    склеивает части и остаётся единственным описанием формы шапки.
  * `dialogs.js::buildRow` — узлы `.tg-dialog-title` / `.tg-dialog-nick`
    (`.vk-*` соответственно); узла ника нет вовсе, когда ника нет.
  * `dialogs.js::tooltipText` — подсказка «Имя (@ник)» либо только имя: имя
    видно всегда, и дублирующая подсказка была бы шумом.
  * `chat.js::updateHead` собирает шапку ИЗ УЗЛОВ (`.tg-session-nick` /
    `.vk-session-nick`), textContent при этом совпадает с sessionHeadText.
  * `slugName`, `KIND_SUFFIX` удалены в обеих панелях; `SLUG_MAX` остался
    только в Telegram — его использует `folderSlug` (пункт `// DIRECTORIES`
    это «путь» в терминальной метафоре, а не имя человека).

## Раскладка

`.tg-dialog-name` / `.vk-dialog-name` — флекс с явным порядком жертв: метки
[BOT] и [M] не ужимаются (`flex-shrink: 0`), ник ужимается первым
(`flex: 0 200 auto`), имя — последним и получает ellipsis. Счётчик
непрочитанного во второй строке и под давление не попадает. Шапка сессии
осталась однострочным блоком: она жертвует хвостом (⌁ PACKETS · ◇ KEY), а не
именем.

## Контраст

В VK токен `--v-faint-text` (#7885A0) уже был корректным. В Telegram
`--t-faint-text` был объявлен как `var(--t-grn-faint)` — цветом РАМОК, 1.29 –
1.59:1. Стал #708373 (4.97 / 4.87 / 4.75 к --t-bg / --t-panel / --t-bar) при
яркости не выше --t-grn-dim. Для подсвеченной строки заведён
`--t-faint-text-hi` (#7A8B77, 4.50:1 к --t-active): под курсором имя красится
--t-grn, поэтому потолок иерархии там поднимается вместе с фоном.

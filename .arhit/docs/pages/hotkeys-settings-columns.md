Настройки горячих клавиш: раскладка строк по колонкам (forge-9gsr)

ПРОБЛЕМА. В модалке настроек (вкладки Telegram / VK / Битрикс24, форма js/settings/hotkeys-tab.js) строка действия была flex-контейнером: название (flex: 1 1 auto) — кнопка комбинации (min-width: 104px) — кнопка сброса — примечание. Из-за этого ширина кнопки с комбинацией зависела от длины названия действия и от того, есть ли в ЭТОЙ строке примечание: у одних строк примечание было, у других нет, и клавиши вставали «лесенкой». Читать таблицу глазами было тяжело — колонки не выравнивались по вертикали.

РЕШЕНИЕ. Строка .tg-hotkeys-row переведена с flex на CSS Grid с фиксированным шаблоном из ЧЕТЫРЁХ колонок:

  grid-template-columns: minmax(0, 1.4fr) 140px 26px minmax(0, 1fr);
  /* действие | клавиша | сброс | примечание */

Шаблон одинаков для всех строк таблицы, поэтому каждый элемент стоит строго в своей колонке независимо от длины соседей. Заголовки групп (.tg-hotkeys-group) остаются обычными блоками между строками и сетку не ломают — grid объявлен на строке, а не на таблице.

Сопутствующие правки CSS (static/css/settings-modal.css):
  • .tg-hotkeys-title — убран flex: 1 1 auto, оставлены min-width: 0 и обрезка многоточием;
  • .tg-hotkeys-combo — width: 100% / min-width: 0 вместо min-width: 104px: ширину теперь задаёт колонка, кнопка её заполняет, и все клавиши получаются одной ширины;
  • .tg-hotkeys-reset — justify-self: center вместо flex: 0 0 auto;
  • .tg-hotkeys-hint и .tg-hotkeys-warn — общая четвёртая колонка, обе с min-width: 0 и обрезкой многоточием (раньше warn не обрезался и мог распирать строку).

ПУСТАЯ ЯЧЕЙКА ПРИМЕЧАНИЯ — ключевой инвариант. В render() формы четвёртый span создаётся ВСЕГДА: если конфликта нет и hint пустой, это пустой span.tg-hotkeys-hint. Без него строка без примечания имела бы три ячейки, и grid по-прежнему выравнивал бы её сам, но добавление/снятие конфликта дёргало бы разметку; явная пустая ячейка делает структуру строки постоянной. Полный текст примечания дублируется в атрибуте title — он обрезается многоточием.

УЗКИЙ ЭКРАН (@media max-width: 560px). Шаблон сокращается до трёх колонок (действие | клавиша 132px | сброс), примечание уезжает на свою строку через grid-column: 1 / -1 и переносится по словам; пустая подсказка скрывается (.tg-hotkeys-hint:empty { display: none }), чтобы не оставлять пустую полосу под каждой строкой. Колонки клавиши и сброса при этом не двигаются — вертикальное выравнивание сохраняется и на мобильном.

ОБЛАСТЬ ДЕЙСТВИЯ. Форма одна на три панели (см. [[buildHotkeysForm]]), CSS-блок тоже один, поэтому правка чинит вкладки Telegram, VK и Битрикс24 разом. Точек правки по-прежнему две: js/settings/hotkeys-tab.js и блок .tg-hotkeys-* в css/settings-modal.css.

Resolved two independent causes of intermittently absent agent tab stars. First, Codex0.164 separates TUI and shared managed app-server: TUI argv/FD have no native session ID while a background server launched by the first TUI owns many unrelated journals. Exact matching now inventories controlling TTY plus ancestry, excludes managed services from pane ownership, and queries native explicit threads.name with canonical cwd from read-only WAL-aware state_N.sqlite against transient pane titles. Braille spinner only strips title decoration; task state still comes from events. Duplicate titles or profiles, missing schemas and failed probes remain unbound instead of guessing by cwd. Titles/prompts are never persisted or returned. Second, same-cadence attention and journal refreshes could lose discovery requests whenever try_lock was busy, leaving resumed historical files unindexed indefinitely. Discovery is latched until successful ingestion and retries on error; refresh updates retained descriptor timestamps so resumed files get recent-file priority. Regression tests cover contention, resumed log prioritization, profile/title ambiguity, WAL-only rows, controlling TTY and managed-service exclusions. Changes preserve provider task timers, explicit completion semantics, manual binding and original Claude Analytics.

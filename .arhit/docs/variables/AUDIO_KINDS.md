# AUDIO_KINDS

`tmux-web/static/js/messenger/voice-transcript-core.js` — виды вложений, у которых бывает расшифровка:
`['voice', 'audio', 'voice_message', 'audio_message']`.

Четыре слова, а не одно, потому что лексика у трёх панелей разная, а фронт-модуль —
общий. Список — фронтовый близнец `forge_voice::gate::VOICE_KINDS` на бэкенде; расходятся
они молча (карточка просто не получит блока расшифровки), поэтому пополнять их надо
парой.

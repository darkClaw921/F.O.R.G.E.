# EAGER_FETCH_BUDGET

`tmux-web/static/js/messenger/voice-transcript-core.js` — потолок запросов готового текста на одну пачку отрисовки: **12**.

Действует ТАМ, ГДЕ НЕТ `IntersectionObserver` (фейковые документы тестов, старые
окружения). С наблюдателем текст подгружается только для карточек, попавших в экран; без
него модуль вынужден спрашивать заранее — и без потолка отрисовка ленты из двух сотен
голосовых дала бы две сотни параллельных запросов одним кадром.

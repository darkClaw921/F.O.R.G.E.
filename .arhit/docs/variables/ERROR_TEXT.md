# ERROR_TEXT

`tmux-web/static/js/messenger/voice-transcript-core.js` — человеческие причины отказа ПО КОДУ (таблица `код -> текст`).

# ГЛАВНОЕ: ТЕКСТ ОШИБКИ С БЭКЕНДА СЮДА НЕ ПОПАДАЕТ ВОВСЕ

В поле `message` кадра `voice_transcribe_error` лежит хвост stderr движка, пути до
бинарей и обрывки конфигурации. Человеку в ленте это не нужно, а показывать пути и тем
более следы ключей — прямой вред. Поэтому фронт печатает текст исключительно по коду.
Кадр `error` несёт `code` ОТДЕЛЬНО от `message` именно ради этого разделения.

# ПОЛНЫЙ СПИСОК КОДОВ (контракт `forge_voice::VoiceError::code`)

| код | текст человеку |
|---|---|
| `voice_not_audio` | Это вложение не звук — расшифровывать нечего. |
| `voice_too_long` | Запись слишком длинная для расшифровки. |
| `voice_no_ffmpeg` | Не установлен ffmpeg — звук нечем подготовить. |
| `voice_no_whisper` | Локальный движок расшифровки не установлен. |
| `voice_no_model` | Модель локального движка не загружена. |
| `voice_no_key` | Не введён ключ облака расшифровки. |
| `voice_busy` | Сейчас идёт другая расшифровка — попробуйте через минуту. |
| `voice_config` | Настройки расшифровки не читаются. |
| `metal_unavailable` | Локальному движку нужен GPU — включите облако в настройках. |
| `not_authorized` | Панель не подключена. |
| `not_connected` | Нет связи с сервером мессенджера. |
| `no_media` | Файл голосового не удалось получить. |

Текст `metal_unavailable` — единственный, который ПРЕДЛАГАЕТ ВЫХОД: правило проекта
запрещает считать локальную модель на процессоре, и без подсказки про облако человек
упёрся бы в тупик. Коды, которых здесь нет (например облачные `cloud_no_funds`),
показываются как `ERROR_FALLBACK`.

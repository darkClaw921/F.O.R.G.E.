# MEET_BTN_CLASS

Общий класс кнопки — по нему её находит перерисовка и красит `css/meet.css`. Второй класс у кнопки панельный (`tg-meet-btn`/`vk-meet-btn`/`b24-meet-btn`) — им панель управляет ВИДИМОСТЬЮ в своей палитре и своих правилах наведения. Разделение не косметическое: механика показа у панелей разная (у Телеграма и VK кнопка гасится сама, у Битрикса — вместе с контейнером), а вид общий.

# providers

Конфигурация двух источников модалки памяти: claude и codex. Содержит endpoint GET/PUT, label кнопки, scope-подпись и текст отсутствующей памяти. Claude использует проект активной tmux-сессии; Codex — общую память профиля и каталоги субагентов, без обещания изоляции по проекту. Значения фиксируются в renderMemory на ревизию: позднее сохранение не может записать в endpoint нового выбранного источника.

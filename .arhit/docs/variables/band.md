# band

chart.js::band — восьмой тип SVG-кита аналитики: тонкая полоса категорий по корзинам ряда.

Сигнатура: band(container, {labels: string[], values: Array<string|string[]>}, opts) → {update, redraw, svg} (создаётся через chartFactory, как остальные чарты кита).

Назначение — чарт 13 плана «версии Claude Code по дням»: важен не размер величины, а МОМЕНТ смены категории. Поэтому у полосы нет ни оси Y, ни подписей значений.

Правила отрисовки:
- Один тон (--accent) со ступенями непрозрачности 0.3..1.0 по порядку ПЕРВОГО появления категории. Палитра из пяти цветов здесь не годится: в живом архиве за квартал 35 версий CLI — цвета по кругу дают конфетти, а «пять цветных плюс серое остальное» превращает полосу в серую ленту, где смен не видно вовсе.
- Корзина без категории — нейтральная заливка --border с прозрачностью 0.35 и подсказкой «версия неизвестна»; пропускать её нельзя, дыра читалась бы как «этого дня не было».
- Несколько категорий в одной корзине (день обновления) делят ячейку по вертикали, подсказка перечисляет все.
- Крайние категории периода подписаны по краям полосы, даты смен — снизу с минимальным зазором 44 px (подписи внахлёст читаются хуже, чем их отсутствие).

opts: emptyText, formatX (по умолчанию formatDay), neutralLabel, color. Тесты — analytics_chart.test.mjs (три обязательных состояния плюс отдельный блок про 12 версий: ступени непрозрачности, отсутствие серого у дней с версией, подписи только крайних).

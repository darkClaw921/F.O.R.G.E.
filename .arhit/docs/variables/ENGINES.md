# ENGINES

`tmux-web/static/js/settings/voice-tab.js` — значения селекта движка расшифровки, в порядке показа:
`local` — «Локально (whisper.cpp на GPU)», `cloud` — «Облако (polza.ai)».

Подписи называют вещи своими именами намеренно: «Локально» без упоминания GPU скрывало бы
от человека, что без Metal расшифровки просто НЕ БУДЕТ (прогон, не доказавший GPU,
убивается), а «Облако» без имени сервиса — что звук уезжает наружу и стоит денег.
Значения проверяются на бэкенде `forge_voice::settings::parse_engine`.

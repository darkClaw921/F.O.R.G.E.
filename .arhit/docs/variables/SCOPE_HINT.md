# SCOPE_HINT

Подпись блока выбора бесед авторазбора (tmux-web/static/js/settings/voice-tab.js) — ОДНА на три панели.

Текст: «Пока ничего не выбрано, разбираются голосовые ВО ВСЕХ беседах. Отметьте нужные — и авторазбор ограничится только ими. Беседы, скрытые белым списком видимости, не разбираются в любом случае.»

Почему подпись обязательна: пустой список означает «во всех беседах», а белый список, который человек ни разу не открывал, читается ровно наоборот — как «ничего не выбрано, значит ничего и не разбирается». Молчаливое расхождение здесь стоило бы человеку уверенности в том, что фича вообще включена. Второй половиной подпись честно называет вышестоящий фильтр: видимость сильнее скоупа.

Рядом в том же модуле живёт SHARED_HINT — подпись под селектом движка («движок общий для всех мессенджеров»).

# VK_VOICE_CONFIG

`tmux-web/static/js/settings/voice-tab.js` — конфиг секции «Голосовые сообщения» для панели VK.

Поля: `key: 'vk'`, `enabledKey: 'vk_voice_autotranscribe'`, `toggleClass: 'vk-voice-auto'`,
`hint` — текст под заголовком. Подсказка VK отдельно оговаривает, что беседы, скрытые
белым списком видимости выше, не разбираются, и свои исходящие — тоже.

# ПОЧЕМУ `api` НЕ В КОНФИГЕ

Сетевые функции передаются в `buildVoiceForm` ССЫЛКАМИ, а не строкой пути: адреса живут в
`js/vk/api.js`, и контрактные тесты сверяют их с таблицей роутов плагина. Путь, собранный
здесь, эту сверку молча обошёл бы.

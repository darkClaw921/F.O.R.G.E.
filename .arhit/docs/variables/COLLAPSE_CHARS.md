# COLLAPSE_CHARS

`tmux-web/static/js/messenger/voice-transcript-core.js` — сколько символов расшифровки показывается несвёрнутыми: **320**.

Пятнадцатиминутное голосовое — это лист текста, и развёрнутым он выдавливает из ленты
всё остальное. Порог выбран так, чтобы обычное «ага, буду в семь» не сворачивалось
никогда: сворачивание короткой реплики — это лишнее нажатие на ровном месте.
Само сворачивание в разметке делает `-webkit-line-clamp`; проверить его можно только в
настоящем браузере (`clientHeight < scrollHeight`), фейковый документ здесь слеп.

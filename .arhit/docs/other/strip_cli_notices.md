# strip_cli_notices

auto_approve::strip_cli_notices(region) (tmux-web/src/auto_approve.rs) — убирает из текста запроса подсказки и предупреждения самого Claude Code перед отправкой в LLM-эскалацию блоклиста. Маркеры (CLI_NOTICE_MARKERS, регистронезависимо): 'tip:', 'auto mode handles these prompts', 'cannot be auto-allowed', 'approve only if you trust', 'can pick up untrusted hooks', 'manual approval required'. Зачем: эти строки не часть команды, но читаются моделью как довод против — живьём 'Approve only if you trust it' и 'find with -exec … cannot be auto-allowed' склоняли Sonnet к approve=false на безобидной сборке релиза, причём НЕСТАБИЛЬНО (один экран то проходил, то нет). Блоклист (is_dangerous/danger_scope) по-прежнему смотрит на текст ЦЕЛИКОМ — сужать ему область незачем.

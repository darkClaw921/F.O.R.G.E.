# restoreRecords

tmux-web/static/js/home/home.js — приватный (не экспортируемый) хелпер: восстанавливает пачку записей истории. В цикле POST /api/sessions/history/restore {name, path}; 409 (имя занято) — мягкая ошибка, не прерывает цикл. Возвращает {firstOk: имя первой успешно восстановленной сессии|null, failed: [имена не восстановленных, кроме 409]}. НЕ трогает UI (fetchSessions/openSession/alert) — это делают вызывающие restoreSelected (мультивыбор) и restoreDay (группа-день). Выделен, чтобы устранить дублирование цикла между этими двумя функциями.

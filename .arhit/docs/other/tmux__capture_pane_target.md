# tmux::capture_pane_target

tmux-web/src/tmux.rs — захват видимой части КОНКРЕТНОЙ панели: 'tmux capture-pane -p -J -t <session>:<win.pane>'.

pane — суффикс из list_claude_pane_targets; пустая строка = активная панель сессии. В остальном идентична capture_pane (флаг -J склеивает перенесённые tmux строки; отсутствующая сессия/панель/окно → Ok("")), отличается только адресацией: capture_pane всегда смотрит активную панель активного окна и потому не видит prompt в фоновом окне.

Используется воркером auto_approve::run по каждой панели каждой сессии.

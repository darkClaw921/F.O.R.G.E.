# agents::summary::summary

Build a filtered historical AgentSummary from AgentIndex without filesystem IO or mutations. Accepts validated local-date range, optional provider/profile/full project path, and day/week bucket; price metadata and update timestamp are supplied by the store. Started tasks count on start day, completed/aborted count on end day. agentTimeMs uses summed per-task duration clipped proportionally to the range; wallTimeMs uses the union of clipped real intervals. Live working tasks can accrue to now; waiting and unknown tasks stop at lastActivityAtMs. Incomplete tasks are counted explicitly and never classified as successful. Usage records independently contribute requests, nullable token counters and separate estimated/reported cost, with conservative unknownTokenRequests and unpricedRequests. Model IDs include provider; project IDs are full canonical directories. Queries preserve unknown data and do not manufacture zero spend.

# new_random_id

plugins/vk/src/api/methods.rs. Положительный i32 из младших бит Uuid v4 — идентификатор ЛОГИЧЕСКОЙ отправки для messages.send. Крейт rand ради этого не заводится. Ноль исключён: у VK random_id=0 означает «дедупликацию не делать». Вызывать РОВНО ОДИН РАЗ на отправку: VK дедуплицирует повтор с тем же random_id и возвращает тот же message_id, поэтому транспортный ретрай обязан нести прежнее значение — иначе собеседник получит два сообщения (тест transport_retry_reuses_random_id).

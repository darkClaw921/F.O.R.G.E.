# tmux::resolve_target

tmux-web/src/tmux.rs — приватный общий резолв tmux-target для доставки ввода в сессию. Возвращает '<session>:<win>.<pane>' (панель с Claude CLI по find_claude_pane) либо '<session>:' — активная панель, если Claude-панель не найдена или tmux вернул ошибку (ошибка логируется warn'ом).

Завершающее двоеточие обязательно: без него tmux резолвит числовое имя сессии (например '8') как номер окна текущей сессии — тот же баг, что чинился в capture_pane.

Используется send_keys и send_key.

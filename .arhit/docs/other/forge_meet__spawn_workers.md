# forge_meet::spawn_workers

Запускает фоновую часть плагина: открывает SQLite, гоняет миграции, ставит пробы внешних бинарей (ffmpeg, ffprobe, whisper, Chrome, модель) отдельной задачей, выполняет reconcile_on_boot по незакрытым записям и заводит ретенцию. Возвращается быстро — ждать проб не обязан никто, кроме пайплайна, который делает это сам. Без внешних бинарей отрабатывает штатно: плагин обязан стартовать на машине, где не установлено ничего.

# agent-workers-startup

main creates AgentStatsStore with private default configuration and AgentRuntime with no CLI ownership. Ingestion starts in background batches and runtime observes exact process/pane evidence every2s even when Analytics is closed. Discovery every30s and configured price updates use independent background flows, so neither HTTP startup nor live tracking waits on full archive or price network IO. On graceful shutdown the recurring ingestion/runtime tasks are aborted and AgentStatsStore::flush persists the latest valid normalized cursor snapshot. Worker code never starts an LLM or calls paid account APIs. Tests use discoverDefaults=false and temporary paths, with deterministic offline grace/local Bash/reply projections, coalesced HTTP rebuild admission and flush-after-append regression.

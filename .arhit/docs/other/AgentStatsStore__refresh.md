# AgentStatsStore::refresh

Serialized incremental journal refresh shared by indexing and attention workers. A discover=true call first latches an atomic discovery request, even when try_lock finds the ingestion gate busy. The next successful refresh, including a normal discover=false attention tick, consumes that request and executes discovery; coordinator errors restore the request for retry. This prevents synchronized two-second workers from silently dropping every thirty-second discovery and missing new journals or resumed historical sessions. Concurrent requests received during an active pass stay queued for the following pass. Discovery refreshes modification metadata of existing source descriptors before prioritizing reads, while ordinary passes inspect pending, recent, and open-session logs. Published snapshots remain coherent and previous source contributions survive individual read errors. Regression contended_discovery_is_retried_by_next_tick_and_finds_resumed_old_logs holds the gate, requests discovery, releases the gate, and verifies that the next ordinary tick finds both a resumed two-day-old session and a new journal.

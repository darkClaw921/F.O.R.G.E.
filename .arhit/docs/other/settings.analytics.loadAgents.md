# settings.analytics.loadAgents

Независимо обновляет компактный счётчик текущих основных агентов через инъецируемый getAgentLive. Работает только для не disposed и подключённого host при видимой browser tab, предотвращает дубли медленного запроса через agentLoading. После успешного ответа показывает workingCount; при ошибке оставляет прежний count и сообщает об отказе обновления. Единственный timeout повторяет запрос через 2 секунды. dispose и visibilitychange снимают таймер и не дают позднему ответу его восстановить.

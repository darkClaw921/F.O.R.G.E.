# write_bytes_atomic

plugins/chat-analysis/src/atomic.rs (переехала из plugins/vk/src/config.rs при выносе ядра анализа, эпик forge-caport-1a-4fwj). ЕДИНАЯ точка атомарной записи приватного файла плагина-мессенджера: create_dir_all родителя -> запись во временный файл рядом (tmp_path_for: .<имя>.<pid>.tmp, права 0600 выставляются ДО первого байта) -> fsync -> rename на целевой путь -> повторный set_owner_only (rename сохраняет права tmp, но целевой мог существовать раньше с более широкими). При ЛЮБОЙ ошибке временный файл удаляется, целевой остаётся прежним — частичного состояния на диске не бывает. Ею пишутся vk.toml (write_table), курсор LongPoll и хранилище заметок (prompts::save). В крейт вынесена, чтобы Telegram (у него есть только три кирпича) и Bitrix (у него она спрятана внутри приватной write_table) не собирали её заново. В plugins/vk доступна под прежним именем через pub(crate) use — все вызывающие не изменились.

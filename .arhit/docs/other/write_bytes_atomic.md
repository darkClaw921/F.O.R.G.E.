# write_bytes_atomic

plugins/atomic/src/lib.rs (крейт forge-atomic). Путь миграции: plugins/vk/src/config.rs -> plugins/chat-analysis/src/atomic.rs (эпик forge-caport-1a-4fwj) -> plugins/atomic/src/lib.rs (задача forge-meet-f0-8bzq.4). ЕДИНАЯ точка атомарной записи приватного файла: create_dir_all родителя -> запись во временный файл рядом (tmp_path_for: .<имя>.<pid>.tmp, права 0600 выставляются ДО первого байта) -> fsync -> rename на целевой путь -> повторный set_owner_only (rename сохраняет права tmp, но целевой мог существовать раньше с более широкими). При ЛЮБОЙ ошибке временный файл удаляется, целевой остаётся прежним — частичного состояния на диске не бывает. Ею пишутся vk.toml, курсор LongPoll, хранилище заметок (forge_chat_analysis::prompts::save), дальше файлы записи встречи forge-meet. Последний переезд — в собственный ЛИСТОВОЙ крейт с единственной зависимостью anyhow: forge-meet нужны только эти четыре функции, а через forge-chat-analysis они тянули бы tokio+tokio-util+uuid+forge-claude-runner, и реальным исходом была бы четвёртая копия tmp+rename+chmod. Старый путь forge_chat_analysis::atomic::* жив через pub use forge_atomic as atomic; — ни одно место вызова не правилось. См. страницу forge-atomic-crate.

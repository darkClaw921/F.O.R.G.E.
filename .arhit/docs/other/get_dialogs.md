# get_dialogs

GET /api/bitrix/dialogs?limit&offset&filter (plugins/bitrix/src/routes/dialogs.rs) — страница списка диалогов портала. Источники: B24Client::dialogs_bundle (im.recent.get + первая страница im.recent.list + счётчики + задачи с участием MEMBER — один batch), затем дозагрузка im.recent.list (до MAX_EXTRA_PAGES=3 страниц) пока хвоста меньше offset+limit; смещение считается по самому im.recent.list (не по длине im.recent.get, в котором есть чаты задач — иначе пропускались бы строки). Склейка dto::merge_dialogs (приоритет im.recent.get), затем чаты задач с участием, которых нет в im.recent.* (dto::dialog_from_task), с попутным наполнением TaskIndex. Фильтр директории dir_matches, сортировка пины→date_update, страница offset/limit. has_more = есть ещё загруженные строки ИЛИ у портала есть недогруженный хвост (hasMore) при непустой странице. Ошибки: 409 not_authorized, 503 not_connected, 400 invalid_input, ошибки портала. Прежняя константа RECENT_GET_SATURATION удалена.

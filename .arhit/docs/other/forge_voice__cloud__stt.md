# forge_voice::cloud::stt

Модуль `plugins/voice/src/cloud/stt.rs` (863 строки) — облачная расшифровка ОКНАМИ.

# ЗАЧЕМ ОКНА

У API polza.ai есть практический потолок на длину одного файла, и длинное голосовое
(лекция, пересланный подкаст) целиком не проходит. Поэтому звук режется на окна не длиннее
`MAX_STT_WINDOW_SECS = 90` (`DEFAULT_STT_WINDOW_SECS = 90`), каждое уходит отдельным
запросом, а тайминги сегментов сдвигаются обратно в общую ось.

# ДВЕ СТРАТЕГИИ НАРЕЗКИ

- `plan_windows(total_ms, window_ms)` — равномерная сетка. Годится всегда.
- `plan_windows_at_silence(total_ms, window_ms, speech)` → `CutWindows` — сдвигает границы
  окон в паузы, найденные VAD, и добавляет `CUT_PAD_MS = 300` запаса. Так фраза не рвётся
  посередине. Именно из-за нарезки существует известный баг `forge-12532` (задвоение речи
  на стыке окон при неудачном резе).

# КЛЮЧЕВЫЕ ЭЛЕМЕНТЫ

- `Window` — интервал в миллисекундах плюс смещение для обратного сдвига.
- `build_window_args(input, w, out)` — argv ffmpeg для выреза окна в mp3
  (`WINDOW_BITRATE = "32k"`, каталог `WINDOW_DIR = "cloud"` внутри скретча).
- `build_form_fields(model, language)` — поля multipart-формы вызова.
- `shift_segments(segments, offset_ms)` — сдвиг таймингов окна в общую ось. ВАЖНО: для
  этого НЕ годится `remap_segment_times` из `forge-meet` — та применяет МНОЖИТЕЛЬ
  (исправление дрейфа), а здесь нужен именно сдвиг.
- `parse_verbose_json(raw)` — разбор ответа `STT_RESPONSE_FORMAT = "verbose_json"`:
  сегменты плюс определившийся язык.
- `SttOptions`, `CloudSttOutcome`, `FailedWindow` — параметры и результат: отказ ОДНОГО
  окна не убивает всю расшифровку, он попадает в список `failed` и виден человеку.
- `CloudClient::transcribe_file(...)` — один файл одним запросом (короткое голосовое).
- `CloudClient::run_windows(...)` — полный проход по окнам с прогрессом.

# ОГРАНИЧЕНИЯ

Требует ffmpeg (нарезка и перекодирование в mp3) и ключ polza.ai. Цена линейна по
длительности звука (порядка 0,70 ₽/мин по замеру Ф18 forge-meet). Файл в облако всегда
уходит mp3, а не исходным ogg/opus.

# forge_voice::cloud::service

Модуль `plugins/voice/src/cloud/service.rs` (396 строк) — СЛУЖЕБНЫЕ вызовы polza.ai,
не связанные с самой расшифровкой: проверка ключа, баланс, каталог моделей и цены.

# ЗАЧЕМ

Вкладка настроек обязана уметь ответить на три вопроса, не заставляя человека открывать
`voice.toml`: «ключ вообще рабочий?», «сколько на нём денег?», «какие модели доступны и
почём?». Без этого выбор облачного движка — прыжок в темноте: человек узнавал бы про
исчерпанный баланс только по отказу расшифровки.

# КЛЮЧЕВЫЕ ЭЛЕМЕНТЫ

- `KeyInfo` / `parse_key(v)` — состояние ключа (валиден, метка, ограничения).
- `Balance` / `parse_balance(v)` — остаток средств.
- `Pricing` / `parse_pricing(model)` — цена модели за единицу.
- `ModelInfo` / `parse_models(v)` — каталог; `filter_kind(models, kind)` отбирает по виду,
  где `KIND_CHAT = "chat"` (модели саммари) и `KIND_STT = "stt"` (модели расшифровки).
- Методы на `CloudClient`, дергающие соответствующие эндпоинты.

# СВЯЗИ И ЛОВУШКИ

Наверх используется роутами `/api/meet/cloud/{models,balance}` (Ф16 forge-meet); в
голосовых сообщениях из этого модуля берётся только проверка «ключ задан» для поля
`cloud_key_set` в `…/voice/settings`. Разборщики намеренно терпимы (`number`/`text` из
`cloud::mod` возвращают `Option`): API добавляет поля, и строгий разбор превращал бы
каждое их изменение в неработающую вкладку. Переэкспорт наружу делается ТОЛЬКО глобом —
поимённый список однажды уже забыл `filter_kind`.

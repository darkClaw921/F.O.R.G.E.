# apply_prices

Recomputes price estimates on a coherent AgentIndex using the last validated PriceCatalog. Each UsageRecord receives its model/token-based estimated API cost. A BTreeMap groups eligible usage references by root_session_id once; each task then aggregates only records belonging to its root and within its task start/end interval. This preserves subagent rollup and unknown-price counts while avoiding the previous all-tasks-by-all-records scan on every live journal update. The observed raw local cache contained about 252000 usage events and 3600 starts before global deduplication, illustrating a product approaching 900 million comparisons at that input scale; actual folded counts depend on deduplication. Existing task-cost reset and Copilot attribution rules are preserved. No journal text, prompts, or extra persisted fields are introduced. Dependencies: AgentIndex, UsageRecord, PriceCatalog; invoked by ingestion refresh and catalogue repricing.

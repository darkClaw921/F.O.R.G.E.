# forge_meet::pipeline::run

Сквозной прогон пост-обработки: сведение дорожек -> архивный m4a -> проверка дрейфа по ffprobe -> таймлайн речи из журнала -> ожидание конца всех записей -> единственный слот whisper -> расшифровка (микс либо по дорожкам) -> атрибуция -> transcript.json/md -> база -> саммари -> ready. Stage задаёт точку входа для POST /retry?from=. Два жёстких ограничения очереди: слот whisper строго один (Metal занимается процессом целиком) и whisper не стартует, пока идёт любая запись (Chrome рендерит встречу на том же GPU). После получения транскрипта встреча УЖЕ НЕ ПАДАЕТ: провал саммари пишется в свой статус.

# reply_preview_text

plugins/telegram/src/dto.rs

`pub fn reply_preview_text(text: &str) -> Option<String>`

Превью текста для цитаты: одна строка, не длиннее REPLY_PREVIEW_CHARS (140) code points.

ТРИ ОБЯЗАТЕЛЬНЫХ СВОЙСТВА (зеркалятся на фронте в reply.js::truncatePreview):
- режем по CODE POINTS, а не по байтам: "🦀" — четыре байта, побайтовая обрезка разорвала бы
  символ;
- любые пробелы, табы и переводы строк схлопываются в ОДИН пробел, хвостовые убираются: цитата
  рисуется одной строкой, «лесенка» из исходного сообщения ломала бы вёрстку ленты;
- многоточие ВХОДИТ в лимит — результат никогда не длиннее REPLY_PREVIEW_CHARS.

Пустой (или состоящий из одних пробелов) текст ⇒ None: фронт покажет только пометку медиа.

ОПТИМИЗАЦИЯ. Длина считается на лету: +1 символ сверх лимита уже доказывает, что резать придётся,
и дальше разбирать весь текст (например, пересланную «простыню») не нужно.

ПРИМЕНЯЕТСЯ к ReplyToDto.text (через preview_parts) и к ReplyToDto.quote (в reply_to_from_header).

# createAgentSettings

Фабрика формы источников статистики и тарифов. Принимает host, зависимость api, document и onSaved; возвращает show/hide/destroy и refs для тестов. Форма живёт независимо от polling live-данных. Первый запрос config+summary.pricing идёт при открытии details видимого экрана; скрытый ответ игнорируется. POST/PUT разрешён только после загрузки настоящей конфигурации. Сохранение отправляет только разрешённые настройки, оставляет draft при ошибке и сообщает родительскому view через onSaved. Тарифы обновляются по сохранённому HTTPS URL, прежний каталог сохраняется при ошибке.

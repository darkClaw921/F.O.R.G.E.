# forge_voice::audio

Модуль `plugins/voice/src/audio.rs` (735 строк) — ПОДГОТОВКА ЗВУКА: от файла в медиа-кэше
плагина до того, что съест выбранный движок.

# ЗАЧЕМ

Голосовые приходят в чём угодно: VK отдаёт ogg/opus, Telegram — ogg или m4a, Bitrix —
что залил отправитель. whisper.cpp читает ТОЛЬКО WAV 16 кГц моно, облако хочет компактный
mp3. Этот модуль — единственное место, где происходит перекодирование, и единственное,
которое знает раскладку медиа-кэша плагинов.

# КЛЮЧЕВЫЕ ЭЛЕМЕНТЫ

- `Target` — `Mp3` (для облака, `MP3_BITRATE = "64k"`) либо `Wav`
  (`WHISPER_SAMPLE_RATE = 16_000`, моно).
- `media_dir(cache_dir, dir_name)` / `media_bin(cache_dir, dir_name, stem)` /
  `resolve_media(...)` — раскладка кэша: подкаталог `MEDIA_SUBDIR = "media"`, файл
  `<stem>.bin` рядом с `<stem>.meta.json`. `resolve_media` возвращает `None`, если файла
  нет: докачку решает плагин, ядро в сеть не ходит.
- `require_readable(path)` — отказ `no_media`, если файл исчез или нечитаем.
- `ScratchDir` — временный каталог `SCRATCH_SUBDIR = "voice-work"` с `Drop`, который его
  убирает. Без него перекодированные mp3/WAV копились бы рядом с кэшем навсегда.
- `build_mp3_args` / `build_wav_args` / `build_args(target, …)` — чистая сборка argv
  ffmpeg (тестируется без запуска процесса).
- `convert(...)` — запуск ffmpeg с `DEFAULT_FFMPEG_TIMEOUT_SECS = 180`.
- `probe_duration_ms(...)` — длительность звука ПО ФАЙЛУ. Нужна там, где платформа её не
  сообщает: у Bitrix24 длительности в метаданных вложения НЕТ вовсе, и потолок «слишком
  длинное» ловится только по декодированному звуку.
- `PreparedAudio` + `prepare(...)` — общая точка входа: разрешить путь → длительность →
  конверсия под цель → вернуть готовый путь и скретч.
- `key_label(key)` / `no_audio_error(what)` — человекочитаемая метка ключа для логов и
  типовой отказ.

# СВЯЗИ

Вниз: `tools::resolve_ffmpeg`, `proc`. Вверх: `transcribe::run` зовёт `prepare` первым
шагом (`PREPARE_PERCENT = 5` — доля прогресса, отдаваемая на подготовку), `waveform`
пользуется тем же ffmpeg для декодирования огибающей.

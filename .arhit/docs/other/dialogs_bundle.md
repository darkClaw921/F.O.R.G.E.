# dialogs_bundle

B24Client::dialogs_bundle(member_id) (plugins/bitrix/src/api/methods.rs) — один batch-запрос (один хит лимита 2 rps) для страницы списка диалогов Bitrix24: im.recent.get (верхушка, единственный источник чатов задач) + ПЕРВАЯ страница im.recent.list (LIMIT 200, хвост; чатов задач не отдаёт) + im.counters.get + tasks.task.list{MEMBER=member_id, order ACTIVITY_DATE desc, select LIST_SELECT} (задачи, где владелец вебхука фигурирует в любой роли: постановщик, ответственный, соисполнитель, наблюдатель). Возвращает DialogsBundle {recent, counters, list: Option<RecentListRaw>, tasks: Vec<TaskRaw>}. Отказ отдельной команды (halt:0) даёт пустую часть, а не ошибку. Почему: живьём im.recent.get отдаёт лишь часть списка (16 из 81, 33 из 213), а раньше im.recent.list звался только при 200+ строках im.recent.get — этого не происходило, и чаты пропадали; чат задачи есть в im.recent.get только при недавней активности (6 из 28 задач с участием). Ключи пакета: COLD_START_RECENT_KEY=recent, DIALOGS_LIST_KEY=list, COLD_START_COUNTERS_KEY=counters, DIALOGS_TASKS_KEY=tasks. Вызывается из routes::dialogs::get_dialogs.

# ensure_private_file

config::ensure_private_file(path) в plugins/meet/src/config.rs — выставляет файлу конфига права CONFIG_FILE_MODE = 0600. Зовётся ПОСЛЕ каждой записи meet.toml из PUT /api/meet/config, а не только при создании: атомарная запись создаёт файл заново, а сам файл мог быть создан прежней версией плагина, распакован из бэкапа или написан руками — все три случая дают права по umask. Причина не косметическая: в файле может лежать ключ API polza.ai, и файл с правами 0644 читается любым процессом пользователя и любым другим пользователем машины. Рядом живут file_mode(path) (права восьмеричной строкой для UI) и file_is_world_readable(path) — по нему MeetConfig::from_file пишет warn, если в конфиге есть ключ, а права шире; молча права при чтении НЕ чинятся, потому что файл правят руками.

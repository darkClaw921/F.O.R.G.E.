# attention_prompt::tests

Seven focused native attention regression tests exercise Codex command/patch/network/permissions/stdin/MCP menus, selected cursor movement and wrapped native footers; structured choice/freeform/notes/unanswered questions; ordinary prose, idle composers, answered output and quoted/diff negatives; released/development OpenCode permission stages and custom/multi/review questions; identical independent sessions, inactive panes and any-pane OR aggregation; linked-primary selection and per-pane/process uncertainty; and an actual isolated tmux TUI. The isolated case starts a private socket with /dev/null configuration, renders a native permission in an inactive window, verifies attention, preserves a known wait during copy mode, clears after answer output, refuses to arm from copied historical menus, and leaves the active window unchanged. It does not send terminal input or launch any agent/model. Existing66 attention and61 autoapproval regressions are also run to protect journal/idle and permission-safety semantics.

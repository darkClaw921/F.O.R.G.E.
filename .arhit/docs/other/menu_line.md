# menu_line

auto_approve::menu_line(lines: &[&str]) -> Option<usize> — индекс строки меню текущего prompt'а ('❯ 1.'). Общий якорь для extract_command_region, extract_subject и stability_region.

Ищет ПОСЛЕДНЕЕ вхождение (rposition), а не первое. Настоящий prompt всегда внизу панели — тот же инвариант, что у attention::prompt_at_bottom. Выше на экране легко остаётся ЧУЖОЕ такое же меню: cat собственных тест-фикстур, diff, лог предыдущего запроса. С первым вхождением область проверки блоклиста строилась вокруг цитаты: заголовок искался над цитатой ('Bash command / cat …'), а команда настоящего запроса в регион не попадала — то есть 'rm -rf' в реальном prompt'е мог быть пропущен как безопасный, если выше висела цитата с меню. Это был не отказ в апруве, а ЛОЖНЫЙ апрув опасной команды.

Тест quoted_menu_above_does_not_shadow_real_request проверен на фальсифицируемость: с position (старое поведение) падает, с rposition проходит. Второй тест — subject_and_stability_anchor_to_the_bottom_menu.

Связи: используется тремя функциями модуля; вместе с is_request_header и stability_region образует набор фиксов «авто-апрув в окнах с суб-агентами».

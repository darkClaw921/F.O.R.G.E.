# upload_multipart_parts

Заливает несколько файлов ОДНИМ multipart-запросом на upload-сервер VK (plugins/vk/src/api/mod.rs). Существует ради альбомов: VK принимает до пяти фотографий полями file1..file5 и сохраняет их одним photos.saveMessagesPhoto, поэтому пятёрка стоит трёх троттленных запросов вместо пятнадцати. НЕ троттлится (чужой хост, не метод API). Каждая часть собирается через Part::stream_with_length(body, size) — это обязательно: с обычным stream() reqwest не знает длины, уходит в chunked (который upload-сервер VK не принимает) и буферизует файл целиком, из-за чего отправка полугигабайтного видео уехала бы в RSS. Ответ upload-сервера — голый объект без конверта response, разбирается parse_upload_response. VkClient::upload_multipart (одиночный файл) теперь тонкая обёртка над этим методом.

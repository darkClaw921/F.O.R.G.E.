# title_from_messages

Имя собеседника по уже выгруженным сообщениям — заголовок для шапки промпта анализа чата (plugins/telegram/src/analysis/context.rs).

ЗАЧЕМ ИМЕННО ТАК. У VK имя беседы берётся из кэша peer'ов, прогретого resolve_names во время выгрузки. У Telegram кэш peer'ов (TelegramState::peers) хранит только PeerRef — id и access_hash, без title'ов. Отдельный RPC ради украшения шапки платился бы на КАЖДОМ разборе, поэтому имя выводится из данных, которые уже на руках.

ПРАВИЛО: берётся автор первого ВХОДЯЩЕГО (out == false) сообщения, у которого непустое отображаемое имя. Для лички это ровно собеседник; для группы — просто первый заговоривший, что всё равно лучше пустоты.

ПУСТАЯ СТРОКА — легальный ответ (весь кусок истории исходящий, либо авторов нет вовсе, как у постов от имени канала). prompt::build в этом случае подставит «без названия».

Имя автора вычисляется общим для модуля хелпером speaker_name: first_name -> @username -> числовой id. Пустой подписи не бывает никогда.

Ноль обращений к сети и к состоянию — чистая функция над срезом MessageDto, тестируется литералами (title_comes_from_the_first_incoming_sender).

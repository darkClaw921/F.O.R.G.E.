# VkState

Разделяемое состояние плагина VK (plugins/vk/src/state.rs): создаётся один раз в crate::init, оборачивается в Arc и раздаётся axum-хендлерам, WS-соединениям и фоновым воркерам. Ключевые поля: config (неизменяемая часть) + token под RwLock (единственная меняющаяся во время работы часть конфигурации), broadcast ёмкостью BROADCAST_CAPACITY=1024 БЕЗ фильтрации по вкладке и диалогу, login под Mutex (переходы автомата сериализованы), uploads, lp_cursor, health (Arc, общий с VkClient — иначе 503 отдавался бы по данным, ничего не знающим о реальных вызовах), workers + shutdown (CancellationToken), authorized_notify, captcha_imgs, client (ОДИН клиент на токен, значит один троттлер), peers (синхронный кэш имён), тайминги ws/lp как ДАННЫЕ ради быстрых тестов, media_inflight/message_inflight/message_cache, prompts (пер-чатовые заметки, загружаются синхронно в конструкторе). АЧ-Ф3 добавил поле analysis: AnalysisHub — реестр активных анализов чата через Claude. Создаётся безусловно, даже когда бинаря CLI на машине нет (ClaudeRunner::new в этом случае только warn'ит), потому что анализ — одна кнопка, а не условие работы мессенджера; отказ выносит роут кодом 409 claude_unavailable с путём и инструкцией.

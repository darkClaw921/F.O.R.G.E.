# forge_cdp

Свой клиент Chrome DevTools Protocol — ради дистрибуции ОДНИМ Rust-бинарём: готовые обёртки означали бы Node-сайдкар либо чужую модель жизненного цикла. Состав: launch (запуск Chrome с отдельным профилем и чтением DevToolsActivePort), ws/transport (соединение и мультиплексирование команд с таймаутами), session (браузер и цели), page (вкладка: навигация, инжект до загрузки документа, оценка выражений, скриншот), inject (Runtime.addBinding и приём кадров). Измерено на Chrome 151: биндинг доносит данные из OOPIF без усечения, запуск с окном крадёт фокус (лечится --no-startup-window и созданием цели в фоне), у неактивной вкладки скриншот работает только с fromSurface:true.

# forge_meet::pipeline::speakers

Чистые функции атрибуции: интервалы речи из потока событий (пер-трековый VAD и DOM-индикатор одним потоком — ветка «трек = человек» не может быть единственной), отбрасывание коротких, слияние близких, пересечение сегментов с интервалами двумя указателями, разрезание спорного сегмента по потокенным меткам, склейка в абзацы, линейная коррекция дрейфа. Tie-break при равном перекрытии — по имени спикера: без него победитель зависел бы от порядка обхода HashMap, и повторный прогон одной записи давал бы разные файлы.

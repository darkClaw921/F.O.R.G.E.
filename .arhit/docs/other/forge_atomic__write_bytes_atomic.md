# forge_atomic::write_bytes_atomic

Запись файла целиком через временный файл рядом с целевым, fsync и rename: читатель видит либо старое содержимое, либо новое, но никогда обрезанное. Вынесено в отдельный листовой крейт, потому что нужно троим (Echo, анализ чата, плагин встреч), и четвёртая копия tmp+rename+chmod была бы способом развести три разных поведения при одинаковом имени. Плагин встреч пишет так манифест и транскрипт: манифест переписывается на каждом изменении состава дорожек, и обрыв посреди записи оставил бы каталог, который пост-обработка не прочитает.

# speakers

speakers.rs — слияние транскрипта с таймлайном спикеров. Чистые функции, ядро тестов фазы 5.

ДВА РАВНОПРАВНЫХ ИСТОЧНИКА ИНТЕРВАЛОВ, оба разбирает intervals_from_events одним потоком:
- SpeechEvent::On/Off — пер-трековый VAD (режим PerParticipant, трек = человек);
- SpeechEvent::Active — активный спикер из DOM (режим Slots). Для Телемоста это ЕДИНСТВЕННЫЙ источник: проба Ф0 дала два аудиотрека на трёх участниках и track.muted, не менявшийся при смене говорящего. Событие Active эксклюзивно: новый активный закрывает предыдущего, повтор того же имени интервал не рвёт.

Разбираются: несортированный вход, дубли on/on и off/off, off без on, незакрытый интервал в конце записи (закрывается концом записи — так выглядит обрыв).

attribute_segments, шаги: отброс интервалов короче 250 мс -> слияние соседних одного спикера с зазором меньше 400 мс -> пересечение по миллисекундам двумя указателями -> confidence = доминирующий/сумма -> при confidence < 0.6 и втором претенденте >= 25 % разрез сегмента по ПОТОКЕННЫМ меткам (-ojf) с пометкой overlapped. Все пороги — поля конфига.

ДЕТЕРМИНИРОВАННЫЙ TIE-BREAK: при равном перекрытии побеждает лексикографически меньшее имя. Без него исход зависел бы от порядка обхода HashMap, и тесты падали бы через раз, а повторный прогон давал бы другой файл.

merge_tokens_to_words склеивает subword-токены («Кол», «лег», «и» -> «Коллеги,»): метки в -ojf потокенные, а не пословные (измерено в Ф0). Служебные токены вида [_BEG_] отбрасываются на разборе JSON.

merge_into_paragraphs (шаг 6) вынесен отдельной функцией: transcript.json обязан сохранить исходную нарезку (по ней фронт ищет и подсвечивает), абзацы нужны только transcript.md и промпту саммари.

remap_segment_times / remap_intervals / drift_scale — линейная коррекция таймлайна. Множитель, а не сдвиг: дрейф накапливается пропорционально времени. В пайплайне корректируются ИНТЕРВАЛЫ, а не сегменты — сегменты whisper уже живут на оси звука.

# agents::opencode::read

Read one OpenCode source database into a complete OpenCodeCursor contribution. Inputs: path to regular opencode.db, canonical profile identity, inclusive lower history timestamp in Unix milliseconds, optional previous cursor. Output: Result<OpenCodeCursor> with authoritative normalized AgentEvent list and decoded_rows count. Performs source identity/schema validation, cached-id reconciliation, timestamp and mutable-length checks, incremental append read, and pure lifecycle replay from small metadata records. Does not mutate previous, launch an agent, change SQLite settings or write source files; SQLITE_BUSY/unsupported schema are retryable source errors for the coordinator. Caller should run in spawn_blocking and avoid invoking when DB/WAL metadata is unchanged. Parent module publishes task/live/history snapshots and handles global quiet/settled expiry.

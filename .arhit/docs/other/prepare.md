# prepare

Подготовка аудио к расшифровке (forge_voice::audio::prepare). Порядок: проверка файла — длительность декодированием — потолок — перекодирование. Длительность считается ДО перекодирования, чтобы двухчасовая запись отсекалась до траты минуты процессорного времени. Возвращает PreparedAudio, который держит ScratchDir: рабочий каталог сносится на Drop при любом исходе, включая ошибку, отмену и панику. Параметры: source (файл медиа-кэша), target (Mp3 для облака или Wav16k для whisper), ffmpeg, cache_dir (в нём рождается рабочий каталог), max_duration_secs, timeout, cancel.

# ScratchDir

Уникальный рабочий каталог расшифровки внутри cache_dir/voice-work, сносящий себя на Drop (forge_voice::audio). Имя содержит PID И счётчик процесса: только PID недостаточно — два потока одного devforge получили бы одно имя и стёрли бы друг другу файлы (ровно на этом обжигался forge_atomic::tmp_path_for, forge-vcqz7). Ошибка удаления глотается: Drop бежит и на пути паники, остаток подметает LRU кэша плагина.

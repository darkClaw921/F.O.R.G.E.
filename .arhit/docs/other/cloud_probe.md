# cloud_probe

MeetState::cloud_probe() в plugins/meet/src/state.rs — опрос живости ключа polza.ai для GET /api/meet/status. НЕ возвращает Result намеренно: единственный вызывающий — роут, который никогда не падает, и недоступный polza.ai обязан стать полем со статусом ошибки, а не 500 (панель плагина гейтится этим ответом). Спрашивает БЕСПЛАТНЫЙ GET /key: он не тратит денег и сразу показывает остаток лимита; GET /balance сюда не ставится — это второй сетевой вызов ради числа, нужного не всегда. Результат кэшируется в поле cloud_probe на CLOUD_PROBE_TTL = 60 с (панель дёргает статус в фоне и не по одной вкладке), потолок вызова — CLOUD_PROBE_TIMEOUT = 3 с, поставленный дважды: внутри вызова и снаружи через tokio::time::timeout, чтобы ограничить и разрешение имени с рукопожатием TLS. Возвращает None, когда ключа нет — тогда сетевого вызова не происходит вовсе, и тесты статуса герметичны.

# agents::runtime::online_state

Return local network path availability as Option<bool> without external sockets or DNS. macOS probes IPv4 default and IPv6 default routes concurrently using /sbin/route with a one-second deadline per process, then verifies the chosen interface UP/RUNNING and not-loopback flags through getifaddrs. Any usable default is online, including IPv6-only hosts; offline requires both route families to be conclusively absent/down. BSD route can report a missing route as exit0 with empty stdout and stderr not-in-table; classify that explicit diagnostic as absent, rather than trusting status alone. Permission errors, timeouts, missing interface metadata or mixed absent/unknown results stay None and cannot fabricate an offline transition. Linux reads IPv4/IPv6 default route metadata from procfs and applies the same interface link checks. AgentStatsStore owns the twenty-second Claude offline grace and excludes ongoing local commands; this observer supplies facts only. Pure classification tests cover IPv6-only availability, dual absence, unavailable probes, permission errors and both zero/nonzero-status BSD route-not-found messages; a live read-only macOS check confirmed the zero-status diagnostic behavior.

# spawn_uploads_gc

Запускает фоновый GC незавершённых загрузок VK и регистрирует его для graceful shutdown (plugins/vk/src/routes/upload.rs). Первый прогон — сразу на старте: он убирает СИРОТ прошлого процесса (реестр uploads живёт в памяти, поэтому после рестарта каждый .part никому не принадлежит). Дальше раз в UPLOAD_GC_INTERVAL=5 минут выбрасываются записи старше UPLOAD_TTL_SECS=30 минут вместе с файлами. Вызывается из lib.rs::spawn_workers ВСЕГДА, в том числе без токена: мусор на диске не зависит от того, залогинен ли пользователь.

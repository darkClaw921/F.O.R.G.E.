# RecordingSink

plugins/chat-analysis/src/testing.rs. Накопительная реализация AnalysisSink для тестов ядра И плагинов: складывает Frame::{Started,Delta,Done,Error} в Mutex<Vec<Frame>> и будит ожидающих через Notify. API: frames() — снимок, text() — склейка всех дельт (то, что увидел бы пользователь), delta_frames() — счётчик кадров (ось, по которой меряется коалесцинг), find(pred), wait_for(timeout, pred) (None — полноценный результат: тест отмены проверяет ОТСУТСТВИЕ финального кадра). Публичная, а не cfg(test): тем же накопителем проверяются роуты плагинов. До выноса ядра тесты хаба разбирали broadcast-канал VK и VkServerMsg, то есть тянули за собой весь WS-протокол ради проверки арифметики кадров.

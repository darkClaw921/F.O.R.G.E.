# forge_vk::voice_auto

Файл `plugins/vk/src/voice_auto.rs` (438 строк) — авторазбор новых голосовых VK.

# ЗАЧЕМ

Требование пользователя: «хочу, чтобы новые голосовые разбирались сами». Модуль —
адаптер между входящим сообщением плагина и общей функцией `routes::voice::begin`.

# ПОРЯДОК РЕШЕНИЯ (и он именно такой не случайно)

1. `prefs(state)` перечитывает `user_settings.json` (`forge_voice::prefs::read`) НА
   КАЖДОЕ входящее — переключённый в браузере тумблер действует со следующего сообщения,
   без перезапуска процесса.
2. `forge_voice::auto::decide(prefs, cand, max_duration_secs)` возвращает `Ok(())` либо
   причину `Skip`: выключен тумблер, беседа вне белого списка видимости, своё исходящее,
   не голосовое, слишком длинное.
3. `SeenKeys` (ограниченный FIFO, `DEFAULT_SEEN_CAPACITY = 512`) отсекает повтор.
   Именно он, а не `VoiceHub`: хаб знает только про ИДУЩИЕ прогоны, стор — только про
   УСПЕШНЫЕ, и прогон, кончившийся отказом, повторная доставка события гоняла бы по
   кругу. Список кодов, которые ИМЕЕТ смысл повторить, задан явно — `retryable(code)`.
4. `run_one` зовёт ту же `begin`, что и кнопка.

# ВЫКЛЮЧЕННЫЙ ТУМБЛЕР ОЗНАЧАЕТ ПОЛНОЕ МОЛЧАНИЕ

Ни докачки файла, ни запуска движка, ни записи в стор. Решение принимается ДО любого
обращения к сети и диску, а `log_skip` пишет причину пропуска в журнал — по нему это и
проверяется на живой приёмке (пункт 5 чек-листа), а не по глазам в интерфейсе.
Дефолт тумблера — ВЫКЛЮЧЕНО, и читается он строго как `=== true`: фича тратит GPU либо
деньги, включаться сама она права не имеет.

# РЕЕСТР ВОРКЕРОВ

`register_worker` до Ф4 копил ручки (за жизнь процесса их клали 3-4), а авторазбор
регистрирует задачу на КАЖДОЕ голосовое — поэтому во все три состояния добавлен
`retain(|h| !h.is_finished())`.

# ОСОБЕННОСТЬ VK: СЛОВАРИ ВИДОВ БЕСЕДЫ У БЭКЕНДА И ФРОНТА РАЗНЫЕ

`vk::dto::peer_kind` отдаёт `group`, а фронт кладёт в `vk_visible_kinds` слово
`community` (`js/vk/format.js::peerKind`). Перевод делает `visibility_kind(peer_id)` —
без него белый список «только сообщества» молча не действовал бы. На словарь есть
отдельный тест.

`voice_attachments(msg)` отбирает из сообщения все звуковые вложения: у VK их в одном
сообщении бывает несколько, и `on_new_message` возвращает число запущенных прогонов.

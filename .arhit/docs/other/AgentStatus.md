# AgentStatus

Read-only /api/agents/status DTO preserves state/scanning/files/scannedFiles/updatedAtMs/errors/historyDays/bytesRead/readFiles and adds profiles: Vec<String>. profiles is always serialized as an array and is sorted/deduplicated from canonical profile identities of currently indexed source descriptors. It includes standard profiles that have only historical tasks or usage and no live task, independently of extra roots shown in configuration. Normal and archived Codex sources with the same profile contribute one selector option. Empty/disabled/uninitialized status uses an empty array. serde(default) keeps deserializing an older status without this additive field backward compatible. The list is published with the index status and performs no filesystem traversal in HTTP handlers. Fixture regression uses two accounts, one historical-only and one active, plus a regular/archive duplicate, and exercises the actual GET status handler.

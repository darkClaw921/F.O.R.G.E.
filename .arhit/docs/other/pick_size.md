# pick_size

plugins/vk/src/attach.rs::pick_size(sizes: &[SizeCandidate], kind: MediaKind) -> Option<usize> (Ф7). ЧИСТАЯ.

ПРАВИЛО:
  Full  — максимальный по max(width, height);
  Thumb — МИНИМАЛЬНЫЙ из тех, у кого max(width,height) >= THUMB_MIN_PX (200); если такого нет — самый большой из имеющихся (все мелкие, и «менее размытый» тут лучше «полегче»).

ПОЧЕМУ ПО ЧИСЛАМ, А НЕ ПО БУКВЕ: буквенный набор VK (s m o p q r x y z w) исторически менялся, у разных объектов он разный, а у картинок стикера его нет совсем. Буква остаётся ЗАПАСНЫМ ключом: letter_px() подставляет табличную оценку размера, только когда width/height равны нулю (старые фото), и разрывает ничью детерминированно. Мутация «сортировать по букве» краснит строку таблицы «буква спорит с числами — верим числам».

Ничья разрешается в пользу ПЕРВОГО по порядку варианта: дубликаты размеров не должны зависеть от обхода. Пустой массив -> None (роут отвечает 404 no_media, фронт рисует значок).

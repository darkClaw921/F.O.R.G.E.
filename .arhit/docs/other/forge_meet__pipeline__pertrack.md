# forge_meet::pipeline::pertrack

Пер-трековая расшифровка с нарезкой по VAD (Ф11). Режет каждую дорожку по её собственным интервалам речи с полями 300 мс, склеивает только речь, гонит whisper по дорожкам и возвращает таймкоды на общую ось (сегмент, пересёкший стык, РАЗРЕЗАЕТСЯ по потокенным меткам, иначе он занял бы всю вырезанную паузу). Даёт две вещи, которых микс не даёт: перебивания разбираются, а подпись спикера становится фактом (confidence 1.0), а не оценкой. Включается ТОЛЬКО в режиме PerParticipant, которого ни у одной площадки не подтверждено, и только если укладывается в бюджет ВРЕМЕНИ: каждая дорожка стоит своей речи плюс постоянная цена запуска whisper (модель грузится заново), и на короткой записи путь честно уходит на микс.

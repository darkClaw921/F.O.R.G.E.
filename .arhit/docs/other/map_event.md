# map_event

plugins/vk/src/longpoll.rs::map_event(ev: &LpEvent, ctx: &MapCtx) -> Vec<VkServerMsg> —
отображение события LongPoll в кадры WS протокола плагина.

ВОЗВРАЩАЕТСЯ ВЕКТОР, а не Option, ровно из-за событий 63/64: «в беседе печатают
трое» обязано стать ТРЕМЯ кадрами typing, иначе фронт увидит только первого.
Пустой вектор — законный исход (например, FlagsReplace: какие биты изменились,
из события не видно, а перечитывать сообщение ради этого — запрос на событие).

MapCtx — контекст обогащения пачки: тексты и вложения, добытые ОДНИМ
getLongPollHistory, плюс карта заглушённых бесед. is_muted() трактует «не знаем»
как «звенит»: лишний тост исправляется одним щелчком, пропущенное сообщение —
ничем.

Соответствие кадров и кодов зафиксировано в шапке ws/protocol.rs; полнота карты
на стороне фронта проверяется node-тестом vk_realtime против ws.js::SERVER_FRAMES.

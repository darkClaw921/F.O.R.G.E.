# ProgressReader

Обёртка над AsyncRead, считающая прочитанные байты (plugins/vk/src/progress.rs). Нужна ОТПРАВКЕ файлов: тело multipart-запроса уезжает в reqwest потоком, и единственная точка, где видно, сколько байт уже ушло, — сам ридер. Колбэк дёргается на каждом poll_read с накопленным счётчиком и НЕ вызывается на ошибочном poll (иначе UI получил бы прогресс из ниоткуда). Прозрачность байт-в-байт — контракт (тест progress_reader_is_byte_transparent): ридер ничего не меняет, не буферизует и не переупорядочивает. Используется в routes/upload.rs::staged_part вместе с tokio_util::io::ReaderStream.

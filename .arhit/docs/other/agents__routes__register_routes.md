# agents::routes::register_routes

Host-only Router<AppState> registration for /api/agents; called before global Bearer and CSRF layers in main. HTTP contract covers coherent live snapshots, validated history filters and sessions pagination, status and single-flight accepted rescans, sanitized configuration, process binding/inventory endpoints and price refresh. Raw HashMap query and Bytes body pass through remote dispatch first; only local requests are decoded against strict DTOs. Configuration rejects editable internal write paths and insecure URLs, preserving cache/config/price locations from current state. Eleven real-router tests exercise all route groups with actual auth/CSRF middleware and synthetic local sources. The busy-ingestion test holds the real store gate: eight POST rescans still return202 within250ms and GET status remains readable/scanning, then the single-flight worker completes when the gate releases. No tests inspect route source strings or depend on guessing a host agent process.

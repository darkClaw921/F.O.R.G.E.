# plugins/tracker/src/routes/report.rs::tests::only_one_border_may_be_given

Regression test for a Tracker report window with only the upper boundary supplied. The fixture fixes now to 2026-09-08T12:00:00Z using the existing report::parse_ts helper and supplies to=2026-09-09; the omitted lower boundary must resolve to the local Monday of that same week. Fixing the clock keeps the explicit September bound valid when the suite runs months later and removes the date-dependent pre-release failure observed on October 29. It still exercises the real current_week and resolve_window functions, local-time window resolution and partial-query fallback. Production handlers, interval validation and report calculations are unchanged; this adjustment does not suppress the inverted-window error tested separately.

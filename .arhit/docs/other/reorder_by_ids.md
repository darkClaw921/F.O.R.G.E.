# reorder_by_ids

plugins/bitrix/src/config.rs. Общее правило перестановки по списку идентификаторов, generic по элементу: берёт Vec<T>, список ids и функцию-ключ T -> String. Выстраивает элементы в порядке ids, а всё непомянутое дописывает в хвост с сохранением относительного порядка; неизвестные ids просто игнорируются. Существует ровно для того, чтобы порядок вкладок в памяти (B24Registry::reorder над слотами Arc<B24State>) и порядок в файле (reorder_portals_in над PortalConfig) считались ОДНИМ кодом — разойдись они, вкладки после перезапуска devforge встали бы иначе, чем их только что перетащили.

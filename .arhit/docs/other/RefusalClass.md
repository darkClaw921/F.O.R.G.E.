# RefusalClass

Класс отказа расшифровки (forge_voice::error): Input (400), State (409), Unavailable (503), Internal (500). Живёт в ядре, чтобы три плагина отвечали на одну причину одним HTTP-кодом: иначе общий фронт-модуль получал бы от VK 409, а от Bitrix 500. Перевод класса в конкретный конструктор ApiError остаётся за плагином — таблицы кодов у них свои и заморожены контрактными тестами.

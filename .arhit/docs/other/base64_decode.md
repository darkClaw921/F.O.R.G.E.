# base64_decode

plugins/telegram/src/dto.rs — декодирование callback-data из base64.

Сигнатура: base64_decode(s: &str) -> Option<Vec<u8>>; None означает «это не base64».

ДЕКОДЕР НАМЕРЕННО ТЕРПИМЕЕ ЭНКОДЕРА (принцип устойчивости на входе, строгость на выходе):
- принимает URL-safe символы '-' и '_' наравне с '+' и '/';
- принимает отсутствующий padding;
- игнорирует переносы строк и пробельные символы;
- ОТВЕРГАЕТ чужие символы и обрубок длиной в один символ (из одного base64-символа байта не
  собрать — это гарантированно битый вход, а не «почти правильный»).

Публичен СПЕЦИАЛЬНО ради routes/dialogs.rs::validate_callback: иначе HTTP-слою пришлось бы тянуть
крейт base64 ради единственной обратной операции. Лимит MAX_CALLBACK_DATA=64 байта проверяется
по ДЕКОДИРОВАННЫМ байтам — base64 раздувает данные на треть, и сверка по длине строки резала бы
легальные payload'ы.

Обратная операция — base64_encode.

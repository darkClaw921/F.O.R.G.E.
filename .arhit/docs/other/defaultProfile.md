# defaultProfile

Выводит идентификатор общего профиля для дополнительного каталога журналов. Аргументы provider и path — строки. Для Codex sessions/archived_sessions, Claude projects и Copilot session-state возвращает родительский каталог; для OpenCode пути к opencode.db — каталог базы. Иначе сохраняет введённый путь, чтобы нестандартная схема не была произвольно переименована. Явно заполненный пользователем profile имеет приоритет в форме. Функция не читает файловую систему и не запускает CLI.

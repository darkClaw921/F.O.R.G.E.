# danger_scope

Выбирает текст, по которому работает блоклист авто-апрува (tmux-web/src/auto_approve.rs). Порядок: 1) extract_command_region — блок команды от заголовка «Bash command»/«Claude in Chrome» до меню; 2) если заголовка нет — идём вверх от строки меню и берём до FALLBACK_SCAN_LINES=3 содержательных строк; 3) если по дороге встретилась строка запроса на правку файла (is_edit_request: «Do you want to make this edit to…», «…create…», «…overwrite…», «…write to…», «…apply this edit to…») — возвращается ТОЛЬКО она, без diff'а над ней. Вся панель не берётся никогда. Причина: живой кейс окна wt:1785950679 — prompt «Do you want to overwrite hub.rs?», а в diff'е строка hub.shutdown().await; слово shutdown из DEFAULT_DANGEROUS блокировало правку, и отказ LLM кэшировался навсегда. Строка запроса остаётся в области намеренно: пользовательская запись блоклиста по имени файла (secrets.rs) обязана работать. «Do you want to proceed?» под is_edit_request не подпадает — это заголовок bash-запроса.

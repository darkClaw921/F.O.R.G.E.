# watcher_loop

Every1500ms lists all tmux sessions, then uses attention_prompt::Observer for native permission and structured-question waiting in all physical panes including inactive windows. Physical panes are captured once per tick and linked aliases use the existing attached-primary policy. Independent equal-text sessions remain independently orange; successful answered output clears only its pane while unknown reads preserve only prior physical state. The orange pass reads no transcript archives and has no input/autoapproval side effects; autoapprove and statistics configuration do not gate it. Journal-derived working projection and explicit-only Echo idle remain separate and unchanged. Session inventory failures preserve state; successful listings prune deleted sessions.

# attachment_string

ЧИСТАЯ функция сборки строки вложения VK из ответа save-метода (plugins/vk/src/routes/upload.rs). Форма: <тип><owner_id>_<media_id>[_<access_key>]. Для UploadKind::Photo на вход приходит элемент массива photos.saveMessagesPhoto, для Doc/AudioMessage — объект docs.save, из которого берётся первое непустое поле doc/audio_message/graffiti. Префикс у документа И голосового один и тот же — doc: audio_message это название ТИПА вложения в полученном сообщении, а не префикс адреса. access_key добавляется всегда, когда VK его прислал (обязателен для приватных объектов, безвреден для публичных). Возвращает None на вырожденном ответе (нулевые или нечисловые идентификаторы, чужая форма) — вызывающий обязан отказать, потому что сообщение с мусорным attachment VK принял бы как текст без вложения, то есть пользователь увидел бы «отправлено» без файла.

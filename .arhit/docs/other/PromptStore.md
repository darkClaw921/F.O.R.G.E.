# PromptStore

plugins/chat-analysis/src/prompts.rs (после выноса из plugins/vk/src/analysis/prompts.rs). Пер-чатовое хранилище: BTreeMap dialog_id (СТРОКОЙ — один инвариант с WS-протоколом и DTO) -> ChatPrompt{prompt: заметка пользователя, updated_at, analysis: Option<ChatAnalysis>, thread: Vec<QaTurn>}. Три половины записи НЕЗАВИСИМЫ: правка или очистка одной не трогает две другие (set / set_analysis / clear_analysis / push_turn / clear_thread), запись живёт, пока жива хотя бы одна. Плоская мапа в одном JSON-файле на плагин, путь — ПАРАМЕТР load/save (у VK ~/.forge/vk-chat-prompts.json из VkConfig::prompts_path). BTreeMap ради стабильного порядка ключей в файле. load никогда не возвращает ошибку (нет файла / больше MAX_FILE_BYTES / не JSON / чужая version -> warn + пустое хранилище), прочитанное проходит normalize. Вытеснение по MAX_CHATS=500 (самая старая по updated_at, тай-брейк по ключу). Файл пишется через atomic::write_bytes_atomic с правами 0600; в tracing — только длины и количества.

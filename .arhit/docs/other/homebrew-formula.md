# homebrew-formula

Formula/devforge.rb is the checked-in Homebrew source template for devforge v0.1.75. It builds the Cargo workspace binary from tmux-web and embeds static assets; rust is a build dependency and tmux is required at runtime. HEAD builds use master, while stable url identifies the release tag. The source template deliberately contains REPLACE_WITH_SHA256: the tagged archive includes this template, so its own final digest cannot be committed into itself. The external darkClaw921/homebrew-tap/Formula/devforge.rb is the installable formula and must contain the actual SHA256 calculated from the exact tagged archive after publication. Never replace digest verification with a bypass. Formula syntax is validated with ruby -c; stable publication validates the archive version and exact source checksum, and the formula test invokes devforge --help. The running user installation is not upgraded or restarted as part of package publication.

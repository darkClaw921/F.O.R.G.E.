# UploadReporter

Отправитель кадров upload_progress по одной загрузке (plugins/vk/src/progress.rs). Адрес карточки во фронте — upload_id, выданный POST /api/vk/upload; total известен заранее (размер staging-файла). Держит СВОЙ Throttle (100 мс / 256 КиБ), поэтому пять параллельных файлов альбома не глушат друг друга: первый кадр каждого проходит всегда, финальный (finish) проходит всегда — иначе прогрессбар навсегда замер бы на 97 %. ВАЖНО: у VK эти кадры вещаются во время POST /api/vk/dialogs/:id/messages, а не во время POST /api/vk/upload, потому что весь трёхшаговый конвейер живёт внутри отправки сообщения.

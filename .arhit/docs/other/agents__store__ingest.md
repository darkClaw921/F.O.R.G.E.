# agents::store::ingest

Serialized bounded source ingestion and coherent index publication. Unchanged/recent/open source selection, discovery latching, source rotation/deletion, pruning, errors and cache persistence retain their behavior. Per-tick availability now unions cached actual event-owner IDs instead of traversing every retained historical event and serializing its session key. Healthy duplicate sources override unavailable copies, and parent-only links do not become owner availability. Successful contribution changes and retention pruning refresh the cached identity sets. Changed contributions are replayed with index::fold_refs on borrowed events under the stable ingestion lock; there is no full event-vector clone. The source cache stays version3 with unchanged retention and limits. Benchmarks are manual, private-copy and opt-in; functional regression tests remain normal test gates.

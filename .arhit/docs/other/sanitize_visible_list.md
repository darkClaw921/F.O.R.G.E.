# sanitize_visible_list

user_settings.rs — приводит белый список видимости Telegram к безопасному виду. Как и sanitize_hotkeys, проверяет только ФОРМУ: смысл ключей ('inbox', 'archive', 'folder:<id>', id чата) знает фронтенд. Неизвестная запись не ошибка — она ни с чем не совпадёт, но останется сохранённой, что позволяет пережить откат версии клиента. Отбрасываются: пустые после trim, длиннее MAX_VISIBLE_ENTRY_LEN=64, содержащие что-либо кроме [0-9a-zA-Z_:.-] (id чатов бывают отрицательными, ключ папки содержит двоеточие). Дубликаты схлопываются С СОХРАНЕНИЕМ ПОРЯДКА — порядок виден пользователю в списке настроек. Потолок MAX_TELEGRAM_VISIBLE=512: список приезжает из браузера и сохраняется в файл.

# config_path

Фактический путь TOML-конфига плагина Telegram (plugins/telegram/src/config.rs). Непустой env FORGE_TELEGRAM_CONFIG_PATH побеждает, иначе default_config_path() (~/.config/forge/telegram.toml; без HOME — ./telegram.toml). Используется в TelegramConfig::load() (чтение) и TelegramConfig::save_credentials() (запись) — load и save всегда работают с одним и тем же файлом. Назначение: контейнеры/systemd с нестандартным layout и герметичные тесты — без override load() читал бы реальный конфиг машины разработчика (из-за этого падал telegram_smoke::test_config_load_with_temp_paths на машинах с настоящими api_id/api_hash). Тесты: config::tests::config_path_env_overrides_load_and_save, config::tests::load_does_not_panic_without_file_and_env, telegram_smoke::test_config_load_with_temp_paths. ENV_KEYS в unit-тестах включает FORGE_TELEGRAM_CONFIG_PATH для clear_env.

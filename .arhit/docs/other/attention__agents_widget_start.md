# attention::agents_widget_start

Срез полосы фоновых агентов с низа панели — часть гейта attention::prompt_at_bottom.

ЗАЧЕМ. Claude Code рисует под областью ввода полосу живых backgrounded-агентов:

    ⏺ main
    ◯ run-phase (+6)  Delegating CrmRecurrenceRules…   3h 41m · ↓ 718.3k tokens

Она держится на экране всё время, пока агенты живы. Гейт prompt_at_bottom смотрит только последние 4 непустые строки панели, поэтому полоса (плюс двухстрочный статус-бар) выталкивала footer prompt'а ('Esc to cancel · Tab to amend · ctrl+e to explain') на пятую позицию снизу. Гейт отвечал false → classify_prompt возвращал None → авто-апрув молчал и свечение не загоралось, хотя 'Do you want to proceed?' висел на экране. Живой кейс: tmux-сессия 213 (проект aira), backgrounded run-phase с шестью потомками; prompt от суб-агента general-purpose не подтверждался, при этом соседние inline-prompt'ы в той же панели подтверждались штатно.

СИГНАТУРА. fn agents_widget_start(lines: &[&str]) -> Option<usize> — принимает список НЕПУСТЫХ строк панели, возвращает индекс первой строки полосы либо None, если полосы внизу нет.

АЛГОРИТМ. Скан снизу вверх: строки с маркером AGENT_ROW_MARKER ('◯') считаются строками агентов; первая строка с AGENT_HEAD_MARKER ('⏺') засчитывается заголовком полосы и завершает срез — но ТОЛЬКО если под ней уже нашлась хотя бы одна строка '◯'. Любая другая строка → None. Глубина ограничена AGENTS_WIDGET_MAX_LINES = 24.

ПОЧЕМУ ЗАГОЛОВОК ОБЯЗАТЕЛЕН. '⏺' — ещё и маркер обычного сообщения ассистента в потоке вывода. Срезать одиночную строку '⏺ Готово' означало бы сдвинуть границу вверх и принять УЖЕ ОТВЕЧЕННЫЙ prompt, оставшийся выше на экране, за активный. '◯' встречается только в полосе, поэтому именно он служит признаком блока. По той же причине '⏺'/'◯' НЕ входят в TODO_ITEM_MARKERS (см. attention::todo_widget_start).

ЗАЩИТА ОТ ПРОЦИТИРОВАННОГО PROMPT'а СОХРАНЯЕТСЯ. Под цитатой prompt'а в diff/логе всегда идут поле ввода и статус-бар ('───', '⏵⏵ auto mode on'), которые под маркеры не подходят: после среза полосы низом панели становится статус-бар, footer не открывается, гейт по-прежнему отвечает false. Зафиксировано тестом agents_widget_trim_keeps_quoted_prompt_protection.

СВЯЗИ. Вызывается из attention::trim_bottom_widgets — итеративного среза, который чередует todo_widget_start и agents_widget_start, пока граница едет вверх (оба блока могут быть на экране одновременно). trim_bottom_widgets вызывается из attention::prompt_at_bottom, а тот — из attention::detect_claude_prompt (свечение) и auto_approve::classify_prompt (авто-апрув).

ОГРАНИЧЕНИЕ. Срез помогает только когда полоса РАЗВЁРНУТА и prompt нарисован на экране. Если backgrounded-агент свёрнут ('Backgrounded agent (↓ to manage · ctrl+o to expand)'), его prompt Claude Code не рисует в панели вообще — tmux capture-pane его не видит, и ни свечение, ни авто-апрув по нему принципиально не сработают.

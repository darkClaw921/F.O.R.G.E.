# forge_voice::transcribe

Модуль `plugins/voice/src/transcribe.rs` (327 строк) — САМО ЗАДАНИЕ расшифровки:
подготовка → движок → стор, с прогрессом наружу.

# ЗАЧЕМ

Между «лестница пропустила» (`gate`) и «текст лежит в сторе» (`store`) есть общий для
обоих движков и трёх мессенджеров сценарий. Он собран здесь, поэтому плагину остаётся
только конверт: собрать `TranscribeJob`, отдать его в `VoiceHub` и превращать кадры
`VoiceSink` в свой WS-протокол.

# КЛЮЧЕВЫЕ ЭЛЕМЕНТЫ

- `TranscribeJob` — ключ вложения, путь к файлу, план движка, длительность, `force`.
- `run(job, ctx) -> Result<Transcript, VoiceError>` — сценарий целиком:
  1. `audio::prepare` под цель движка (`PREPARE_PERCENT = 5` — доля прогресса на этот шаг);
  2. локально — `whisper::run` c `BEAM_SIZE = 5`, облако — `cloud::stt` окнами;
  3. сегменты в `Transcript`, запись в `TranscriptStore`;
  4. скретч убирается `Drop`-ом `ScratchDir` при ЛЮБОМ исходе.
- Прогресс всю дорогу идёт в `VoiceSink`, поэтому фронт видит движение и на подготовке,
  и на самом прогоне.

# ОГРАНИЧЕНИЯ

Функция ничего не знает про HTTP, WS и `AppState`; отмена приходит снаружи (через
`VoiceHub`), она не опрашивает никакие глобальные флаги.

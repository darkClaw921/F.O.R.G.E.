# forgeObserveMeeting

observe.js: полный снимок встречи глазами проб. Возвращает perf/unix (ЕДИНСТВЕННОЕ измерение обоих часов в один момент — из него Rust вычисляет начало оси), href, participants, active, speaking, mic/cam ('on'|'off'|'unknown' — «не знаю» это третье полноправное значение, ложное «уже выключен» стоило бы бота, гудящего в чужую встречу), ui{continueInBrowser,nameInput,joinButton,leaveButton,lobby,captcha,joinAudio}, denied, ended, postCall. Поля фаз 8-10: `ui.joinAudio` — кнопка «подключить звук компьютера» (у веб-клиента Zoom без клика по ней в странице нет НИ ОДНОГО источника звука); `denied` — площадка ОТКАЗАЛА во входе, отдельный сигнал, а не разновидность «ничего знакомого на экране»: Google Meet при ограниченном доступе хоста отклоняет анонимную заявку автоматически и за секунды, и разница между «нам отказали» и «мы ещё ждём» — это разница между честным объяснением человеку и минутой молчаливого ожидания таймаута. clock приходит параметром, чтобы функция осталась чистой и проверяемой в node --test.

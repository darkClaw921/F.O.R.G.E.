# tmux-web/tests/frontend/agent_stats_browser.test.mjs

Настоящий Chrome CDP harness без npm-зависимостей: Node HTTP отдаёт существующий index/CSS/ES modules и browser-only fixture API, затем собственный Chrome child с временным профилем подключается через DevToolsActivePort и встроенный WebSocket. Runtime.evaluate ждёт 13 assertions actual production modules; Page.captureScreenshot сохраняет PNG dark/light/mobile, включая раскрытые настройки с длинными draft root/profile paths. Проверяются mode switch, live/null metrics, manual binding, hidden polling, lazy settings, DOM safety и viewport overflow. Fixture API изолировано в тестовом probe, production код использует обычный apiFetch. Chrome завершается по собственному child process; пользовательский daemon/CLI/LLM не запускается. При отсутствии Chrome тест сообщает явный skip; на текущей приёмке все три браузерных режима реально прошли.

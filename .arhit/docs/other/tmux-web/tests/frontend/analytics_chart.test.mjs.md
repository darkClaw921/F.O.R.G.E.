# tmux-web/tests/frontend/analytics_chart.test.mjs

Тест SVG-кита аналитики: геометрия, тема и отзывчивость на крошечном фейковом DOM (без jsdom).

СТИЛЬ ПРОЕКТА: хелперы ok/eq, счётчик проверок, process.exit(failures ? 1 : 0). Запуск: node tmux-web/tests/frontend/analytics_chart.test.mjs; из cargo test подхватывается через tests/analytics_frontend_suite.rs.

ЧТО ПРОВЕРЯЕТ (334 проверки):
1. Примитивы: niceTicks на [0,0] и на одной точке (делений > 1, шкала не схлопывается, значения конечны), linearScale на вырожденном домене и на NaN, size/finite/clamp, все форматтеры.
2. Палитру: порядок SERIES_TOKENS зафиксирован (страж — перестановка ломает проверенные валидатором ΔE), SERIES_MAX=5, foldSeries сворачивает хвост в «Другое» с суммой, themeColors читает --chart-N с приоритетом над семантическими токенами, ПУСТАЯ тема даёт currentColor, а не хекс.
3. Семь чартов × четыре состояния (пусто / одна точка / все нули / боевые данные): рисуется без исключения, в контейнере ровно один <svg> в пространстве имён SVG, есть viewBox + preserveAspectRatio + width=100%, ни NaN/undefined/Infinity, ни отрицательных x/y/width/height/r/cx/cy/stroke-width, путь d без мусора, цвета — ТОЛЬКО подменённые сентинелы темы. Плюс заглушка «нет данных», живая ось на нулях и update() без второй канвы.
4. Легенды и подсказки: <title> у каждой точки, легенда обязательна от двух серий и не рисуется при одной, подпись легенды красится текстовым токеном (идентичность не только цветом), правая ось barChart масштабируется по своему ряду, heatmap на нулевой матрице держит все 168 ячеек в минимуме шкалы и подписывает ночь, пустой бакет гистограммы сохраняет подпись.
5. Стражи исходника chart.js: нет innerHTML, нет импортов и внешних библиотек, нет createElement без NS, нет хардкод-цветов (#hex).

ФЕЙКОВЫЙ DOM. ~90 строк: createElementNS, appendChild/removeChild/firstChild, setAttribute/getAttribute, textContent, defaultView.getComputedStyle с картой переменных-сентинелов. Возможен потому, что кит намеренно берёт документ из container.ownerDocument.

МУТАЦИОННАЯ ПРОВЕРКА выполнена: снятие size() (разрешить отрицательные размеры) роняет тест.

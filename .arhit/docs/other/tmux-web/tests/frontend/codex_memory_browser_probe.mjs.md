# tmux-web/tests/frontend/codex_memory_browser_probe.mjs

Browser regression probe production openClaudeMemoryModal с fixture-only window.fetch и отдельными Claude/Codex DTO. Проверяет 17 пользовательских сценариев: Claude path query/index/notes/internal back links/edit endpoint, Codex global GET/scope/separate native-subagent groups, nested rollout и ../ links, missing-link blocking, Codex subagent PUT full relative key, late PUT при переключении источника, late GET даже при транспорте игнорирующем AbortSignal, subagent-only без native index, empty state, truncated warning при полном пропуске файлов, закрытие pending read без alert/воскрешения, viewport fit длинных путей. Никакие настоящие файлы памяти не читаются/пишутся, все /api/* перехвачены. Финальный rendered Codex fixture остаётся на странице для screenshot; проверки выполняются в dark/light/mobile harness.

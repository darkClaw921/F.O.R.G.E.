# tmux-web/tests/frontend/agent_stats_history.test.mjs

Поведенческая проверка настоящего createAgentHistory и SVG-kit на минимальном DOM без jsdom и сети. Инъецирует Document с createElementNS и реальной идентичностью focus. Проверяет раздельные API/reported стоимости, сумму/union времени, reasoning без двойного счёта, null-метрики, отсутствие нулевых столбцов для неизвестного дня, понятные Copilot и partial подписи. Названия с HTML-подобным текстом остаются текстом. Проверяет next/prev offset, доступность кнопок на последней странице, сохранение тех же кнопок и фокуса при обновлении, сохранение раскрытого списка моделей, отсутствие NaN/Infinity в SVG, aria-label графиков, empty/null response и teardown без повторной отрисовки. Запуск node tmux-web/tests/frontend/agent_stats_history.test.mjs.

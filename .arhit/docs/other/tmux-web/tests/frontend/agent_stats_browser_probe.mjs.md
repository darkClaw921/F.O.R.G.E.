# tmux-web/tests/frontend/agent_stats_browser_probe.mjs

Browser fixture probe for the actual production index, CSS and ES module graph. All API calls are intercepted with fixture responses, so no user daemon, agent, binding or account is modified. It exercises agent live rows, tuple-preserving binding requests, polling lifecycle, historical SVG charts, provider metadata and responsive settings. Added orange attention coverage using the real buildSessionItem component and state: a waiting permission/question suppresses an older cyan next-step suggestion, uses the resolved orange warning palette even when active and generating, and removes the warning class once answered. Checks run in Chrome through the existing browser runner across dark/light desktop and mobile viewports, with uncaught exceptions and overflow reported as failures. Temporary probe nodes and state are restored before the analytics checks.

# tmux-web/src/agents/prices.json

Bundled price catalogue schema1 dated 2026-10-25. Source rows are independently transcribed numeric USD-per-million token tariffs from https://developers.openai.com/api/docs/pricing, official GPT-5.3-Codex/GPT-5.4 model pages, and https://platform.claude.com/docs/en/about-claude/pricing. Eighteen model families cover GPT-6 Astra/Sol/Luna, GPT-5.3 Codex, GPT-5.4, current/legacy Claude Opus/Sonnet/Haiku and Fable/Mythos5.1. Each row has source, canonical model, exact aliases and rates; only verified fast modes and context thresholds are included. OpenAI write TTLs remain unpriceable when not supplied by journals; Claude rates include five-minute and one-hour writes. This is a fallback estimate table, not a bill or account subscription price. Pricing module validates it and permits schema-compatible HTTPS catalogue replacement while preserving the last good copy.

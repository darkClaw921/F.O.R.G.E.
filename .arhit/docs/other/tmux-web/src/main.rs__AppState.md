# tmux-web/src/main.rs::AppState

Global axum application state includes AgentStatsStore agents and AgentRuntime agent_runtime, both cheap-clonable shared handles. The agent index is independent of the existing lazy Claude AnalyticsStore: it ingests metadata-only journal history in bounded background batches while serving live state to tab indicators and /api/agents. AgentRuntime observes exact pane/PID/start/session evidence, with manual binding support and no cwd-only guessing. Startup constructs these handles without parsing the archive on the HTTP executor, then spawns ingestion and runtime workers once. Graceful shutdown aborts recurring agent jobs and flushes valid metadata cursor/cache state before exiting. Unit-test AppState factory uses discoverDefaults=false and no private paths so route tests never scan actual user profiles. Existing plugin, auth, remote, TODO, messenger and theme fields retain their roles.

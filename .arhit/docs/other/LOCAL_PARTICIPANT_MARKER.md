# LOCAL_PARTICIPANT_MARKER

Имя пробы «своя плитка» (plugins/meet/src/bot/platforms.rs, модуль probe). Единственная проба, которая ВЫЧИТАЕТ элемент из выборки участников, а не добавляет.

Появилась в Ф13 из живого замера на vcc.airlabs.pro: LiveKit рисует бота такой же .lk-participant-tile, что и людей, и без вычитания бот попадал в собственный список участников. Цена ошибки видна не сразу — «Участник 1» в транскрипте оказывался ботом, а функция PageSnapshot::others спасала только пока имя бота в DOM совпадало с именем из заявки посимвольно.

Пустая проба — законное состояние и значение по умолчанию у всех прочих площадок: вычитать нечего, список остаётся прежним. Значение у vcc заморожено тестом only_vcc_subtracts_its_own_tile.

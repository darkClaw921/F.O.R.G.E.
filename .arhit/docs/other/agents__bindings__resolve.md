# agents::bindings::resolve

Resolve provider/session evidence to physical pane IDs, then expand linked-session aliases. BindingBook manual and detached choices are retained for the verified PID/start lifetime independently of task-history query windows: an interactive CLI may remain alive more than a day after its completed task falls outside metadata retention. If task metadata is absent, keep the choice but emit no binding; the next task on the same native session/process restores the choice. Offline-interrupted epochs remain available through store.runtime_tasks and do not remove an existing manual binding; later Active work on that PID/root reuses it. A new explicit manual selection replaces other inactive choices for that same process identity. PID reuse, confirmed pane/process disappearance and explicit detach are handled separately from missing metadata; partial identity probes retain the choice without asserting new work. Tests include manual→offline cut→reconcile→new active epoch, metadata cutoff→new task restoration, process-lifetime detach suppression, wrappers, linked panes, ambiguous independent CLIs and PID reuse.

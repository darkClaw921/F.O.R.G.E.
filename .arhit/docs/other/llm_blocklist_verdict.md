# llm_blocklist_verdict

auto_approve::llm_blocklist_verdict(command, cwd) (tmux-web/src/auto_approve.rs) — LLM-эскалация блоклиста: спрашивает Sonnet через локальный claude -p (LLM_MODEL=sonnet, LLM_TIMEOUT=90с, cwd процесса — временная папка, чтобы не тянуть CLAUDE.md), можно ли авто-подтвердить команду, попавшую в блоклист. Ответ — один JSON {approve, reason}; из вывода вырезается диапазон от первой { до последней }. Исходы: Verdict(bool), Unavailable (нет бинарника claude — эскалация гаснет до конца процесса), Failed (разовый сбой, не кэшируется). Вердикты кэшируются в run(): положительный навсегда, отрицательный на NEGATIVE_VERDICT_TTL=300с. 23.09.2026: в запрос добавлен параметр cwd — рабочая директория ПАНЕЛИ (crate::tmux::pane_cwd), без неё модель считала чужим проектом любой абсолютный путь (живьём отказывала релизной команде с 'cd в чужой репозиторий'), а также строка про штатные операции разработки (смена ветки, pull --ff-only, публикация тега, мерж PR, деплой). Текст команды перед отправкой очищается strip_cli_notices.

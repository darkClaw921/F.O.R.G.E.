# rename_portal_in

plugins/bitrix/src/config.rs (Ф2 мультипортальности Битрикса). Переименовывает портал в bitrix.toml: меняет ТОЛЬКО title записи [[portals]], не трогая ни id, ни секрет. Возвращает true, если портал с таким id в файле нашёлся; отсутствующий портал — не ошибка и не повод переписывать файл. Пустое (или из одних пробелов) имя означает «вернуть автоматическую подпись»: ключ title из записи исчезает, и фронт снова показывает хост портала. Если имя не изменилось, файл не переписывается вовсе — переписывать его ради тех же байтов значит зря рисковать секретом. Идёт через save_portals_to, поэтому наследует все четыре инварианта записи: read-modify-write, права 0600 в момент создания файла, атомарность (tmp + fsync + rename), удаление tmp при любой ошибке. Вызывается из B24Registry::rename.

# Bucket

plugins/vk/src/api/throttle.rs. Чистое ядро троттлера VK: ведро токенов с непрерывным пополнением. Bucket::new(rps, now) создаёт ПОЛНОЕ ведро ёмкостью max(rps, 1) — ёмкость ровно rps при rps<1 не вместила бы целый токен и не пропустила бы НИ ОДНОГО запроса. Bucket::take(now) -> Result<(), Duration>: Ok — идти в сеть, Err(d) — ждать d. Ни асинхронности, ни Instant::now() внутри: всё время приходит параметром, поэтому арифметика лимита проверяется мгновенными тестами. Время, идущее назад, не наливает токенов. Гейт: 3 подряд Ok, 4-й Err(~333 мс) при rps=3, +334 мс Ok, +10 c не больше capacity.

# take_uploads

Потребляет записи реестра загрузок под переданные upload_id (plugins/vk/src/routes/upload.rs). Работает по принципу «всё или ничего»: если хотя бы одного идентификатора нет, staging уже взятых записей подчищается немедленно и возвращается 409 invalid_state. Потребление БЕЗВОЗВРАТНО и это осознанный размен: повторный POST /messages с тем же upload_id обязан получить 409, а не отправить файл второй раз. Двойной клик по «Отправить» и автоповтор фронта случаются куда чаще неудачной заливки, а цена ошибок разная — лишнее сообщение у собеседника не отзывается, файл же всегда можно залить заново. Вызывается из routes/dialogs.rs::post_message перед build_attachment.

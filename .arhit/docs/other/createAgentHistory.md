# createAgentHistory

Создаёт исторический dashboard в переданном DOM-host. Параметр onPageChange получает новый offset, doc позволяет тестировать настоящий рендерер и SVG-kit без браузерной библиотеки. Возвращаемые update(summary,sessions,{offset,limit}), redraw() и destroy() отделяют загрузку данных и lifecycle от отрисовки. update меняет только данные при изменившемся JSON-снимке, сохраняя кнопки страниц и раскрытия разрезов. Отрицательные/нечисловые метрики форматируются общими nullable helpers; provider cost никогда не прибавляется к API estimate, reasoning не прибавляется к output. Графики токенов и оценки используют только известные дневные значения; время отображается двумя линиями одной шкалы. Неизвестные значения показаны как Нет данных. destroy идемпотентно запрещает дальнейшие update/redraw и очищает свой host.

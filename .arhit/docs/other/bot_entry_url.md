# bot_entry_url

providers.rs: адрес, по которому бот РЕАЛЬНО открывает страницу. Единственное место, где он расходится с canonical_url, и только у Zoom: по zoom.us/j/<id> открывается страница «скачайте приложение», а веб-клиент живёт на app.zoom.us/wc/join/<id> (ZOOM_WEB_CLIENT_HOST). Пароль ?pwd= переносится — без него веб-клиент спросит его руками, и вход упрётся в человека на ровном месте. Подменять canonical_url нельзя: он показывается человеку, хранится в записи встречи и держит идентичность комнаты через url_key. Персональная комната /my/<имя> номера не имеет — веб-клиент собирать не из чего, возвращается канонический адрес. Зовётся из ChromeBotFactory::entry_url.

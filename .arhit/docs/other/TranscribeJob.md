# TranscribeJob

Задание расшифровки (forge_voice::transcribe): всё, что нужно прогону — VoiceConfig, EnginePlan из лестницы, исходный файл медиа-кэша, каталог кэша, стор и координаты вложения. Исполняется функцией transcribe::run, которую плагин отдаёт замыканием в VoiceHub::start. Текст записывается в стор ДО кадра done (иначе фронт, получив done, дёрнул бы GET transcript и получил бы пусто), пустой результат в стор не пишется вовсе и отвечает кодом voice_empty.

# agents::index::fold_refs

Deterministically folds borrowed metadata events into tasks and usage. Unique BTreeMap key ordering, first-source ownership, earliest billing timestamp, latest streaming activity, native/cumulative suppression, parent rollup, interruption handling and event tie ordering remain unchanged. Cow borrows unchanged contributions and owns only duplicate usage records that need merging; streamed maxima cannot mutate cached source input. Canonical identity strings are memoized per fold instead of encoded for every historical event. The coordinator calls this helper directly on stable source references, avoiding a deep clone of the full history. Tests cover immutable streamed merge plus existing four-provider, source replacement, cache/restart and interruption equivalence.

# agents::providers::parse

Parse one complete local agent JSONL line into provider-neutral facts. Parameters select provider/profile, native-session fallback, bytes, file modification timestamp, original byte-offset sequence and mutable ParserState. Every emitted event retains sequence for deterministic ordering when consecutive task endings and starts share one millisecond. Native event IDs and turn/task IDs prevent same-time task collisions. Codex task_started opens and task_complete/turn_aborted closes, preserving provider timestamps and duration. Only the first session_meta defines log identity/root/source; copied later headers change cumulative-total namespace only. Native response ownership prefers explicit payload.session_id then this logs own session, never a copied header. Native keys are native:<owner>:<response>; cumulative fallback keys cumulative:<totals-owner>:<total>. Native records disable future cumulative fallback in their own source; ingestion handles cross-source native priority and response dedup without dropping unrelated parent usage. Claude real user prompts open, tools continue, final stop reasons close, API errors and interruptions abort. Sidechain usage links child to root without owning lifecycle. Only own text blocks are checked for interruption, not quoted tool-result text; Bash ends by matching tool_use_id. Copilot root tasks span tool iterations, matching turnId closes only after a final non-tool response; child lifecycle is ignored. Session/root-or-agent/API IDs dedup requests, late model attribution updates the same response. Shutdown counters emit deltas or reset totals and reconcile unresolved request deficits once. Unknown token metrics stay null, reasoning stays within output, Claude cache TTL breakdown is retained when reported. Parser state stores metadata only and invalid records are ignored.

# packaging/aur/devforge/.SRCINFO

Checked-in metadata template paired with PKGBUILD for devforge v0.1.75-1. It duplicates package identity, supported architectures, dependencies, options and the version-qualified source alias required by AUR clients. REPLACE_WITH_SHA256 explicitly marks this as a source template; the installable external AUR metadata is generated after the release tag exists and contains the exact SHA256 of its source archive. Do not publish this placeholder to AUR and do not use SKIP. After final substitution, use makepkg --printsrcinfo in an Arch environment, compare fields with PKGBUILD, and push the generated metadata together with the recipe. The checked-in recipe and metadata version/source values are kept synchronized.

# packaging/aur/devforge/PKGBUILD

Checked-in AUR source template for devforge v0.1.75-1 on x86_64/aarch64. The source alias and upstream URL derive from pkgname/pkgver; the extracted F.O.R.G.E.-<version> workspace builds devforge with cargo build --release --locked -p devforge. Runtime dependencies are tmux, gcc-libs, glibc; Rust/Cargo are build requirements and optional terminal helpers remain declared. The options !lto avoids overriding workspace thin LTO. This source template uses explicit REPLACE_WITH_SHA256, not an old digest or SKIP, because it is itself included in the tagged archive. Before publishing to the external AUR git repository, release tooling substitutes the exact archive digest and generates matching .SRCINFO. The source template is not directly installable until that substitution. Existing build/check/package functions are retained; this release changes metadata only and validates Bash syntax. The external AUR repository must contain actual integrity metadata.

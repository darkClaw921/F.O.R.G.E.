# forgeReadParticipants

Читает участников встречи по DOM-пробам (plugins/meet/src/bot/inject/observe.js).

Плитки берутся пробой participant, имя — вложенной пробой participant_name, а при её промахе текстом самой плитки: протухший participant_name не имеет права обнулить список, если сами плитки ещё находятся. Пустое имя законно — его подписывает уже Rust («Участник N»), потому что нумерация обязана быть устойчивой между наблюдениями, а DOM о своей нумерации ничего не знает.

СВОЯ ПЛИТКА ВЫЧИТАЕТСЯ ЗДЕСЬ (Ф13), пробой local_participant_marker — единственной пробой, которая убирает элемент из выборки, а не добавляет. У LiveKit (vcc.airlabs.pro) бот нарисован такой же .lk-participant-tile, что и люди, и отличается ровно атрибутом data-lk-local-participant=true. Сравнение по имени в Rust работало бы только пока площадка не тронула имя бота: обрезала пробелы, приписала «(вы)» — и бот снова участник самому себе.

Проба пуста у всех площадок, кроме vcc, и тогда цикл идёт как прежде: forgeMarked на пустом списке кандидатов даёт false. Протухшая проба тоже не теряет участников — бот просто снова попадает в собственный список (тесты на оба случая есть в tests/js/observe.test.mjs).

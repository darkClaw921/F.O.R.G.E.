# agents.settings.submit

Обрабатывает submit формы и click Save единым путём с preventDefault и singleflight флагом saving. read проверяет глубину истории, HTTPS URL и каталоги, вычисляет неуказанный профиль. configure получает только публичный restricted DTO. Успешный ответ не перерисовывает поля: новые правки, сделанные во время запроса, остаются draft с соответствующей подписью. Ошибки и запоздавшие ответы скрытого экрана не стирают пользовательский ввод.

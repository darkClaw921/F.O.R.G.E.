# agents::providers::ParserState

Serializable per-source metadata required to resume JSONL parsing without retaining conversation payloads. Public fields session/project/model/parent/turn_open/fast/running_commands expose current journal context to ingestion. Codex state preserves the first own session metadata while later session_meta headers update only the running-total namespace; per-namespace previous totals and native-record flags prevent repeated cumulative usage. Claude state retains outstanding Bash tool-use IDs for matching results and offline exception handling. Copilot retains turn ID/final-response status, request-to-model attribution, per-model counted/reported requests and prior shutdown token totals. A copied or rewritten source must reset this state and replace its contributions; an append carries it forward. IDs and counters are metadata only; no user message or assistant text is serialized.

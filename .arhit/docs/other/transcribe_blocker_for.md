# transcribe_blocker_for

DepsReport::transcribe_blocker_for(backend, cloud_configured) -> Option<&'static str> в plugins/meet/src/deps.rs — что мешает расшифровать ВЫБРАННЫМ путём. Локальный путь делегирует старому transcribe_blocker (whisper_unavailable -> model_unavailable -> metal_unavailable). Облачный путь: отсутствие whisper-cli, весов и Metal перестаёт быть препятствием вовсе (отказ по ним был бы отказом по требованию, которого никто не предъявлял), зато мешают отсутствие ключа (cloud_not_configured) и отсутствие ffmpeg (ffmpeg_unavailable) — окна аудио режутся и сжимаются в mp3 нашей стороной, потому что сырой WAV роняет шлюз polza.ai, а предел сервиса около 60 секунд по стене на запрос. До первой пробы (probed=false) не мешает ничего: «ещё не смотрели» не равно «ничего нет». Зовётся из pipeline::run (этап расшифровки) и из routes::meetings::start_stage (лестница 409 у retry?from=).

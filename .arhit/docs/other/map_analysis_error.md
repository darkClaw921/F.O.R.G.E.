# map_analysis_error

plugins/vk/src/routes/analysis.rs. Единая таблица перевода AnalysisError (общее ядро forge-chat-analysis) в ApiError плагина VK: Busy(n) -> 409 invalid_state с прежним текстом «уже идёт N анализа(ов) по другим беседам…», CliUnavailable -> 409 claude_unavailable с путём из state.analysis.cli_path(), NoPreviousAnalysis -> 400 invalid_input (константа NO_PREVIOUS_ANALYSIS, общая с build_task), Storage -> 500 storage_failed. Существует потому, что крейт про HTTP не знает: коды и тексты у трёх мессенджеров свои. Путь к бинарю берётся здесь, а не приезжает в ошибке: Display ошибки уходит в логи, а путь — кусок файловой системы машины; показывать его — решение плагина. Соответствие кодов ровно такое, каким было до выноса ядра: коды ответа — публичный контракт вкладки.

# VkConfig

Конфигурация плагина VK (plugins/vk/src/config.rs): defaults -> необязательный ~/.config/forge/vk.toml -> env-override FORGE_VK_* -> validate_and_fix. Serialize не выводится намеренно — структура держит SecretToken. Загрузка никогда не падает: невалидные значения чинятся дефолтами с warn-логом. АЧ-Ф3 добавил четыре поля анализа чата, все с serde(default) и клампами: claude_cli_path (default $HOME/.local/bin/claude, тот же дефолт что у forge-echo — плагины запускают ОДИН И ТОТ ЖЕ CLI; читается из TOML, в отличие от config_path/prompts_path, потому что это настройка машины; ровно этот путь называет ошибка 409 claude_unavailable); analysis_timeout_secs (300, 0 = таймаут выключен, уезжает в ClaudeRunner::with_run_timeout); analysis_max_chars (60000, кламп 5000..=200000 — бюджет транскрипта в code points); analysis_model (Option<String>, default Some("sonnet") — полагаться на дефолт CLI нельзя, иначе стоимость анализа зависела бы от чужих настроек ~/.claude). Env-ключи: FORGE_VK_CLAUDE_CLI_PATH, FORGE_VK_ANALYSIS_TIMEOUT_SECS, FORGE_VK_ANALYSIS_MAX_CHARS, FORGE_VK_ANALYSIS_MODEL (пустая строка у последнего ЗНАЧИМА: 'не передавать --model вовсе'). Существование бинаря в validate_and_fix НЕ проверяется: анализ не условие работы вкладки, отказ выносит роут.

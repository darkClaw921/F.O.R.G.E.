# reorder_portals_in

plugins/bitrix/src/config.rs (Ф2 мультипортальности Битрикса). Переставляет записи [[portals]] в bitrix.toml в порядке ids — это порядок вкладок во фронте. Порядок в файле — ЕДИНСТВЕННОЕ место, где он живёт, поэтому перестановка вкладок обязана доезжать до диска: иначе она забывалась бы при каждом перезапуске devforge. Устойчива к неполному и грязному списку: неизвестные id игнорируются, а не перечисленные порталы уезжают в хвост с сохранением относительного порядка — ни один портал не теряется, потому что список приходит из фронта, а фронт мог отстать от состава реестра на один запрос. Пустой список порталов — нечего переставлять, выходит без записи. Правило перестановки вынесено в reorder_by_ids и переиспользуется реестром в памяти (B24Registry::reorder): разойдись эти два порядка — вкладки после перезапуска встали бы иначе, чем их только что перетащили. Запись идёт через save_portals_to со всеми четырьмя инвариантами.

# tmux::list_agent_panes

Read-only bounded async inventory of every tmux window and pane including inactive windows and linked-session aliases. Includes stable pane/session/window IDs, shell PID, controlling TTY, canonical project path, active flags and an ephemeral native terminal title. The title uses tmux substitution to strip ASCII control characters before unit-separator row serialization; titles are serde-skipped and never returned to browsers or caches. The Codex runtime compares the native explicit name to read-only state SQLite metadata to identify CLIs whose journals belong to a shared daemon. Invalid structural rows fail the inventory rather than deleting bindings; an absent tmux server is reliably empty. Linked windows expand to each session alias using existing session metadata. Parser tests cover inactive panes, separate PID identity despite shared cwd, title privacy and malformed-row unknown behavior. Does not alter Claude prompt capture or other terminal APIs.

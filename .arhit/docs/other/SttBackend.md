# SttBackend

Перечисление конфига forge-meet: где считается РАСШИФРОВКА. Варианты cloud (polza.ai openai/whisper-1) и local (whisper.cpp на Metal); значение по умолчанию — Cloud, это прямое требование пользователя («по стандарту всегда облачная») и одновременно единственный вариант, при котором плагин работает на чистой машине: локальный путь требует установленного whisper-cli, весов на 1,6 ГБ и живого Metal. Методы parse (принимает также синонимы polza/whisper), as_str, is_cloud, is_local, константа ALL для списка вариантов в UI. Переключатель НЕЗАВИСИМ от SummaryBackend: законна любая из четырёх комбинаций. От значения зависят: DepsReport::transcribe_blocker_for, ветка расшифровки в pipeline::run, SpeakerConfig::allow_word_split и поле config.stt_backend в GET /api/meet/status. Файл: plugins/meet/src/config.rs.

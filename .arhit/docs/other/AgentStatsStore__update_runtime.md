# AgentStatsStore::update_runtime

Apply pane bindings, process observations and connectivity metadata under the ingestion gate. None probes are unknown, never exit. A confirmed false observation now creates a persisted Interrupted barrier for its exact current task epoch, rather than merely decorating a snapshot as Ended. Unlike an inferred offline cut, confirmed_exit=true overrides pending Bash and prior model replies because the process is known to have stopped. The old task stays incomplete with completed=None, is excluded from Echo recent_tasks, and its last-activity interval remains in history. New Started, Active or real Usage after the barrier creates a new process-resume task ID and startedAt, even when Claude resumes the same JSONL stream within one hour and ParserState still emits Active. Runtime tombstones also retain the task ID they closed, so same-millisecond work in a new epoch cannot be ended by an older false observation; a second confirmed exit can close the new epoch independently. Bound process identities remain metadata, not command arguments. Claude offline cuts still use monotonic twenty-second grace while offline, with Bash/model-reply exceptions; reconnect alone clears pending grace and does not create a new cut. All interruption barriers are immediately cached and replayed into coherent live/history/statistics. Tests cover kill/restart/same-file resume, repeated exits and new PID binding, source-only Echo ends, explicit journal completion, time/token totals, offline exceptions, late replies and concurrent config updates.

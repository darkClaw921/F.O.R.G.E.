# list

repo::segments::list (plugins/meet/src/db/repo/segments.rs) — ВСЕ сегменты встречи разом, по возрастанию idx, страницами по 2000 поверх page(). Существует ради проверок 'в базе не появилось ни одной реплики': там нужен весь список, а просить page() с выдуманным потолком значило бы проверять 'первые 2000 реплик пусты' вместо 'реплик нет'. В боевом пути не зовётся — интерфейс листает расшифровку страницами, потому что час встречи это 600–1200 реплик.

# mock_ffmpeg_window_slicer

Мок ffmpeg для тестов облачной расшифровки (plugins/meet/src/testing/mocks.rs). Пишет в выходной файл строку ID3mock ss=<начало> t=<длительность>, то есть окно, которое у него попросили. Единственный способ без настоящего кодека проверить главный инвариант Ф14: локальный стенд polza_stub читает эти значения из принятого файла и рвёт соединение на куске длиннее 90 секунд, как живой polza.ai рвёт TCP на 62-й секунде.

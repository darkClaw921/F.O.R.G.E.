# attention::todo_widget_start

Находит индекс первой строки TODO-виджета Claude Code в хвосте панели (список только непустых строк) — либо None, если виджета внизу нет. Используется исключительно в attention::prompt_at_bottom, чтобы срезать виджет перед проверкой четырёх хвостовых строк.

Что считается виджетом: заголовок вида '5 tasks (0 done, 1 in progress, 4 open)' (проверяется is_todo_header: строка начинается с числа, затем слово 'task'), под которым идут ТОЛЬКО пункты с маркерами из TODO_ITEM_MARKERS ('◼' в работе, '◻' открытая, '☑'/'☐'/'✓'/'✔' — формы соседних версий CLI). Обход идёт с конца; первая строка, не подходящая ни под пункт, ни под заголовок, обрывает поиск (None). Глубина ограничена TODO_WIDGET_MAX_LINES = 24 строки.

Два условия-предохранителя:
- заголовок засчитывается только при items > 0 — одинокая строка 'N tasks (…)' в выводе команды виджетом не считается (тест todo_header_without_items_is_not_a_widget);
- '⏺' и '◯' в TODO_ITEM_MARKERS НЕ входят: '⏺' — маркер обычного сообщения ассистента в потоке, и его срез позволил бы принять уже отвеченный prompt, оставшийся выше на экране, за активный.

Причина появления: живой кейс сессии 12312312 — при висящем 'Do you want to proceed?' под prompt'ом рисовались 5 задач, footer 'Esc to cancel · Tab to amend · ctrl+e to explain' уезжал за окно из четырёх хвостовых строк, гейт возвращал false → авто-апрув не жал ничего и needs_attention оставался false. См. [[attention::prompt_at_bottom]].

# sanitize_extra_args

Просеивает аргументы whisper, пришедшие СНАРУЖИ — из файла настроек пользователя (plugins/voice/src/whisper.rs). build_args не может собрать -ng по построению, но дополнительные аргументы приходят строкой из конфига, и там можно написать что угодно. Запрещённый флаг (FORBIDDEN_ARGS = [-ng, --no-gpu]) выбрасывается и называется вслух через tracing::warn: молча проглотить его значило бы вернуть ровно ту дыру, ради закрытия которой FORBIDDEN_ARGS существует, а отказать целиком — сломать запуск из-за одной лишней строки в конфиге. Отсеивается не только точное совпадение: -ngl и -ng=1 тоже не проходят (проверка по префиксу). Функция добавлена в Фазе 1 фичи голосовых: до неё такой двери в argv просто не существовало, потому что дополнительных аргументов у forge-meet не было. Покрыта тестом forbidden_flags_from_the_config_are_dropped.

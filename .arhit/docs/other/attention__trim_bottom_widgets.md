# attention::trim_bottom_widgets

Граница «настоящего низа панели» для attention::prompt_at_bottom.

СИГНАТУРА. fn trim_bottom_widgets(lines: &[&str]) -> usize — принимает список НЕПУСТЫХ строк панели, возвращает индекс первой строки хвостовых виджетов либо lines.len(), если виджетов внизу нет. Вызывающий берёт lines[..end] и уже в нём ищет footer prompt'а.

ЗАЧЕМ. Claude Code рисует под prompt'ом несколько блоков, и они встречаются в произвольном сочетании: список задач (attention::todo_widget_start) и полоса фоновых агентов (attention::agents_widget_start). Каждый из них выталкивает footer за окно из четырёх хвостовых строк, которое смотрит гейт. Раньше срезался только TODO-виджет, и одного вызова хватало; с появлением второго блока понадобился итеративный срез.

АЛГОРИТМ. Цикл: на каждом шаге под текущей границей пробуется todo_widget_start, затем (если он ничего не нашёл) agents_widget_start; распознанный виджет отодвигает границу вверх, и следующий разбирается уже под новой границей. Выход — когда ни одна из функций ничего не вернула. Сходимость гарантирована: обе возвращают индекс СТРОГО меньше переданной длины, а условие Some(i) if i < end страхует от зацикливания.

СВЯЗИ. Единственный вызывающий — attention::prompt_at_bottom. Тест bottom_gate_ignores_todo_widget_and_agents_widget_together фиксирует случай, когда на экране оба блока сразу.

# forge_meet::config::MeetConfig

Конфигурация плагина: пути (config_path, cache_dir, db_path, models_dir и пять путей к исполняемым файлам), поведение бота, пороги VAD и атрибуции, лимиты, таймауты, ретенция. Три источника по возрастанию приоритета: умолчания, ~/.config/forge/meet.toml, переменные окружения FORGE_MEET_*. Битый файл даёт умолчания, а не панику: meet.toml правят руками, и опечатка в нём не должна отнимать devforge целиком. validate_and_fix подрезает значения по границам и ВОЗВРАЩАЕТ список поправок, чтобы человек узнал, что именно поправили. Неизвестные ключи не отвергают файл, а называются в логе. Внутри состояния конфиг НЕИЗМЕНЯЕМ: PUT /api/meet/config пишет файл и отвечает restart_required.

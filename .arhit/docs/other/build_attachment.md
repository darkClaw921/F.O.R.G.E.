# build_attachment

Собирает строку параметра attachment метода messages.send из всех загрузок сообщения (plugins/vk/src/routes/upload.rs). Фотографии группируются по MAX_ALBUM_PHOTOS=5 и уезжают альбомами (один multipart-POST полями file1..file5 + один photos.saveMessagesPhoto), документы и голосовые — по одному (способа сохранить два документа одним вызовом у VK нет). Порядок вложений в итоговой строке — ПОРЯДОК ПОЛЬЗОВАТЕЛЯ: он выбирал файлы в определённой последовательности, и перестановка выглядела бы как ошибка отправки. Реализовано через массив слотов по исходным индексам.

# PortalConfig

plugins/bitrix/src/config.rs — одна запись [[portals]] в ~/.config/forge/bitrix.toml.

Поля:
- id: String — стабильный идентификатор портала, выведенный из ХОСТА вебхука (portal_id_from_webhook). Секрета НЕ содержит: его можно отдавать во фронт, класть в WS-кадры и писать в логи. На этом свойстве держатся заголовок X-Forge-Portal (Ф3/Ф8), пер-портальные подкаталоги кэша (Ф6) и пер-портальные настройки (Ф7). В файле необязателен: пустой выводится при загрузке, а на диск попадает уже явным — чтобы правка вебхука руками не переименовала портал и не отвязала от него кэш.
- title: String — необязательное человеческое имя вкладки. Пусто ⇒ фронт показывает хост.
- webhook: WebhookUrl — СЕКРЕТ целиком (тип без Serialize).

Методы: from_webhook(webhook, title) — портал с выведенным id; display_name() — title, иначе хост, иначе id (секрета не содержит ни в одной ветке).

Deserialize с #[serde(default)] на контейнере: запись без id/title читается. Записи с пустым webhook отбрасываются при загрузке (resolve_portal_ids) — это мусор, а не 'портал в настройке'.

# seed_archive_flags

Досев архивных диалогов в кэш флагов уведомлений (plugins/telegram/src/updates.rs).

ЗАЧЕМ. Стартовый листинг фронта идёт через iter_dialogs(), а он отдаёт ОСНОВНОЙ список: архив представлен одной служебной строкой «Архив» (dto::is_folder_row), которую роут отбрасывает. В результате про архивные чаты сервер не знал ничего, а TelegramState::is_archived на промахе отвечает false («показать»). Любой архивный чат звенел тостом до тех пор, пока пользователь руками не откроет ~/archive (GET /dialogs?folder=archive).

ЧТО ДЕЛАЕТ. Один раз за процесс (TelegramState::claim_archive_seed) вызывает routes::dialogs::folder_dialogs с folder_id = 1 и ARCHIVE_SEED_LIMIT = 100, результат уходит в remember_dialogs. Зовётся в supervisor сразу после refresh_notify_defaults — ДО первого разобранного апдейта, иначе сообщение из архивного чата уедет во фронт звенящим.

ОГРАНИЧЕНИЯ. Не досевает, пока не прочитаны глобальные дефолты (тогда и claim не тратится — повтор случится на следующем реконнекте). Ошибка запроса только логируется: не досеяли — сработает ленивый резолв probe_dialog_flags по первому сообщению. Изменения архива дальше по сессии ловит updateFolderPeers (folder_peers_mapped → CacheEffect::DialogArchived), поэтому повторять досев на каждом реконнекте не нужно.

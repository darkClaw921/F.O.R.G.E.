# agents::store::benchmark_history_refresh_snapshot

Manual ignored benchmark for metadata-only history overhead. Requires FORGE_AGENT_PERF_CACHE to name a private version3 cache copy; source discovery, original journal reads and user cache writes are disabled. Measures three unchanged zero-byte ingestion passes, one complete fold, task pricing and snapshot persistence into a temporary directory. Also times three clones of the largest cached JSONL cursor to check whether reader transaction refactoring is worth its semantic risk. Prints only aggregate event/task/usage counts and elapsed milliseconds. Compare the same frozen metadata copy under the same build profile; this is not a live daemon CPU percentage or a local model workload. During development, a temporary former-fold reference was compared byte-for-byte against all optimized tasks/usage on this frozen snapshot, then removed.

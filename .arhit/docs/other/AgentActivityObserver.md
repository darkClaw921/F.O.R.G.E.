# AgentActivityObserver

Stateful bridge from authoritative journal task events to tab/Echo behavior. update takes existing tmux GenSnapshot metadata, AgentSnapshot live/waiting/unknown, and journal-only recent tasks. Tracks observed native session identity and most recent original/projected start plus exact bound tab names. Projects all busy states separately from visible working stars; multiple root IDs per tab count once each and use earliest start. deduplicate_generating applies only session_group alias rules, never pane text similarity. Explicit ending is emitted once only when observed during this process and newer than observer startup; historical ingestion and unseen endings are silent. Open tasks absent from the projected live view are forgotten/expired rather than inferred complete. Closed/forgotten identities are pruned with the bounded source window.

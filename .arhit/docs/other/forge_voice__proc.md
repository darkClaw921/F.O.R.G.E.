# forge_voice::proc

Модуль `plugins/voice/src/proc.rs` (292 строки) — ЗАПУСК ВНЕШНЕГО ПРОЦЕССА с наблюдением
за stderr и осмысленным хвостом ошибки. Переехал в Ф1 вместе с движками: `whisper`
тянет его за собой, отдельно вынести было нельзя.

# ЗАЧЕМ

Голосовая фича запускает ffmpeg и whisper-cli. У обоих полезное происходит в stderr:
whisper печатает туда проценты и строку инициализации Metal, ffmpeg — причину отказа.
Просто дождаться кода возврата недостаточно — надо читать поток ПО ХОДУ и уметь убить
процесс по решению наблюдателя.

# КЛЮЧЕВЫЕ ЭЛЕМЕНТЫ

- `run_watched(cmd, timeout, on_line)` — главная функция: построчно отдаёт stderr
  замыканию, а то возвращает `LineVerdict` — продолжать либо убить процесс. Именно на
  этом построен Metal-гард: не увидели `ggml_metal_init:` — `LineVerdict::Kill`.
- `LineVerdict` — решение наблюдателя по строке.
- `TailBuffer` + `tail(text, n)` — кольцо на `STDERR_TAIL_LINES = 20` последних строк.
  Тащить в ошибку весь stderr нельзя (мегабайты прогресса), а без хвоста отказ
  недиагностируем.
- `ProcError` — код возврата, сигнал и тот самый хвост; реализует `Display` и
  `std::error::Error`.
- `run(...)` — простой запуск без наблюдения; `capture_stdout(...)` и
  `capture_stdout_bytes(...)` — сбор вывода (второй нужен `waveform`: там на stdout идёт
  сырой PCM, и через строки его тащить нельзя).

# СВЯЗИ

Под ним — `tokio::process`. Над ним — `whisper::run`, `audio::convert`,
`audio::probe_duration_ms`, `waveform::compute`, нарезка окон в `cloud::stt`.
`From<CloudError> for ProcError` сводит облачные и локальные отказы в один тип.

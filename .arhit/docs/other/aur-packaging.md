# aur-packaging

AUR distributes devforge as a source-build package. The checked-in packaging/aur/devforge/PKGBUILD and .SRCINFO are synchronized v0.1.75-1 release templates; native architectures are x86_64 and aarch64, runtime dependencies tmux/gcc-libs/glibc, build dependencies Rust/Cargo, plus optional TUI helpers. Cargo builds --release --locked -p devforge from the workspace root; embedded static assets require no separate resource directory. options !lto preserves workspace thin LTO. Source templates contain REPLACE_WITH_SHA256 because the source archive contains those files and cannot contain its own final hash. The authoritative installable recipe is the external ssh://aur@aur.archlinux.org/devforge.git repository: after the exact merged release commit is tagged, download the source archive, calculate SHA256, substitute real integrity metadata, generate .SRCINFO with makepkg --printsrcinfo, validate syntax/source/version/checksum, and publish both files to its master branch. Never publish placeholders or SKIP. Homebrew tap uses the same tag and archive digest. Users install via yay -S devforge or paru -S devforge. The release script is not required for the controlled PR/merge/tag flow and should not be run from a dirty feature branch.

# set_chat_prompt

plugins/vk/src/state.rs — VkState::set_chat_prompt(dialog_id, raw, now) -> anyhow::Result<Option<ChatPrompt>>.

Записывает заметку пользователя к беседе и СРАЗУ сохраняет файл. Мапа и файл меняются под ОДНИМ lock'ом (VkState.prompts: Mutex<PromptStore>): иначе два одновременных сохранения из двух вкладок могли бы записать файлы в порядке, обратном порядку правок, и более старая заметка победила бы. Пустой текст = удаление записи (PromptStore::set), возвращается None.

Ошибка записи означает, что память уже изменена, а файл — нет; источник истины файл, следующий успешный save выровняет. Откатывать правку намеренно не стали: это показало бы пользователю старый текст в поле, куда он только что напечатал новый.

Парный читатель — VkState::chat_prompt(dialog_id) -> Option<ChatPrompt>: отдаёт КОПИЮ, а не guard, чтобы не сериализовать все запросы вкладки на одном локальном файле. Само хранилище грузится синхронно в конструкторе VkState::with_timings через analysis::prompts::load — сети это не трогает, инвариант init_never_touches_the_network цел.

# NEGATIVE_VERDICT_TTL

Срок жизни отрицательного вердикта LLM-эскалации блоклиста авто-апрува (tmux-web/src/auto_approve.rs), 300 секунд. Кэш вердиктов в auto_approve::run хранит (approve, ts) по хэшу текста команды. Положительный вердикт живёт до конца работы процесса — разрешение на конкретный текст со временем не портится. Отрицательный протухает через TTL: модель могла ответить «нет» по мусорному тексту или просто неудачно, а вечный кэш означал, что висящий prompt уже никогда не будет переспрошен до перезапуска процесса. Цена — примерно один вызов claude -p в 5 минут на панель, а не на каждый тик.

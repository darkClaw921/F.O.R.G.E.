# AgentStatsStore::configure

Atomically apply a complete AgentConfig without racing concurrent HTTP configuration writes. A dedicated async configure mutex serializes path canonicalization, file save, memory swap and rescan as one transaction, preventing concurrent writes from colliding on forge_atomic PID-based temporary filenames. The configure mutex is separate from the ingestion gate because rescan acquires that gate itself; this avoids recursive-lock deadlock. Save runs in spawn_blocking and an IO failure returns before the in-memory config changes. After a successful swap the serialized rescan publishes an index for the same configuration. Existing internal cache/config/price paths are preserved by the public routes restricted DTO. Tests run twenty-four concurrent configure calls and compare the final TOML, live config and enabled index status.

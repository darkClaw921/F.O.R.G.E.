# routes/cloud.rs

forge-meet, Ф16: HTTP-роуты каталога облачных моделей и остатка средств для вкладки настроек.

РОУТЫ
- GET /api/meet/cloud/models -> CloudModelsDto { configured, stt[], chat[], total, error }
- GET /api/meet/cloud/balance -> CloudBalanceDto { configured, balance, key, error }

РЕШЕНИЯ
1. Ходит СЕРВЕР, а не браузер: каталог и баланс polza.ai требуют Authorization: Bearer pza_..., и прямой запрос из страницы означал бы ключ в памяти вкладки, в devtools и в кэше PWA. Наружу уезжают только идентификаторы, цены и суммы; на утечку ключа в тело ответа есть проверка в tests/polza_stub.rs.
2. Оба роута отвечают 200 ВСЕГДА. Отказ облака — поле error, а не статус: вкладку настроек открывают именно тогда, когда что-то сломано, и роут, падающий вместе с чужим сервисом, оставил бы человека без места, где чинится ключ. Ветки 'ключа нет' (configured:false, error пуст) и 'сервис молчит' (error непуст) различимы в теле.
3. Кэша нет ни у каталога, ни у баланса: вызовы случаются по открытию вкладки настроек (единицы раз в день), а устаревший баланс после пополнения читался бы как 'деньги не пришли'. Лимиты ключа при этом берутся из кэшированной пробы MeetState::cloud_probe — второй платы за те же числа нет.
4. Потолки: CATALOGUE_TIMEOUT = 15 с (каталог около 400 записей), BALANCE_TIMEOUT = 10 с. Оба ставятся дважды — свой на вызове клиента и внешний tokio::time::timeout поверх (разрешение имени и TLS).
5. CloudModelDto несёт timestamps: Option<bool> — только у stt. Some(false) означает 'выбор ломает атрибуцию спикеров целиком'; флаг считает cloud::stt_gives_timestamps, чтобы имя единственной пригодной модели не появилось третьей копией во фронте. Модели типов tts/image/video/embedding/music в списки не попадают, но считаются в total.
6. Цена приходит из ModelInfo.pricing, разобранной из top_provider.pricing: поля pricing верхнего уровня у записей нет вовсе, и наивный разбор молча показал бы 'бесплатно'.

ТЕСТЫ: юнит-тесты модуля (без ключа роуты не ходят в сеть; мёртвый сервис становится полем) и два теста на стенде в plugins/meet/tests/polza_stub.rs (цены ненулевые, whisper-large-v3-turbo помечен timestamps:false, баланс в рублях вместе с лимитом ключа).

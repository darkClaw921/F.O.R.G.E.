# plugins/claude-runner/src/lib.rs

Крейт forge-claude-runner: фасад над Claude CLI (spawn, стриминг, отмена). Листовой крейт — им пользуются и плагин Echo, и анализ чата VK, и ни один из них не зависит от другого.

ClaudeRunner cheap-clonable через Arc; один процесс devforge = один раннер, внутри до значения семафора одновременных стримов. one_shot() собирает результат целиком, stream() отдаёт поток событий.

ARGV (build_args): -p --output-format stream-json --include-partial-messages --verbose, затем опционально --model и --append-system-prompt. Prompt уходит ПОСЛЕДНИМ positional-аргументом, ЛИБО — при prompt_via_stdin=true — на stdin, и тогда в argv его нет вовсе.

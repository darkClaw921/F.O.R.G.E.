# plugins/tracker/src/error.rs

TrackerError — типизированные ошибки крейта forge-tracker и alias Result.

Крейт листовой и его будет вызывать HTTP-слой фазы 2, поэтому ошибка обязана нести не только текст, но и КЛАСС проблемы: по нему роут выбирает код ответа. Отсюда четыре варианта, а не один anyhow:
- Io(String) и Json(String) — беда с хранилищем (~/.config/forge/tracker.json): права, диск, битые байты. Это 500. Есть From<std::io::Error> и From<serde_json::Error>.
- NotFound(String) — ссылка на несуществующий объект (задача, список, пункт, веха, отрезок). Это 404.
- Conflict(String) — запрос синтаксически верен, но нарушает инвариант модели: ручной отрезок с stopped_at <= started_at, второй активный отрезок по той же задаче. Это 409.

ВАЖНО: загрузка стора эти варианты как фатальные НЕ использует — битый файл там логируется через warn и даёт пустой стор, чтобы сервер поднялся (TrackerStore::load).

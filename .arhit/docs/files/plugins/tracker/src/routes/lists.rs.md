# plugins/tracker/src/routes/lists.rs

Роуты списков задач (блок // LISTS в левой колонке панели): GET/POST /api/tracker/lists, POST /lists/reorder, PATCH/DELETE /lists/:id. Принятое правило удаления: DELETE убирает только сам список, а у задач и вех обнуляет list_id — задачи переезжают в ~/inbox, а не исчезают. Иначе одно нажатие на крестик у папки уносило бы историю времени по всем её задачам безвозвратно: журнала удалений в трекере нет. Каскад выполняет store::delete_list, роут его только вызывает. Все мутации списков публикуют reload: точечного кадра для списка в TrackerEvent нет намеренно, а изменение списка почти всегда затрагивает и задачи, то есть точечный кадр всё равно не описал бы последствие целиком.

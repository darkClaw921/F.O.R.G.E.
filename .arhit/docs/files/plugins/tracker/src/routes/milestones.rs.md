# plugins/tracker/src/routes/milestones.rs

Роуты вех — дорожка // MILESTONES (символ ромба) на диаграмме Гантта: GET/POST /api/tracker/milestones, PATCH/DELETE /milestones/:id. Веха это точка, а не отрезок: есть дата и подпись, нет ни длительности, ни статуса, поэтому она живёт отдельной коллекцией — попытка выразить её задачей со статусом done засорила бы канбан и отчёты записями, по которым никто не работал. Поле date принимает YYYY-MM-DD и полный RFC 3339 (голая дата = локальная полночь, report::parse_ts); неразбираемое значение отбивается кодом 400 и на создании, и на патче: сохранить его молча означало бы получить веху, невидимую на Гантте (она не попала бы ни в одно окно) без единого признака ошибки. Мутации публикуют reload.

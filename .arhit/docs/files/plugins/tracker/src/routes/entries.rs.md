# plugins/tracker/src/routes/entries.rs

Роуты таймеров задачи и ручной правки отрезков: POST /tasks/:id/timer/start|stop, GET/POST /api/tracker/entries (?task_id=), PATCH/DELETE /entries/:id. start_timer НИКОГДА не останавливает чужие таймеры: одновременно идущие отрезки по РАЗНЫМ задачам — штатный сценарий, ради которого трекер и писался; единственное ограничение действует внутри задачи (повторный start отдаёт уже идущий отрезок с тем же id), и держит его store::start_timer, а не роут — иначе правило жило бы в двух местах. stop_timer по задаче без активного отрезка отвечает 200 и {stopped:false}: кнопка «стоп» нажимается по состоянию, которое UI видел мгновение назад, и гонка со второй вкладкой обычна; ошибка заставила бы показывать красный тост на действие, приведшее ровно к желаемому результату. require_valid_span() отбивает неразбираемые отметки и перевёрнутый интервал кодом 400 ДО обращения к стору, причём в patch_entry — по ИТОГОВОМУ состоянию отрезка (патч мог сдвинуть только одну границу), иначе правка «подвинь начало на час вперёд» вывернула бы отрезок наизнанку и дала отрицательную длительность в отчёте. Вторая попытка сделать отрезок активным при уже идущем таймере той же задачи — 409 из стора.

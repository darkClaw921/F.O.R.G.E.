# plugins/vk/src/analysis/mod.rs

Корень модуля анализа чата плагина VK. Растёт по фазам фичи «Анализ чата через Claude»: prompts (пер-чатовое хранилище пользовательского контекста), далее context (выгрузка истории и рендер транскрипта), prompt (теговая сборка запроса) и hub (реестр активных run'ов поверх крейта forge-claude-runner). Общее правило подмодулей: ни один не тянет AppState хоста и не зависит от forge-echo — раннер вынесен в общий крейт workspace именно ради изоляции плагинов друг от друга.

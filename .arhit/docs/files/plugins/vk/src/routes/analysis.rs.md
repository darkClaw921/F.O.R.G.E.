# plugins/vk/src/routes/analysis.rs

Четыре роута фичи «Анализ чата через Claude»: пер-чатовая заметка и запуск/отмена разбора.

  GET  /api/vk/dialogs/:id/prompt          — заметка пользователя к беседе
  PUT  /api/vk/dialogs/:id/prompt          — сохранить (пустая строка стирает)
  POST /api/vk/dialogs/:id/analysis        — запустить анализ либо вопрос
  POST /api/vk/dialogs/:id/analysis/cancel — остановить идущий разбор

ДВЕ РАЗНЫЕ ЛЕСТНИЦЫ ОТКАЗОВ В ОДНОМ МОДУЛЕ, И ЭТО НАМЕРЕННО.
/prompt: авторизация (409) -> резолв peer (404) -> разбор тела (400). Ступени «соединение» у него НЕТ: заметка лежит в локальном файле, и 503 not_connected на чтение файла был бы враньём — вкладка контекста перестала бы открываться ровно тогда, когда нужнее всего (VK недоступен, пользователь читает кэш). Та же логика, что у GET /api/vk/filters.
/analysis: авторизация -> СОЕДИНЕНИЕ (503, require_ready) -> резолв peer -> тело и kind -> уже идущий run по этой беседе -> наличие Claude CLI -> свободный слот -> выгрузка истории -> старт. Три последние проверки стоят ДО выгрузки не для красоты: выгрузка это до ~1.7 с при бюджете 3 rps, и отказ «уже идут два анализа» после полутора секунд выглядит как поломка.

ОТВЕТ УХОДИТ СРАЗУ. POST /analysis возвращает {run_id, attached, messages_used, truncated} в момент запуска процесса; текст модели приезжает кадрами analysis_delta по /ws/vk, финал — analysis_done. Держать HTTP открытым на всю генерацию нельзя: она длится минуты, любой прокси оборвёт её раньше.

ТЕЛО — Option<Json<T>>, А НЕ Json<T>. Экстрактор Json<T> отработал бы ДО проверки авторизации и превратил бы роут в оракул валидности идентификаторов. Отсутствующее и битое тело — 400 invalid_input, а НЕ «пустая заметка»: стирание требует явного {"prompt": ""}.

КЛЮЧ ХРАНИЛИЩА — КАНОНИЧЕСКИЙ id: peer_id.to_string() ПОСЛЕ resolve_peer, а не сырой сегмент URL. Иначе /dialogs/1234/prompt и /dialogs/%201234%20/prompt завели бы две разные заметки на одну беседу.

КОДЫ ОШИБОК: not_authorized (409), not_connected (503), unknown_dialog (404), invalid_input (400), claude_unavailable (409, в сообщении путь до бинаря), invalid_state (409, слоты заняты), storage_failed (500). Фронт принимает решения по коду, а не по тексту.

ИНВАРИАНТЫ УТЕЧКИ (тесты в этом же файле): токен VK не появляется ни в файле заметок, ни в теле любого из четырёх ответов; текст заметки не попадает в логи ни при сохранении, ни при чтении, ни при перезагрузке файла — остаются только счётчики символов.

# plugins/vk/src/ws/mod.rs

WebSocket-handler /ws/vk?token= — перенос телеграмного цикла с заменой типов. Жизненный цикл: апгрейд (token в query нужен только потому, что браузерный WebSocket не умеет слать Authorization; проверку делает middleware хоста) -> подписка на broadcast -> ПЕРВЫЙ кадр login_state -> цикл tokio::select! {biased; shutdown -> idle -> heartbeat -> broadcast -> входящий}. Три инварианта, которые легко потерять при переписывании: (1) подписка ДО снапшота — событие между снапшотом и подпиской иначе теряется навсегда; (2) biased задаёт приоритет веток, чтобы остановка сервера не ждала heartbeat'а; (3) битый входящий кадр даёт warn и игнор, а НЕ разрыв — он может прийти от более новой версии фронта или из кэша PWA. RecvError::Lagged не рвёт соединение: клиенту уходит resync, он перечитывает состояние по REST. Тайминги (15с heartbeat / 60с idle) берутся ИЗ СОСТОЯНИЯ, а не из констант: иначе тест закрытия по idle ждал бы боевую минуту. Фильтрации по активному диалогу нет намеренно — бейдж и тосты должны работать с любой вкладки devforge.

# tags.js

Чистая логика редактора тегов карточки трекера (tmux-web/static/js/tracker/tags.js).

ЗАЧЕМ. Карточка задачи (modals.js) импортирует core/dom.js, который дёргает getElementById на уровне модуля, — значит она неимпортируема в голом node и не покрывается тестом. Нормализация тегов, дедуп и выбор подсказок — место тихих ошибок (задвоенный ##тег, потерянный порядок, дубль Forge/forge), поэтому они вынесены сюда: ни DOM, ни сети. Покрыто tmux-web/tests/frontend/tracker_tags.test.mjs (23 теста).

КЛЮЧЕВОЙ ФАКТ МОДЕЛИ. Отдельной сущности «тег» НЕТ: тег живёт ровно как строка в task.tags (plugins/tracker/src/models.rs), ни таблицы тегов, ни эндпоинтов /api/tracker/tags не существует. Поэтому «создать новый тег» = добавить в список строку, которой ещё не встречалось; никакого CRUD за этим не стоит. Источник подсказок — задачи снимка /api/tracker/state, те же, что питают блок // TAGS в сайдбаре (main.js). Второго источника намеренно нет: две копии списка разъезжаются.

ЭКСПОРТЫ
- SUGGEST_LIMIT (8) — сколько подсказок показываем разом.
- normalizeTag(raw): срезает ВСЕ ведущие '#' и пробелы; '#', '###', пустое → '' («добавлять нечего»). Регистр НЕ приводится: чужое написание не переписываем.
- splitTags(raw): строка → массив тегов, разделители — пробелы и запятые (вставка из буфера, старая форма поля '#тег #тег').
- hasTag(list, tag): наличие без учёта регистра.
- addTag(list, raw) → {tags, added, tag}: ЧИСТАЯ, исходный массив не мутируется; пустое и дубль (без учёта регистра) не добавляются; новый тег уходит в конец, порядок существующих сохраняется.
- removeTagAt(list, index) — крестик на чипе; чужой индекс безопасен.
- popTag(list) — Backspace на пустом вводе.
- knownTags(tasks) — все теги снимка по алфавиту, дубли по регистру схлопнуты (сохраняется первое написание).
- suggestTags(known, query, current, limit) → {items, create, query}: уже навешенные вычеркнуты; совпадения с начала выше совпадений внутри слова, внутри группы алфавит; create — нормализованный запрос, только если такого тега нет ни среди известных, ни среди навешенных.
- moveSuggest(index, delta, count) — движение стрелок по кольцу; -1 при пустом списке.

СВЯЗИ. Импортируется только modals.js (функция tagEditor строит по этим функциям DOM). Порядок и форма списка важны для buildPatch: он сравнивает tags.join(' ') со старым и шлёт PATCH только при фактическом изменении.

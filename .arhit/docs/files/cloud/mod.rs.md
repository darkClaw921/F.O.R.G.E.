# cloud/mod.rs

Каркас облачного клиента polza.ai (plugins/meet/src/cloud/mod.rs). CloudConfig с обязательным base_url (точка подмены в тестах), моделями, окном нарезки и таймаутами; SecretKey — ключ, печатающий только маску pza_RIcg...Uzu4js в Debug и Display, значение достаётся явным expose(); CloudClient на reqwest из workspace с connect_timeout и без общего таймаута (общий убил бы стрим саммари), ключ уходит только заголовком Authorization, ошибки reqwest чистятся without_url(); CloudError с кодами cloud_not_configured, cloud_transport, cloud_timeout, cloud_unauthorized, cloud_no_funds, cloud_rate_limited, cloud_http, cloud_bad_response и преобразованием в ProcError; number()/text() читают значения, приходящие и строкой, и числом. Константы: DEFAULT_BASE_URL, DEFAULT_STT_MODEL=openai/whisper-1, DEFAULT_SUMMARY_MODEL=google/gemini-3.5-flash, MAX_STT_WINDOW_SECS=90.

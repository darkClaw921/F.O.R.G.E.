# cloud/stt.rs

Облачная расшифровка (plugins/meet/src/cloud/stt.rs): POST /audio/transcriptions окнами. plan_windows режет запись встык и жёстко ограничивает окно 90 секундами (предел сервиса около 60 секунд по стене на запрос). build_window_args собирает argv ffmpeg с -ss и -t ДО -i и кодеком libmp3lame: на облако уходит mp3, потому что WAV роняет их шлюз. build_form_fields даёт поля формы без timestamp_granularities (параметр принимается и молча игнорируется). parse_verbose_json превращает ответ в WhisperSegment с пустым tokens — пословных меток облако не даёт. shift_segments кладёт окно на общую ось СЛОЖЕНИЕМ (remap_segment_times для этого не годится: это множитель дрейфа на AttributedSegment). transcribe_file ведёт весь прогон: одно упавшее окно даёт дыру и gap_note, отказом считается только случай, когда не доехало ни одно окно.

# bot/chrome.rs

Боевой MeetBot поверх forge-cdp (Ф4). Запуск Chrome, инжект ДО навигации, две задачи (насос биндинга и наблюдение по пробам), вход по чистой функции next_join_step с двумя ветками pre-join и счётчиками попыток, гашение микрофона и камеры повторно после входа, детект конца через bot::endgame, идемпотентный stop с гарантией отсутствия живых процессов. ChromeBotFactory ставится в spawn_workers вместо MissingBotFactory.

# bot/endgame.rs

Детект конца встречи и автовыход (Ф4), чистая логика без браузера. EndWatch::observe(elapsed_ms, EndSignals) отдаёт StopReason по шести независимым сигналам: target упал, все дорожки ended, DOM-маркер или пост-звонковый адрес, потолок длительности, бот один, тишина при не более чем одном собеседнике. Все таймауты — миллисекундные поля EndConfig::from(&MeetConfig). Ключевой страж: автовыходы слепы, пока пробы не сработали ни разу (participants_known), иначе протухший селектор выглядел бы пустой комнатой и выкидывал бы бота с живой встречи.

# bot/observe.rs

Разбор снимка страницы и именование участников (Ф4). PageSnapshot — все поля необязательны; ParticipantNamer закрепляет номер за ключом участника навсегда (номер уезжает в транскрипт); Axis переводит часы страницы в единственную ось записи ОДНИМ измерением пары perf+unix, дальше живёт монотонным performance.now(). DeviceState из трёх значений: unknown это не off.

# tmux-web/tests/tracker_smoke.rs

Смоук-тесты плагина forge-tracker по проводу через настоящий axum-сервер на свободном порту (близнец meet_smoke.rs). Проверяют host-уровневый контракт фазы 3: (1) tracker_routes_are_absent_without_the_flag — без register_routes восемь путей (/api/tracker/status, /state, /tasks, /lists, /entries, /milestones, /report и /ws/tracker) отвечают 404, а /healthz жив; (2) the_status_route_answers_200_with_the_plugin_mounted — с плагином status отдаёт 200 {"enabled":true}, и merge не съедает хост-роут; (3) a_task_created_over_the_wire_shows_up_in_the_state — POST /api/tracker/tasks и GET /api/tracker/state работают поверх одного стора; (4) a_failed_init_leaves_the_host_alive_and_the_plugin_absent — ветка Err(init) из main.rs оставляет сервер живым и роуты несмонтированными. Стор герметичен (tempfile), живой ~/.config/forge/tracker.json не трогается.

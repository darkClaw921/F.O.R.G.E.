# tmux-web/src/server_config.rs

Резолвинг эффективной конфигурации сервера: ServerConfig (JSON ~/.config/forge/server_config.json) + RunOptions (CLI) + окружение → EffectiveConfig. Приоритет всегда CLI > file > env > default. Помимо bind/port/auth_token/remote_mode держит гейты opt-in плагинов: pwa_enabled, telegram_enabled, vk_enabled, bitrix_enabled, meet_enabled и tracker_enabled (личный трекер forge-tracker; env-константа ENV_TRACKER = DEVFORGE_TRACKER, файловое поле tracker: Option<bool>). Каждый гейт вычисляется одним выражением cli_opts.X || file.X || truthy(env), а тесты (tracker_priority_matches_the_other_plugins, resolve_tracker_is_independent_of_the_other_plugins) ловят копипасту между плагинами. False у гейта означает, что роуты плагина не регистрируются вовсе и его /api/*/status отдаёт 404 — на этом 404 держится фронтовый гейт кнопок.

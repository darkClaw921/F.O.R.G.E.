# tmux-web/src/agents/model.rs

Provider-neutral contract for local Codex, Claude, OpenCode and Copilot statistics. AgentSessionId combines provider, canonical profile root and native session ID; key() encodes a JSON tuple to prevent separator collisions. AgentEvent keeps only metadata: task lifecycle, context, usage and running command IDs; it never retains prompt/reply/tool payloads. AgentTokens input excludes cache traffic and output already includes reasoning, so total() adds input, output, cacheRead and cacheWrite once. AgentTask distinguishes working, waiting, ended and unknown, keeps original start, explicit completion/duration, nullable tokens/cost, root linkage and temporary tmux process bindings. AgentSnapshot is a coherent live view with root counts; AgentQuery and AgentSummary define the independent /api/agents surface without changing Claude analytics. Unknown metrics use null instead of fabricated zero. History defaults to 91 days; quiet timeout is ten minutes and settled OpenCode timeout thirty seconds.

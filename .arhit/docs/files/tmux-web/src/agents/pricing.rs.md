# tmux-web/src/agents/pricing.rs

Versioned token API-value catalogue used by the shared local agent statistics index. PriceCatalog::default loads bundled prices.json, an independently assembled dated table from official OpenAI/Anthropic pricing pages; ModelPrice records model IDs, exact aliases, dated-snapshot recognition, source URL, base rates, explicitly supported fast multiplier, optional context tier and cache-write policy. All rates are USD per million tokens. price(UsageRecord) returns a nullable estimate, independent of provider-reported charges: output already contains reasoning; cache reads/writes are separate. Unknown models, unsupported fast tiers, missing token counters and unknown cache TTL produce None rather than fabricated zero. Claude writes require the known one-hour portion, charging the remainder at the five-minute rate. GPT cache-write TTL is unavailable in normalized usage, so nonzero writes stay unpriced. Per-request context tiers count the whole prompt including cached tokens; aggregate multi-request counters use base rates because their sum cannot establish request context size. load/save validate schema1, ISO date, identifiers/aliases, finite nonnegative bounded rates and HTTPS source URLs; invalid files are ignored and atomic save preserves the prior catalogue. update(url) uses a fresh reqwest client without credentials/cookies/usage data, HTTPS only, same-origin bounded redirects, 15-second total timeout and a 1MiB streamed limit; malformed, oversized, stale or unsupported updates return Err without modifying the last good catalogue. Store owns refresh cadence (24 hours) and failure retry (six hours). Tests verify arithmetic, reasoning, reported-charge separation, unknowns, exact snapshot aliases, cache TTL, context boundaries and aggregation, last-good persistence, bounded transfer and origin checks.

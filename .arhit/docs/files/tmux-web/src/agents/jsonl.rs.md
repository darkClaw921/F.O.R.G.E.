# tmux-web/src/agents/jsonl.rs

Incremental regular-file JSONL tailer uses inode, byte offset, observed length/mtime and a bounded checkpoint digest. Only complete lines advance the parser; a partial final line is retried after growth. Append resumes at committed offset, truncate/replacement/rewrite rebuilds that source contribution. Lines are consumed through a bounded buffer (8MiB maximum decoded line) so huge tool output cannot cause unbounded allocation. Nonblocking Unix open prevents FIFO hangs and opened metadata must identify a regular file. Cursor serializes only ParserState metadata and normalized AgentEvents, never source text. Reader reports consumed/checkpoint bytes for instrumentation and a more flag for bounded ingestion batches. Caller preserves the last good cursor on errors and performs metadata fast paths before invoking this function.

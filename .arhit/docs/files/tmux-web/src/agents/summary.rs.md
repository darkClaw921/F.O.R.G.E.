# tmux-web/src/agents/summary.rs

Read-only historical queries over the normalized AgentIndex, independent of the older Claude analytics metrics. Public summary(index, query, now_ms, updated_at_ms, pricing) returns totals, provider/model/project breakdowns and local day/week series; sessions returns newest-first task history with pagination; projects returns canonical full-path project shares. Dates are strict YYYY-MM-DD, inclusive calendar endpoints in server local timezone, default today, maximum 3660 days; invalid dates, reversed ranges and unsupported buckets return validation errors. Local-day boundaries use timezone mapping and tolerate a midnight DST gap. Every provider/profile/project filter applies consistently to task counts, durations, usage, cost and breakdowns. Task starts and explicit endings are counted on their respective dates. Work intervals are clipped to the query window; completed provider duration is apportioned across wall-time slices using cumulative fractions so daily slices add exactly. Agent time sums tasks; wall time unions their overlap. Quiet/unknown task time stops at last journal activity and incompleteTasks remains explicit. Usage is assigned by provider timestamp; reasoning is not added twice. Null tokens and costs remain unknown, with partial-token/unpriced request counters. Reported cost and API estimate remain separate columns. Sessions limit defaults 200, caps 500, validates overflow and applies offset after filtering and stable sorting. Synthetic tests cover parallel tasks, clipping, provider duration, all filters, unknown data, same-basename projects, pagination, weekly series, midnight completion, fractional rounding and duplicate-source replay equality.

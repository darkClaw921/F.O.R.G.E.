# tmux-web/src/agents/store.rs

AgentStatsStore coordinates discovery, incremental JSONL/SQLite source ingestion, immutable task/usage publication, runtime observations and interruption barriers, pricing and private cache persistence. Configuration/ingestion gates serialize writes; filesystem work runs in spawn_blocking, and failed sources retain last-good contributions. Discovery requests remain latched across gate contention and existing descriptors receive fresh modification metadata before read priority. Unchanged ticks now reconcile availability from transient distinct event-owner IDs, preserving parent-only distinction and healthy duplicate precedence, instead of scanning/encoding every historical event. Changed sources refresh their identity sets; cache load rebuilds them without changing version3. Full index replay borrows source contributions with fold_refs and memoized canonical keys, preserving output bytes and task lifecycle. Save borrows the source map rather than cloning all metadata. Two ignored manual private-copy benchmarks measure idle bookkeeping/refold/pricing/save and save-specific peak RSS/physical footprint; all functional tests run normally. No polling interval, collection, retention, configured source or feature behavior is disabled.

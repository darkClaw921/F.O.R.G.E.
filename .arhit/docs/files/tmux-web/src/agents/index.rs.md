# tmux-web/src/agents/index.rs

Deterministic folding of normalized contributions into tasks and usage, preserving native-response global deduplication, earliest attribution/latest activity, canonical first-source ownership and source-sequence ordering. Interrupted epochs preserve unknown/incomplete semantics, model/Bash offline exceptions and confirmed-exit boundaries; subsequent true activity opens a new task without replaying Echo idle. Production now uses fold_refs on borrowed source metadata: Cow owns only duplicate usage records requiring merge, while CanonicalKeys memoizes canonical session/profile JSON identities per fold. Existing owned fold callers remain supported. Root sessions avoid allocating a visited-parent set; child/cycle logic is unchanged. The same copied399794-event snapshot produced byte-identical complete task and usage values against the former owned fold, and normal tests cover immutable streamed merge, cumulative/native suppression, cache/restart and interruption replay. See agent-statistics-performance for scoped Debug benchmarks.

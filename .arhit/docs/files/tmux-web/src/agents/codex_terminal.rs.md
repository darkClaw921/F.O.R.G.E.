# tmux-web/src/agents/codex_terminal.rs

Read-only native Codex terminal identity resolver for Codex versions using one shared app-server across terminals. The ephemeral tmux pane title is parsed only when it has the exact native name plus current project basename; one Braille busy spinner may prefix the name. Queries the latest regular state_N.sqlite per configured canonical Codex profile using READ_ONLY, WAL-aware connections and 50 ms busy timeout. SELECT projects only id,cwd for threads.name=? (explicit native name), never prompt-bearing title or first_user_message. Canonical cwd validates the explicit name; cwd alone never identifies work. A unique native identity across every readable profile is required. Duplicate names in one cwd/profile, copied names across profiles, missing native-name schema, inaccessible existing database and bounded enumeration/query overflow produce no evidence. Returns only pane-to-native-id/profile identities; names and titles are never persisted, logged or serialized. Runtime assigns this evidence only to one verified native CLI with the same controlling TTY and pane ancestry; app-server services remain excluded from interactive ownership. The journal lifecycle still decides Working/Waiting/Unknown. Unit tests cover busy and idle names, project mismatch, prompt non-projection, WAL visibility, duplicates, profiles and legacy schemas.

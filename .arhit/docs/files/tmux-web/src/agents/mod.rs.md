# tmux-web/src/agents/mod.rs

Shared local coding-agent statistics module, independent of AppState and existing Claude analytics. model defines stable provider/event/task/query DTOs; sources resolves standard, env and custom profile roots; JSONL/providers parse bounded metadata-only streams; opencode reads both live SQLite schemas; index folds task lifecycle and deduplicated usage; cache stores normalized source contributions; pricing estimates API value from a dated validated catalogue; summary produces local-calendar filters and parallel-time aggregates; store orchestrates background ingestion and runtime projections. Public entry point AgentStatsStore is cheap-clonable and suitable for AppState. Sources remain authoritative; private conversation payloads are never cached.

# tmux-web/src/agents/providers.rs

Metadata-only JSONL adapters for Codex, Claude Code and GitHub Copilot, implemented independently from observed lifecycle rules of vorssaint-utils at 4f510c075bea4dc1d1724411ea38cf9b6d458b90. The public parse(provider, profile, fallback_session, line, modified_ms, sequence, state) accepts one complete JSONL record, returns normalized AgentEvent values, and never writes prompts, replies, tool arguments or outputs into parser state. ParserState is serializable metadata that the incremental reader checkpoints with its byte offset. Invalid JSON and unknown record types are ignored. RFC3339 and seconds/milliseconds epoch timestamps are supported; missing timestamps use source modification time rather than now, preventing historical replay from creating new work. Native request/event IDs are preferred for replay/archive dedup; offset is only a last fallback. Context keeps canonical full project paths and profile-scoped identities. The store is responsible for ten-minute quiet timeout, process validation, source contribution reconciliation and aggregate query semantics.

# tmux-web/src/agents/routes.rs

Protected REST surface for local coding-agent statistics, registered before the host Bearer/CSRF layers. GET /api/agents/status reads indexing status; /live returns a coherent live snapshot filtered by provider/profile/project with recalculated root counts; /summary, /projects and /sessions expose validated historical queries. Filters use YYYY-MM-DD local-server dates, canonical provider slugs, profile/project IDs, day/week buckets and limit1..500/nonnegative checked offset. Invalid dates/providers/buckets/pagination return400. POST /rescan returns202 through AgentStatsStore request_rescan, which coalesces work in a background task without waiting for ingestion. GET/PUT /config exposes a restricted deny_unknown_fields DTO: enabled, discoverDefaults, roots(provider,path,profile), historyDays1..3660, priceUpdates and optional HTTPS credential-free priceUpdateUrl. Absolute and ~/ paths are accepted even before the folders exist; relative roots are rejected. Cache/config/price write locations never enter the editable/public DTO and are preserved from the current store, preventing arbitrary host-file writes. Configuration persistence and indexing are delegated to the store. GET /bindings returns bindings and inventory under one runtime lock; /inventory is an alias for the sanitized inventory. POST /bindings accepts only sessionId/paneId and delegates exact process validation; DELETE accepts sessionId and is idempotent204. POST /prices/refresh returns validated PriceStatus without launching models. Every handler performs shared remote dispatch using the original query/body before local validation, preserving ?server behavior without reading the wrong local source. Tests use the real Axum router, Bearer middleware and same-origin guard:13 protected methods, cross-origin mutations/Content-Type, empty nullable snapshots, actual synthetic Codex/Claude filter and pagination behavior, TOML persistence/private-path preservation, malformed config and filters, binding failures without guessing a host process, remote-dispatch ordering, nonblocking202 and cached price status without network.

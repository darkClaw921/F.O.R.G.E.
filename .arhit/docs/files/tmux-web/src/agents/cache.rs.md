# tmux-web/src/agents/cache.rs

Version3 private metadata cache, source cursors and contribution availability. SourceState retains related session_ids for journal polling plus transient event_session_ids containing actual event owners only. refresh_session_ids collects distinct typed identities before canonical encoding; owner IDs exclude parent-only references so a failed subagent source does not invent an unavailable root. The transient set is skipped in serialization and regenerated by load for every existing v3 cache, requiring no migration or loss of retained history. save serializes a borrowed SnapshotRef under the caller ingestion lock, preserving the previous JSON byte format while avoiding a deep source/event-map clone. Tests verify owner/parent distinction, old-cache rebuild and byte-identical borrowed persistence. No prompts, source text or additional personal data enter the cache.

# tmux-web/src/agents/bindings.rs

Exact agent session to tmux pane matching shared by automatic and manual bindings. resolve(tasks, inventory, previous, book) uses only native session IDs proven by profile-scoped Claude registry, explicit resume arguments or open source log files; cwd is never evidence. Session IDs copied to several profiles or multiple independent processes/panes remain ambiguous. Node/bun/deno wrappers collapse into their native child while independent native CLIs stay separate; a wrapper resume argument may identify its leaf process. Linked aliases of one stable pane_id receive the same binding, without creating duplicate root tasks. Temporary exact-evidence silence preserves a prior valid identity; complete inventory failure retains prior bindings. BindingBook keeps process-lifetime manual choices and explicit detach suppression. Manual selection validates a current unended task, provider, exactly one logical CLI in the pane and known PID/start identity, rejects processes already bound to another active session, and never adopts an arbitrary shell by cwd. Manual and detach entries expire on pane/process disappearance or PID reuse. Tests verify same-folder isolation, wrapper/native resolution, independent-process ambiguity, native/profile disambiguation, linked expansion, PID reuse, explicit detach and failed inventory preservation.

# tmux-web/src/agents/sources.rs

AgentConfig loads private agents.toml under XDG_CONFIG_HOME/forge (default ~/.config/forge) and augments standard local CLI journal roots. Defaults include Claude .claude/.config/claude and CLAUDE_CONFIG_DIR projects, Codex normal/archived sessions with a shared CODEX_HOME profile identity, XDG_DATA_HOME OpenCode, and Copilot session-state. Canonical roots deduplicate symlink aliases. Discovery accepts provider-specific regular files only, rejects sockets/FIFOs and directory symlinks, bounds traversal depth and isolates unreadable roots. Files are newest-first for live priority, history defaults to 91 days. Saving config uses forge_atomic, never rewrites CLI settings or credentials. AgentRoot carries provider/path/profile so multiple accounts remain distinct.

# tmux-web/src/attention_prompt.rs

Read-only native interactive attention for Codex, Claude Code and verified OpenCode layouts. Recognizes waiting approvals, structured choice questions and freeform question tools using native headings, selection rows and final keyboard footers. Ordinary assistant prose, idle composers, quoted history and answered screens do not qualify. Capture uses one tmux process per unique physical pane with pre/post pane identity and copy/dead-mode metadata, independent of the autoapproval toggle and agent-statistics enabled setting. Observer remembers uncertainty per physical pane/root PID, aggregates all windows including inactive panes, reuses linked-alias captures, and leaves existing linked-primary selection to attention.rs. It never sends keys, approves requests, persists terminal text or scans transcript archives/process trees. Tests cover permissions/questions, stale/quoted negatives, identical independent sessions, linked aliases, multiple panes, uncertainty, copy-mode retention and an isolated private-socket inactive TUI clearing after answer.

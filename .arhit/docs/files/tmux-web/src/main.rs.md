# tmux-web/src/main.rs

Точка входа devforge: сборка AppState, хост-роутов (терминал, сессии, todos, аналитика, PWA) и монтирование opt-in плагинов. Плагины регистрируются последовательными блоками — Echo, Telegram, VK, Bitrix24, forge-meet, forge-tracker — СТРОГО до .fallback(static_embed::serve_static) и до .layer(...): регистрация после .fallback дала бы 404 на роуты плагина, после .layer — дыру в авторизации, потому что bearer_auth и csrf_guard покрывают только зарегистрированное под ними. Каждый блок гейтится соответствующим полем EffectiveConfig (tracker_enabled и т.д.), а ошибка init логируется через warn и НЕ роняет сервер (`?` в этих блоках запрещён). Симметрично в graceful-shutdown вызываются forge_*::shutdown, причём плагины гасятся до финального снимка истории сессий.

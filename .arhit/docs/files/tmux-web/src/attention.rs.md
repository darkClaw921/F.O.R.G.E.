# tmux-web/src/attention.rs

Holds independent orange input-required state and journal-derived agent working state. Orange detection now uses the read-only attention_prompt observer for Codex, Claude Code and verified OpenCode native permission/question overlays across all physical panes/windows. Existing detect_claude_prompt, prompt_at_bottom and permission autoapproval parsing remain unchanged; widened native detectors are not used to answer or approve anything. Unknown/copy-mode reads retain only same-pane/process known state; successful answered reads clear it. Linked-primary dedup remains session-group-only and independent equal-text sessions keep separate signals. Working clocks/counts/providers and explicit-only Echo idle continue through AgentActivityObserver and AgentStatsStore. Old hash_pane is now test-only because production no longer hashes terminal output.

# tmux-web/src/codex_memory.rs

Serves native global Codex memory for the shared brain modal. GET /api/codex-memory reads CODEX_HOME (or HOME/.codex), exposes memories/**/*.md and agent-memory/**/*.md with source-qualified relative keys, optional memories/MEMORY.md index_name/index, global scope, exists and truncation state. Native memory is generated by Codex and may be regenerated; agent-memory contains persistent sub-agent notes. No project filter is applied and no memory is created automatically. PUT edits existing Markdown only, preserving UTF-8 contents. Validation restricts sources, path components, suffix and size; descriptor-relative openat with O_NOFOLLOW rejects file, directory and source symlinks, including enumeration-to-open replacements. Enumeration is bounded to 1024 files, eight nested directories, one MiB per file and 16 MiB total; truncation is reported. Blocking disk operations run in Tokio spawn_blocking. Remote reads return an empty scope and remote writes are rejected. Tests use only isolated temporary fixtures, covering native/sub-agent read/write, absent stores/indexes, traversal, source/parent/file symlinks, size limits and HTTP error contracts.

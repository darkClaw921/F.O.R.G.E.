# tmux-web/src/capacity_recovery.rs

Default-on Codex capacity recovery for terminal chats. The lightweight two-second worker reuses AgentRuntime native Codex process/TTY/pane inventory without scanning transcripts or using LLMs. It requires one exact non-wrapper Codex candidate and PID/start identities for both the pane root and CLI. Native red model-capacity error must be the latest output immediately above an empty styled composer; the optional background-terminal notice is allowed. Physical capture rows preserve cursor coordinates. ANSI dim2 distinguishes a placeholder from a typed draft, including Home-cursor and multiline drafts. Copy mode, hidden cursor, dead pane, nonalternate screen, busy footer, stale output and quoted errors are rejected. Stable initial error waits15seconds. A visible occurrence is consumed once; subsequent genuine failure contexts back off30/60/120/240/300seconds. Footer counters, colors and line wrapping are excluded from occurrence hashes; resize alone is never a new error. A fresh capture and live process identities are rechecked before literal Russian continuation plus Enter to the same physical pane. State is memory-only and captured text is never logged or cached. A stale or disabled agent inventory suspends recovery. Tests use a private tmux socket and synthetic raw-terminal UI; no running user agent is messaged.

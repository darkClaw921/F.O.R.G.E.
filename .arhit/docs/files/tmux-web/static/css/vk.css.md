# css/vk.css — стили панели VK (раздел «имя и @ник в строке беседы»)

Самодостаточный файл: панель живёт в собственной палитре и НЕ наследует токены
приложения.

## Раскладка первой строки элемента списка

`.vk-dialog-name` — флекс с ЯВНЫМ ПОРЯДКОМ ЖЕРТВ при нехватке места:
  * `.vk-dialog-bot` ([BOT]) и `.vk-muted-mark` ([M]) — `flex-shrink: 0`,
    не ужимаются никогда: это состояние беседы, а не текст, и «полметки» не
    бывает;
  * `.vk-dialog-nick` — `flex: 0 200 auto`, ужимается ПЕРВЫМ: это приписка, и
    её потеря восстановима наведением (подсказка «Имя (@ник)»);
  * `.vk-dialog-title` — `flex: 0 1 auto` + ellipsis, ужимается последним.
Счётчик непрочитанного живёт во второй строке (`.vk-dialog-status`) и под это
давление не попадает вовсе.

Раньше строке хватало обычного nowrap + ellipsis: в ней стоял слаг
(`durov@node`, максимум 24 знака). Человеческое имя длины не имеет — у бесед
встречаются заголовки на 60+ символов, — и при старом правиле имя вытеснило бы
за край всё, что правее.

## Цвет ника

`.vk-dialog-nick` и `.vk-session-nick` красятся `--v-faint-text` (#7885A0 в
тёмной теме) — токеном приглушённого ТЕКСТА, а не рамочным `--v-acc-faint`.
Разница принципиальная: именно этой подменой токен был испорчен когда-то
(1.1–1.3:1, текст-невидимка), и щит от возврата стоит в
tests/frontend/vk_theme_contrast.test.mjs. Контрасты #7885A0: 5.44 / 5.32 /
5.15 / 4.52 к --v-bg / --v-panel / --v-bar / --v-active — отдельного «яркого»
токена для подсвеченной строки, в отличие от телеграмной панели, здесь не
понадобилось. В светлой теме — #5E7791.

## Шапка сессии

`#vk-session-head` СОЗНАТЕЛЬНО остался однострочным блоком с ellipsis, а не
флексом: он обрезается справа, то есть жертвует хвостом (⌁ PACKETS · ◇ KEY), а
не именем открытой беседы. Ник в шапке — отдельный узел `.vk-session-nick`,
его рисует js/vk/chat.js::updateHead по sessionHeadParts.

Проверяется тестом tmux-web/tests/frontend/vk_dialog_name.test.mjs — он читает
САМ css/vk.css (Node каскад не считает) и сверяет контрасты формулой WCAG из
js/messenger/theme-core.js::contrastRatio.

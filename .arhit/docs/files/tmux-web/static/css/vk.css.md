# tmux-web/static/css/vk.css

Стили ТОЛЬКО панели «ВКонтакте» (#vk и её оверлеи: #vk-login, #vk-captcha, #vk-lightbox, #vk-analysis). Изоляция проверяется vk_contract.test.mjs: файл не смеет содержать селекторов .tg-/#tg-/#telegram/.b24-/#bitrix, иначе виноватой за поломку выглядела бы соседняя панель. Цвета — только через токены --v-* (контраст проверяет vk_theme_contrast.test.mjs).

Попап анализа: .vk-analysis-controls — flex с переносом строкой, рассчитан на пять кнопок (ANALYZE, REFRESH, STOP, CLEAR, CLEAR Q&A) плюс поле глубины. .vk-analysis-btn гасит и width:100% от .vk-login-btn, и её margin-top: последний нужен вертикальной колонке экрана логина, а в горизонтальном ряду ронял бы вторичные кнопки ниже основных. .vk-analysis-updated — приглушённая строка «разобрано до <дата>, N сообщений»; :empty не занимает места вовсе, чтобы попап до первого разбора не выглядел недорисованным. .vk-analysis-out (разбор) и .vk-analysis-thread (Q&A) — два независимых блока со своей прокруткой и своими max-height (46vh и 24vh), на узком окне карточка занимает экран целиком.

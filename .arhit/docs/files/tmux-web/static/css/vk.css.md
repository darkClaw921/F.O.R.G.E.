# tmux-web/static/css/vk.css

CSS вкладки VK. forge-8tjz (2026-08-06): удалено правило .vk-line-own { background: color-mix(in srgb, var(--v-active) 45%, transparent) }, которое красило фон строки собственных сообщений в ленте (пользователь: "почему мои сообщения имеют подсветку на заднем фоне? нужно сделать как в телеграм плагине"). Тот же класс .vk-line-own продолжает ставиться в разметке (chat.js:525, upload.js:732 — pending-заливка) и используется JS-логикой (различение своих строк), но визуально теперь ничем не отличается от чужих строк, кроме цвета ника (.vk-line-nick-own — var(--v-cyan) вместо var(--v-acc) у .vk-line-nick). Это ровно та же схема, что у Telegram (.tg-line-own без фона, только .tg-line-nick-own красит ник) и у Bitrix (forge-zw3d, тот же фикс для .b24-line-own). Живая проверка на реальном VK-аккаунте: групповой чат с несколькими участниками, зум на пиксели подтвердил — фон own-строк идентичен фону чужих строк построчно.

# tmux-web/static/css/agents-settings.css

Стили формы источников/тарифов и компактного блока счётчика в настройках. Используют существующие --fg/--fg-dim/--border/--accent и общие agent controls. Дополнительные каталоги показаны четырьмя колонками на широком экране; на мобильном провайдер и удаление остаются в первой строке, путь и профиль занимают ширину строки. Details и кнопки имеют keyboard focus; длинные адреса каталога переносятся. Файл подключает общий frontend writer через style.css.

Root-row содержит label.agent-field wrappers с постоянными подписями provider/path/profile; align-items:end выравнивает кнопку удаления к inputs. На ширине до 700px path/profile занимают всю строку, provider и remove первую. Общая column form сохраняет естественную высоту полей; правила flex-basis относятся только к фильтрам нового режима.

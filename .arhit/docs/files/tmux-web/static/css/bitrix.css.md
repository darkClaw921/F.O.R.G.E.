# tmux-web/static/css/bitrix.css

Палитра и вёрстка вкладки «Битрикс24». Префикс всех классов — b24-, id — b24-* (кроме корня #bitrix и кнопки #bitrix-toggle). Файл САМОДОСТАТОЧЕН: @font-face и все media-queries живут здесь, а не в mobile.css.

ИЗОЛЯЦИЯ. Ни одного селектора .tg-, .vk-, #telegram, #vk — инвариант проверяется tests/frontend/bitrix_contract.test.mjs. Панель НЕ наследует токены приложения: 12 переменных объявлены на #bitrix, светлая тема (#bitrix[data-b24-theme="light"]) переопределяет ВСЕ до единого. Единственный !important в файле — #bitrix[hidden] { display: none }.

Токены: --b-bg/--b-panel/--b-bar/--b-active (фоны), --b-acc/--b-acc-dim/--b-acc-hi/--b-faint-text/--b-red/--b-green/--b-cyan/--b-violet (текст), --b-acc-faint (РАМКИ, не текст — смешение этих двух ролей было дефектом VK). Акцент оранжевый #FF9F43: он обязан отличаться от зелёного Telegram и синего VK, иначе сообщение уходит не в тот чат. Каждое значение прогнано через контраст-чекер, цифры — в комментариях; страж — tests/frontend/bitrix_theme_contrast.test.mjs.

Разделы: кнопка вкладки, панель и токены, светлая палитра, titlebar, тело (колонка + сессия), строка списка, карточка задачи (Ф10), лента и строки сообщений, медиа-карточки (Ф8), клавиатуры ботов, очередь отправки (Ф9), оверлеи (login, dropzone, lightbox), статусбар, курсор клавиатуры и шпаргалка (Ф11), prefers-reduced-motion, узкие экраны (Ф11).

Ф11 добавила: .b24-kb-cursor (полоска слева, а не рамка — рамка сдвигала бы содержимое строки и лента дёргалась бы на каждом шаге курсора), блок .b24-keys-help* (шпаргалка строится в keynav.js::showHelp) и мобильные правила в @media (max-width: 768px) — off-canvas колонка, полная ширина сессии, safe-area-inset для prompt и статусбара, 100dvh под экранную клавиатуру, схлопывание карточки задачи. Порог 768 продублирован в js/bitrix/mobile.js, и комментарий-напоминание стоит в обоих местах.

# tmux-web/static/css/agents.css

Общие стили статистики агентов: переключатель режимов, гибкая строка фильтров, типографика, ошибки и host секции. Палитра полностью наследуется от семантических CSS-переменных FORGE; литералы тем не добавляются. hidden явно сильнее display секций. На мобильных фильтры переносятся, поля дат занимают доступную ширину. Focus-visible использует --accent, чтобы селекторы и действия оставались доступными с клавиатуры.

Mobile flex-basis 140px ограничен прямыми .agent-filters > .agent-field. Вложенные поля формы настроек остаются естественной высоты. Persistent labels, focus-visible и inherited theme palette действуют для всех новых форм.

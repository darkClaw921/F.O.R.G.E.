# tmux-web/static/css/agents-history.css

Стили исторической части статистики в существующей теме FORGE. Семантические переменные управляют фоном, текстом, границами и фокусом; новых цветов и шрифтов не вводится. Definition-list сводки использует адаптивную сетку, дневные SVG-графики две колонки и широкую строку времени, модели и проекты располагаются рядом на широком экране. На 900px разрезы переходят в одну колонку, на 600px графики становятся одноколоночными и KPI сохраняют читаемые две колонки. Таблицы прокручиваются только в собственных region-контейнерах; длинные пользовательские названия и пути переносятся, числа используют табличные цифры. Панель пагинации переносится без замены контролов. Focus-visible region-контейнера использует акцент темы.

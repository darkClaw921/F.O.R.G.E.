# tmux-web/static/css/tracker.css

Палитра и раскладка панели forge-tracker. Панель НЕ наследует токены приложения: у неё свои переменные --t-* под атрибутом data-tracker-theme (зелёный терминальный набор из макета ~/Documents/ForgeTracker.pen). Содержит: титлбар и левую колонку, ленту режима list, доску kanban (прокручивается КОЛОНКА, а не страница), сетку Гантта, карточку задачи #trk-modal (z-index 30), диалог переноса в tasks/todo #trk-push (z-index 40, стоит ПОВЕРХ карточки, потому что перенос вызывается и из открытой карточки) и .trk-note-link — действие в строке статуса, которым панель заменяет себе тост. Правило #tracker[hidden] { display: none !important } обязательно: собственный display: flex у #tracker побеждает атрибут hidden, и без него панель висела бы под терминалом на всех вкладках (такое же правило есть у #vk и #telegram).

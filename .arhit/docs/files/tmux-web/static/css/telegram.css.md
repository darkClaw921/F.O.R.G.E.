# css/telegram.css — стили вкладки Telegram

Самодостаточный файл: панель живёт в собственной палитре и НЕ наследует токены
приложения. Подключён через @import в static/style.css ПЕРЕД mobile.css.

## Шрифт (решение Фазы 6)

JetBrains Mono ЗАВЕНДОРЕН: `static/vendor/fonts/jetbrains-mono/` (Regular 92 КБ
+ Bold 95 КБ + OFL.txt). Два @font-face с `font-display: swap`; `src`
начинается с `local('JetBrains Mono')`, поэтому у кого шрифт установлен —
тот ничего не скачивает. CDN ЗАПРЕЩЁН: devforge обязан работать офлайн, а
вкладка показывает переписку — внешний запрос с Referer'ом здесь неуместен
вдвойне. rust-embed подхватывает static/** целиком, mime_guess отдаёт
`font/woff2` (закреплено тестом в tmux-web/src/static_embed.rs).

## Токены

Тёмная палитра — дефолт, объявлена на `#telegram`; светлая — на
`#telegram[data-tg-theme="light"]` (переключает js/telegram/theme.js).

- `--t-bg`, `--t-panel`, `--t-bar`, `--t-active` — поверхности;
- `--t-grn`, `--t-grn-dim`, `--t-grn-hi` — текст трёх уровней;
- `--t-grn-faint` — РАМКИ;
- `--t-faint-text` — приглушённый ТЕКСТ (метки времени, разделители дат,
  приписки, удалённые строки). Отдельный токен появился в Фазе 6: в тёмной
  теме он алиас на `--t-grn-faint`, а в светлой `#B4C7BB` на фоне `#E7ECE6`
  давал контраст 1.5:1 и текст исчезал. Теперь `#6F8C7C` = 3:1.
- `--t-amber`, `--t-cyan`, `--t-red` — состояния.

## Ответы на сообщения (R1/R2)

Новые классы (сверены с реальным DOM chat.js, а не с ТЗ):
- `.tg-reply-quote` + `-name` / `-text` — цитата в строке сообщения; одна строка с
  nowrap + ellipsis (`.tg-line` отдаёт по наследству `pre-wrap`, и без этого цитата ломала бы
  ритм ленты). `:not([data-reply-to])` — цитата без оригинала (ответ на сторис): курсор-палец не
  обещает несуществующий переход;
- `.tg-reply-bar` + `-name` / `-text` / `.tg-reply-cancel` — полоса «отвечаю на …» над #tg-prompt.
  Маркер «↳» рисует CSS (`::before`), а не JS: в полосу приходят только имя и превью из Telegram, и
  конкатенация служебного символа попала бы под обрезку ellipsis. Полоса строго однострочная,
  поэтому съесть поле ввода на узком экране не может по построению;
- `.tg-reply-btn` — кнопка «↰» на строке. Прячется `opacity: 0` + `pointer-events: none`, а НЕ
  display/visibility: так она остаётся в порядке табуляции (иначе действие недоступно с
  клавиатуры), но не перехватывает клики и выделение текста. Показ — `.tg-line:hover`,
  `.tg-line:focus-within`, `.tg-reply-btn:focus-visible`; для тач-устройств отдельный
  `@media (hover: none)` — сигнал «нечем наводить» точнее ширины экрана;
- `.tg-msg-highlight` + `@keyframes tg-msg-flash` — подсветка строки после перехода по цитате.
  Плотность вынесена в `--tg-flash` / `--tg-flash-peak`, чтобы анимация ЗАКАНЧИВАЛАСЬ ровно
  статическим цветом (иначе на исходе 0.9s строка дёргала бы цветом: chat.js держит класс 2000 мс)
  и чтобы светлая тема получила более плотный тон. Маркер слева — inset-тень токеном без
  color-mix: где color-mix не поддержан, полоса всё равно отвечает «куда меня перенесло».
- `.tg-line` получил `position: relative` (его не было) — кнопка «ответить» висит абсолютом.
  Единственные абсолюты внутри строки (`.tg-media-play`, `.tg-media-duration`) держит
  `.tg-media-body` со своим position, поэтому новый контекст их не трогает.

## Слои (z-index)

3 — подложка off-canvas-колонки; 4 — сама колонка; 5 — оверлей логина;
6 — titlebar и statusbar (НАД логином: тумблер темы и состояние связи обязаны
оставаться доступны до входа в аккаунт); 7 — dropzone и лайтбокс (модальные,
несут собственные кнопки).

## Анимации (Фаза 6)

- `@keyframes tg-blink` — каретка `.tg-caret`, 1.05с, `step-end`. Видна только
  пока поле пустое: `#tg-input:not(:placeholder-shown) + .tg-caret` гасит её
  (в разметке у input стоит `placeholder=" "` — пустой placeholder включает
  `:placeholder-shown` не во всех браузерах).
- `@keyframes tg-pulse` — точка `.tg-pulse`, 2с. Цвет задаётся классом
  состояния на `#tg-titlebar` (`tg-conn-connected|reconnecting|offline`),
  который ставит main.js::setMode вместе с Mode-бейджем. В offline анимация
  выключена: мигающий красный читался бы как «идёт работа».
- Анимируются ТОЛЬКО opacity и transform — никакого layout.
- `@media (prefers-reduced-motion: reduce)` гасит всё поимённо (каретка
  становится постоянной, точка замирает в полном цвете). Для подсветки цитаты гасится ТОЛЬКО
  затухание — сама подсветка остаётся, иначе переход по цитате теряет смысл.

## Узкие экраны

`@media (max-width: 768px)` живёт ЗДЕСЬ, а не в mobile.css — так файл остаётся
самодостаточным. Колонка контактов становится off-canvas (см.
js/telegram/mobile.js), появляется ☰, скрывается длинная строка titlebar,
медиа-карточки становятся `width:100%`, панель ограничивается `100dvh`
(виртуальная клавиатура). Для ответов там компактные отступы полосы и более узкое имя автора
(30%), кнопка «↰» видна всегда. Отдельный `@media (max-width: 480px)` убирает центр
статусбара и заголовок.

## Обязательный сайзинг

`#main` — flex-колонка, поэтому `#telegram` обязан быть `flex: 1 1 auto;
min-height: 0`, иначе лог с overflow растягивает контейнер и ломает layout
соседних вкладок. Единственный `!important` в файле — `#telegram[hidden]`.

## Приглушённый текст и @ник в строке чата (правка «имя вместо слага»)

`--t-faint-text` был объявлен как `var(--t-grn-faint)` — то есть цветом РАМОК
(ровно тем дефектом, от которого отдельный токен и должен был защищать; тот же
баг чинили в css/vk.css). Контрасты были 1.59 / 1.56 / 1.52 / 1.29 к --t-bg /
--t-panel / --t-bar / --t-active: текст физически невидим, а с появлением @ника
в строке чата это стало заметно сразу.

Новое значение `#708373` — серо-зелёный: 4.97 / 4.87 / 4.75 к --t-bg /
--t-panel / --t-bar. Яркости `--t-grn-dim` (основной текст) он НЕ превышает
(WCAG-L 0.20915 против 0.20919) — иерархия держится обесцвеченностью, а не
светом: размах каналов 19 против 99 у насыщенного #2C8F5A.

`--t-faint-text-hi` (`#7A8B77`) — тот же текст НА ПОДСВЕЧЕННОЙ СТРОКЕ
(фон --t-active). Отдельный токен нужен потому, что на #0E241A потолок для
яркости --t-grn-dim — 4.03:1, то есть AA там недостижим ни для одного цвета,
который не ярче основного текста. Но на --t-active основной текст ДРУГОЙ:
строка под курсором красится --t-grn (12.29:1), активная — --t-grn-hi
(14.41:1), и потолок поднимается вместе с фоном. #7A8B77 даёт ровно 4.50:1 к
--t-active (5.55 / 5.43 / 5.30 к остальным фонам) и остаётся втрое темнее
--t-grn. Применяется ТОЛЬКО к @нику строки чата: превью цитаты на наведении
трогать нельзя — там сосед это имя автора цвета --t-grn-dim, и подсветка
сделала бы приписку контрастнее того, чему она подчинена. В светлой теме токен
намеренно равен базовому (`var(--t-faint-text)`): там потолок задаёт сам
--t-grn (3.18:1 на --t-active).

## Раскладка первой строки элемента списка

`.tg-dialog-name` стал флексом с ЯВНЫМ ПОРЯДКОМ ЖЕРТВ: `.tg-dialog-bot` и
`.tg-muted-mark` не ужимаются никогда (`flex-shrink: 0`), `.tg-dialog-nick`
ужимается первым (`flex: 0 200 auto`), `.tg-dialog-title` — последним и
получает ellipsis. Раньше строке хватало обычного nowrap + ellipsis: слаг был
не длиннее 24 знаков. Человеческое имя длины не имеет (у групп встречаются
заголовки на 60+ символов) и при старом правиле вытеснило бы за край и ник, и
[BOT], и [M]. Счётчик непрочитанного живёт во второй строке
(`.tg-dialog-status`) и под это давление не попадает вовсе.

`#tg-session-head` СОЗНАТЕЛЬНО остался однострочным блоком с ellipsis, а не
флексом: он обрезается справа, то есть жертвует хвостом (⌁ PACKETS · ◇ KEY), а
не именем открытого чата — это его поведение было и до появления ника.
Приглушает ник там `.tg-session-nick`.

Проверяется тестом tmux-web/tests/frontend/telegram_dialog_name.test.mjs — он
читает САМ css/telegram.css (Node каскад не считает) и сверяет контрасты
формулой WCAG из js/messenger/theme-core.js::contrastRatio.

# tmux-web/static/css/modals.css

Стили общих модальных окон FORGE. Для .claude-memory-modal сохранено прежнее семейство классов, расширенное общим просмотром Claude/Codex: кнопки источников с aria-pressed получают тему accent/fg-on-accent, scope и путь памяти используют dim и overflow-wrap:anywhere. Полные имена nested Codex файлов переносятся без горизонтального overflow. Desktop ширина 60vw с min/max ограничениями viewport; при max-width:768px memory card занимает 100dvw и поддерживает общий mobile full-screen режим. Область текста ограничена 60vh и прокручивается; редакторы, ошибки и back navigation сохраняют общие theme tokens. Новых hardcoded product цветов нет.

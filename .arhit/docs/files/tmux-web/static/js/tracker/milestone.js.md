# tmux-web/static/js/tracker/milestone.js

Диалог вехи Гантта (MILESTONE > gantt) — заменил два window.prompt в main.js.

ЗАЧЕМ. Раньше веха заводилась и правилась двумя window.prompt подряд (подпись, затем дата строкой ГГГГ-ММ-ДД): дату приходилось набирать руками — единственное место панели без пикера; удаление пряталось за 'сотри подпись'; браузерная модалка невидима для автоматизации (ни CDP, ни e2e-гейт её не видят).

ФОРМА. Разметка #trk-ms в index.html — близнец #trk-push (диалог переноса): затемнение, карточка в терминальной рамке, титульная строка с [esc], тело и подвал CANCEL / OK. Отличия: поля 'подпись' (input text) и 'дата' (input type=date), а слева в подвале — DELETE, видимый ТОЛЬКО при правке существующей вехи (создание удалять нечего).

ЭКСПОРТЫ:
- milestonePatch(ms, form) — ЧИСТАЯ: тело PATCH только из изменённого. Правка одной подписи не трогает дату и наоборот; сброса у вехи нет (веха без даты не существует), поэтому пустая подпись и негодная дата в патч не попадают.
- milestoneReady(form) — ЧИСТАЯ: создавать можно только с подписью и датой; пока не годна, кнопка OK/ADD погашена (иначе заведомый 400).
- openMilestoneDialog(ms|null, defaultDate), closeMilestoneDialog(), isMilestoneOpen() (нужна modals.js, чтобы Esc снимал ровно один слой), initTrackerMilestone(deps), teardownTrackerMilestone().

DOM СНАРУЖИ. Как в to-todo.js: узлы (*, из core/dom.js) и сервисы (create/patch/remove через api.js, note) приходят в initTrackerMilestone из main.js — модуль не импортирует core/dom.js и потому импортируем в node, где и проверены обе чистые функции (tests/frontend/tracker_fields.test.mjs).

ПОВЕДЕНИЕ. Enter внутри диалога = OK, Esc = CANCEL, клик по затемнению закрывает. Флаг busy защищает от двойного клика. Ошибка сети показывается В ДИАЛОГЕ, набранное не пропадает. Своей перерисовки нет: сервер на любую правку вехи шлёт кадр reload, панель перечитывает снимок, снимок тянет refreshGantt — ромб переезжает во всех открытых окнах.

Живьём проверено: создание (ромб встал в клетку today), правка даты (+2 дня — ромб на 2 клетки правее), правка только подписи (дата не поехала), DELETE (ромб и чип исчезли).

# tmux-web/static/js/vk/mobile.js

Off-canvas колонка бесед панели VK на узких экранах. На десктопе #vk-contacts — обычная колонка внутри #vk-body; на ширине <=768px она уезжает за левый край и выезжает поверх ленты по кнопке ☰. Открытое состояние — класс vk-contacts-open НА #vk, а не на самой колонке: одним состоянием управляются ТРИ элемента (колонка, подложка #vk-contacts-scrim, aria-expanded кнопки), и общий предок избавляет от рассинхронизации. Порог 768 ПРОДУБЛИРОВАН в css/vk.css (CSS не читает JS-константы) — расхождение даёт худший из багов: колонка уже нарисована выезжающей, но closeVkContactsAfterSelect считает экран широким и не закрывает её после выбора беседы; напоминание об этом стоит в обоих местах. Закрытие: выбор беседы (главный сценарий), клик по подложке, Esc (обработчик на документе реагирует только при открытой колонке), уход на десктопную ширину через matchMedia. Модуль намеренно НЕ трогает hidden у колонки — на десктопе это единственный список бесед, скрывает её только transform. Экспорт: initVkMobile (идемпотентна), setVkContactsOpen, closeVkContacts, toggleVkContacts, closeVkContactsAfterSelect, isVkNarrowScreen, _debugVkMobile.

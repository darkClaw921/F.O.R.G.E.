# tmux-web/static/js/vk/keynav.js

Клавиатурная (vim) навигация по панели VK: курсор по беседам и ленте, действия над сообщением, шпаргалка, реестр комбинаций через js/vk/keys.js.

ГЕЙТЫ ВЛАДЕНИЯ (panelVisible / vkOwnsKeyboard). panelVisible() возвращает false, если: панели нет или она скрыта; открыт оверлей логина #vk-login; открыт оверлей captcha #vk-captcha (отличие VK от Telegram — код 14 прилетает на любой метод API); открыт попап анализа чата #vk-analysis. Последняя ветка добавлена в фазе 4 фичи «Анализ чата» и является P0: внутри попапа два поля ввода (вопрос модели и заметка о беседе), и без гейта одиночные j/k листали бы список бесед вместо набора текста — вопрос стало бы физически не написать. vkOwnsKeyboard() дополнительно требует включённого тумблера и фокуса внутри панели.

Тест: tmux-web/tests/frontend/vk_keynav.test.mjs (собственный фейковый DOM: составные селекторы, activeElement, capture-фаза).

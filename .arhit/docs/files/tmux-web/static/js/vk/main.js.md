# tmux-web/static/js/vk/main.js

Сборка панели VK: гейт кнопки Ⓥ, постоянный WS, карта кадров, бейдж непрочитанного, тосты, белый список бесед.

buildHandlers() покрывает ВСЕ варианты VkServerMsg. С Ф5 в карте есть секция «--- анализ чата ---» с четырьмя обработчиками (analysis_started / analysis_delta / analysis_done / analysis_error), которые только делегируют в js/vk/analysis.js: решение «мой ли это кадр» принимает попап, потому что сервер вещает события без фильтрации по беседе, и в открытый попап одинаково прилетают кадры чужого разбора из соседней вкладки. Импорт обработчиков идёт из './analysis.js' рядом с initAnalysis/openAnalysis/teardownAnalysis.

Кадры анализа к LongPoll отношения не имеют — это поток локального процесса claude, вещаемый тем же сокетом.

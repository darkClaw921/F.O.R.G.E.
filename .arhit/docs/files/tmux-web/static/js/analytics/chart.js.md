# tmux-web/static/js/analytics/chart.js

SVG-кит дашборда аналитики (Фаза 4) — семь типов чартов без единой сторонней зависимости.

ЗАЧЕМ. В devforge нет chart-библиотек и заводить их нельзя: фронт целиком едет в бинарь через rust-embed, а сторонний рантайм принёс бы собственную палитру, которая не следует за пользовательской темой (11 переменных themes.rs, меняются одним setProperty на <html>).

ПУБЛИЧНОЕ API. Единая сигнатура chart(container, data, opts) -> {update(data, opts), redraw(), svg}; update() перерисовывает НА МЕСТЕ, redraw() нужен после смены темы.
- barChart(el, {labels, values, overlay?:{label, values, format?}}, opts) — столбцы + НЕОБЯЗАТЕЛЬНАЯ наложенная линия на СВОЕЙ, независимой оси справа (чарт 1: сообщения по дням + новые сессии).
- lineChart(el, {labels, series:[{label, values}]}, opts) — 1..5 линий (чарты 3, 9, 10).
- hbars(el, [{label, value, secondary}], opts) — горизонтальные полосы, secondary рисуется ВНУТРИ полосы статусным --warn (доля прерванных вызовов; это состояние, а не серия, поэтому слот палитры не занимает) — чарты 6, 8.
- donut(el, [{label, value}], opts) — доли (чарт 7); хвост сверх пяти сворачивается в «Другое», нулевая сумма даёт пустое кольцо без деления на ноль.
- stackedArea(el, {labels, series}, opts) — стек по корзинам (чарты 4, 5); шкала по МАКСИМУМУ СУММЫ корзины, одна корзина рисуется столбиками стека, наведение по корзине даёт полный разрез.
- histogram(el, {labels, values}, opts) — бакеты пауз и длин (чарты 3, 9); пустой бакет сохраняет подпись и остаётся столбиком нулевой высоты.
- heatmap(el, {matrix, rowLabels?, colLabels?}, opts) — час × день недели (чарт 2); ОДИН оттенок --accent через fill-opacity 0.08..1.0, матрица нулей даёт ровный минимум, ночь 00-06 подчёркнута скобкой, рядом легенда шкалы.

ПРИМИТИВЫ (экспортируются и используются тестом): node(doc, tag, attrs) — ЕДИНСТВЕННАЯ точка создания узлов, всегда createElementNS; clear(el) — очистка без innerHTML; tip(doc, target, label) — <title> внутри фигуры + класс is-hover; finite/size/clamp — барьер против NaN и отрицательных координат; linearScale(d0,d1,r0,r1) — на вырожденном домене кладёт точку в середину диапазона вместо деления на ноль; niceTicks(min,max,target) — на [0,0] даёт шкалу 0..1, делений всегда больше одного; themeColors(container, opts) — цвета из CSS-переменных; foldSeries(items, max, otherLabel); форматтеры formatCompact/formatCount/formatMs/formatUsd/formatPercent/formatDay; константы SERIES_MAX=5 и SERIES_TOKENS.

ЦВЕТА. Только CSS-переменные, БЕЗ хекс-фолбэков (в отличие от js/echo/stats.js): хардкод пережил бы смену темы ровно у того пользователя, который тему и настроил. Последний рубеж — currentColor. Порядок слотов --accent → --warn → --agent-accent → --success → --danger прогнан валидатором палитры (симуляция дейтеранопии/протанопии, ΔE OKLab×100): худшая соседняя пара 10.9 при дейтеранопии и 33.1 при обычном зрении, контраст к --bg-elev у всех пяти >= 3:1. Шестого цвета не бывает никогда — хвост уходит в «Другое» приглушённым --fg-dim. Тема может переопределить слоты через --chart-1…--chart-5.

ОГРАНИЧЕНИЯ И ДОГОВОРЫ. Ни одного импорта (кит самодостаточен), ни одного innerHTML, ни одного createElement без NS, ни одного хардкод-цвета — всё это проверяется стражами в tests/frontend/analytics_chart.test.mjs. Отзывчивость через viewBox + preserveAspectRatio + width=100%, внутри — единицы графика 720x260, пиксели в разметку не попадают. Документ берётся из container.ownerDocument, окно — из ownerDocument.defaultView (глобали только как последний рубеж), поэтому кит рисуется на фейковом DOM без jsdom. У каждого чарта обязаны работать три состояния: пусто (заглушка «нет данных»), одна точка, все нули.

СВЯЗИ. Данные берёт дашборд (js/analytics/analytics.js, Фаза 5) и вкладка настроек (js/settings/analytics-tab.js, Фаза 6) из js/analytics/api.js; сам кит в сеть не ходит и разметки страницы не знает. Файл попадает в бинарь автоматически через rust-embed (static_embed.rs).

## Фаза 7 — восьмой тип чарта: band
`band(container, {labels, values}, opts)` — тонкая полоса категорий по корзинам, ради чарта «версии Claude Code по дням»: важен не размер, а МОМЕНТ смены. Ни оси Y, ни значений.

Решения: один тон (`--accent`) со ступенями непрозрачности по хронологии первого появления вместо палитры — в живом архиве за квартал 35 версий, и пять цветов по кругу дают конфетти, а «пять цветных плюс серое остальное» — серую ленту, где смен не видно. Крайние версии подписаны по краям, точная версия — в подсказке, даты смен подписаны снизу с минимальным зазором 44 px. Корзина без категории рисуется нейтральной заливкой `--border` с прозрачностью 0.35, а не пропускается: дыра в полосе читалась бы как «этого дня не было». Несколько категорий в одной корзине делят её ячейку по вертикали.

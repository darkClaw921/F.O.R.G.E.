# tmux-web/static/js/bitrix/visibility.js

Белый список видимых диалогов Битрикс24 (Ф4, финализация в Ф11).

Чистый модуль: ни DOM, ни сети, ни состояния; зависит только от format.js::dialogKind. Тест — tmux-web/tests/frontend/bitrix_visibility.test.mjs (58 ассертов).

ЭКСПОРТ: VISIBLE_KINDS (user|chat|task), kindLabel, filterKind, normalizeFilter, filterActive, dialogVisible, visibleDialogs, dialogIdVisible, visibleUnread, filterSummary, pruneMissingPeers.

ВСЕ ЧЕТЫРЕ ТОЧКИ ПРИМЕНЕНИЯ перечислены в шапке файла и в странице bitrix-visibility-model: колонка (dialogs.js::visibleSource), счётчики директорий (dialogs.js::renderDirs), бейдж вкладки (main.js::recomputeUnread — при действующем фильтре серверный total игнорируется целиком), тосты и накопление непрочитанного (main.js::maybeToast, Ф7). Пропуск любой = протечка скрытого диалога.

ГЛАВНОЕ ОТЛИЧИЕ ОТ VK: неизвестный диалог СКРЫТ. У VK тип беседы выводится из самого peer_id, здесь нет: 'chat7' — это и обычный чат, и чат задачи, различает их entity_type, которого в идентификаторе нет. Поэтому dialogIdVisible консервативен (как у Telegram): диалог вне загруженного списка при действующем фильтре скрыт, иначе фильтр протекал бы уведомлениями ровно от тех чатов, которые просили не показывать. Поимённый выбор работает и без списка.

ВКЛЮЧЁН НЕ ЗНАЧИТ ДЕЙСТВУЕТ: filterActive требует и тумблера, и непустого выбора — включённый режим с пустым списком дал бы пустую панель, что читается как поломка. Гейт bitrix_filter_enabled === true (дефолт выключено), в отличие от bitrix_hotkeys_enabled (!== false, дефолт включено).

ТРИ ВИДА вместо семи: sg/openline/copilot/collab сводятся к chat (filterKind) — отдельные галочки требовали бы знания внутренней терминологии портала.

ФАЗА 5. Точки применения белого списка не изменились (колонка, счётчики директорий, бейдж, тосты): лента фильтром не гейтится — открыть скрытый диалог можно только из колонки, а она уже отфильтрована.

## МУЛЬТИПОРТАЛЬНОСТЬ (Ф7)

Настройки видимости стали ПЕР-ПОРТАЛЬНЫМИ: белый список хранится в bitrix_portal_prefs (tmux-web/src/user_settings.rs), а модуль читает свой срез через portalPrefs(prefs, portalId). Скрытый чат ФОНОВОГО портала не имеет права протечь ни в одну из ЧЕТЫРЁХ точек применения: список диалогов, счётчики директорий, бейдж вкладки и тост. Раньше список был один на все порталы, и при действующем фильтре тост чужого портала подавлялся целиком (fail-closed) — это ограничение снято.

Модуль ПО-ПРЕЖНЕМУ чистый: ни DOM, ни сети, ни состояния. Это не стиль, а условие теста — bitrix_visibility.test.mjs импортирует его напрямую в голом Node (116 ассертов), и первый же импорт браузерного API сломал бы прогон.

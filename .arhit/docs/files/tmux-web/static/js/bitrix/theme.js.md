# tmux-web/static/js/bitrix/theme.js

Собственная тема вкладки «Битрикс24» (тумблер ◐ в titlebar). Панель нарисована в терминальной палитре и НЕ наследует токены приложения — все её цвета объявлены на #bitrix в css/bitrix.css, поэтому переключение темы devforge её не касается. На светлой теме приложения чёрная панель выглядит инородно, отсюда собственный переключатель.

Три режима (localStorage 'forge.b24Theme', по умолчанию auto): auto — светлота выводится из темы ПРИЛОЖЕНИЯ; dark и light — фиксированные, тема приложения игнорируется.

Как работает auto: глобального флага 'сейчас светлая тема' в devforge нет — js/themes/api.js::applyTheme просто расставляет CSS-переменные на :root. Поэтому светлота вычисляется из вычисленного значения --bg через чистые функции общего слоя js/messenger/theme-core.js (parseCssColor, relativeLuminance, resolveTheme), покрытые Node-тестом.

Как ловится смена темы приложения: applyTheme пишет переменные через root.style.setProperty, то есть меняет атрибут style у <html>. MutationObserver на attributeFilter ['style','class','data-theme'] — единственная развязка, которая не тянет плагин в модуль тем (обратный импорт замкнул бы граф модулей). Третий такой наблюдатель на странице (после Telegram и VK) приемлем: связать их означало бы править чужие панели, а стоимость одного callback'а на действие пользователя раз в месяц нулевая.

Экспорт: B24_THEME_STORAGE_KEY, loadB24ThemeMode, saveB24ThemeMode, appBackgroundColor, applyB24Theme (идемпотентна, DOM трогается только при реальном изменении; ставит data-b24-theme на #bitrix и data-b24-theme-mode на тумблер), setB24ThemeMode, cycleB24ThemeMode, initB24Theme (идемпотентна — повторный вызов не создаёт второго наблюдателя), teardownB24Theme, _debugB24Theme.

Вызывается из: core/bootstrap.js (старт страницы, ДО гейта — иначе вкладка мигнула бы чужой палитрой), js/tabs/tabs.js (вход на вкладку: в режиме auto пользователь мог сменить тему devforge, пока вкладка была закрыта) и самого наблюдателя.

ФАЗА 5. Лента и карточки рисуются ТОЛЬКО токенами палитры панели (--b-*), объявленными на #bitrix, поэтому переключение data-b24-theme перекрашивает историю целиком, включая системные строки, карточки ATTACH и кнопки клавиатур.

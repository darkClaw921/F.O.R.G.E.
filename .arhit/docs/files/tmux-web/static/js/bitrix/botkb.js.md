# tmux-web/static/js/bitrix/botkb.js

Inline-клавиатуры сообщений (Ф5, обновлено Ф6). buildKeyboard рисует ряды кнопок params.KEYBOARD; buttonState решает, нажимается ли кнопка ЗДЕСЬ И СЕЙЧАС (бэкенд знает про права портала через enabled/disabled_reason, фронт — про наличие обработчика); pressButton выполняет действие колбэком, сети в модуле нет вовсе. PUT подставляет ACTION_VALUE в поле ввода. SEND с Ф6 ОЖИЛ: chat.js передаёт onSendText, и кнопка отправляет текст тем же путём, что Enter (submitPrompt) — второй путь отправки означал бы вторую копию проверок лимита и режима ввода; без обработчика кнопка честно выключается с SEND_UNAVAILABLE в title. CALL и DIALOG выключены навсегда: они требуют scope imbot, которого у входящего вебхука нет и быть не может (§6 плана). Подпись кнопки пишет бот, поэтому она попадает в документ ТЕКСТОМ (cleanButtonText + textContent), а декоративные скобки рисует CSS.

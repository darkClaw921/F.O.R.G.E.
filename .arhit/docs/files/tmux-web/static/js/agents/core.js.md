# tmux-web/static/js/agents/core.js

Общий слой интерфейса статистики. PROVIDERS/providerName задают четыре стабильных идентификатора и подписи. el/clear создают и очищают DOM без разбора разметки источников. number/count/cost/clock/duration сохраняют отсутствие метрик, не превращая null в нулевой расход; tokenTotal суммирует input/output/cacheRead/cacheWrite и не добавляет reasoning повторно. rangeQuery вычисляет календарные today/7/30/91/custom фильтры, elapsed продолжает серверный elapsedMs без сравнения часов сервера и браузера. createPoller принимает load/getQuery/onData/onError и инъекцию timers: show запускает один visible-only интервал, change создаёт поколение запроса, hide инвалидирует ответы и удаляет таймер. Старое поколение и ошибки скрытого экрана не отрисовываются; медленный запрос текущего поколения не размножается.

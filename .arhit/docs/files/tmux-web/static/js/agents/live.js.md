# tmux-web/static/js/agents/live.js

Представление текущих основных задач на основе нормализованного AgentSnapshot. createAgentLive(host, deps) создаёт постоянные keyed строки по task.id: провайдер, состояние working/waiting/unknown, проект/модель, серверный elapsedMs и раздельные известные оценки стоимости. Токены подагентов уже включены сервером; неизвестные метрики не становятся нулём. Каждое обновление меняет тексты существующих узлов, сохраняя фокус и выбранную панель ручной привязки. Панели выбираются из доступного sanitized inventory с подходящим provider; linked aliases объединяются в один option физического paneId. bind/unbind отправляют точный sessionId без разбора tuple, обрабатывают pending/error, вызывают onChanged после успеха. Локальный ticker продолжает серверный elapsed от monotonic anchor; unknown время заморожено, hide/destroy удаляют таймер. Значения источников вставляются textContent.

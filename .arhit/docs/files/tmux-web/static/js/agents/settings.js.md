# tmux-web/static/js/agents/settings.js

Форма источников журналов и API-тарифов. createAgentSettings(host,{api,doc,onSaved}) создаёт закрытый details «Источники и тарифы» и постоянный DOM-черновик. show помечает форму видимой и запускает первую загрузку только при открытом details; hide инвалидирует незавершённый ответ, destroy удаляет DOM. Периодического опроса формы нет: live polling не может стереть draft или фокус.

Поля клиента строго ограничены enabled,discoverDefaults,roots[{provider,path,profile}],historyDays,priceUpdates,priceUpdateUrl. enabled относится ко всем четырём провайдерам. Внутренние cachePath/configPath/pricePath не передаются. rootRow добавляет выбираемый провайдер, каталог журналов, необязательный профиль и удаление; defaultProfile выводит общий профиль из типовых sessions/archived_sessions/projects/session-state путей и OpenCode DB. Отсутствующий каталог допускается, это объяснено подписью.

load независимо получает config и summary.pricing; пока config не загружен, редактирование и сохранение недоступны. submit проверяет диапазон 1..3660, HTTPS URL и непустые каталоги, затем вызывает configure. Ошибка сохраняет черновик; новые изменения, внесённые во время запроса, не заменяются старым ответом. onSaved уведомляет host об изменении индекса. paintPricing показывает дату, источник и количество моделей последнего исправного каталога. refresh недоступен для несохранённого URL и не заменяет каталог после неудачного запроса. Пользовательские значения и ошибки отображаются через textContent.

Тест agent_stats_settings.test.mjs проверяет фактический renderer на DOM-адаптере: ленивую загрузку, payload без приватных путей, вывод профиля, ошибки сохранения/обновления, сохранение draft при hide/show и запрет отрисовки запоздавшего hidden ответа. CSS вынесен в agents-settings.css и наследует существующие токены FORGE.

Дополнительный root отображается через постоянные label wrappers «Агент», «Каталог журналов», «Папка профиля», поэтому заполненные пути остаются различимы без placeholder. Desktop grid выравнивает remove к inputs; mobile row переносит path/profile wrappers на полную ширину, provider/remove оставляет на первой строке. Форма не наследует flex-basis фильтров и не получает искусственную высоту на узком экране.

# tmux-web/static/js/agents/view.js

Контроллер нового режима «Агенты». createAgentView(host,{api,doc,timers,onBindingsChanged,liveFactory,historyFactory,settingsFactory}) создаёт независимые live/history/settings hosts и сохраняет фильтры в forge.agents.filters. show/hide/destroy управляют запросами, локальными часами и наблюдателями; document.visibilitychange останавливает скрытый экран. Каждые 2 с видимого режима читаются status/live/bindings. История, summary и projects обновляются при изменении query, дня, updatedAtMs или runtime signature задач (id/state/start/lastActivity во всех live/waiting/unknown); workingCount также исключает cache reuse. nowMs не входит в signature, поэтому неподвижная история кешируется. Guard между стадиями запроса не запускает summary/history после скрытия или смены фильтра, поколение poller игнорирует уже летящие ответы. Профили берутся из status.profiles всего индекса, включая исторические источники; отсутствующее поле старого remote безопасно трактуется как []. Select/form состояния и focus не пересоздаются при обычном poll. История перерисовывает SVG на theme/resize/show. API и рендереры внедряются для реальных behavior tests без production mocks.

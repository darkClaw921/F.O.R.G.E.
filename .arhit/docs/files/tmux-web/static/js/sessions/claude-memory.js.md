# tmux-web/static/js/sessions/claude-memory.js

Общая модалка кнопки 🧠 для просмотра и редактирования памяти Claude и Codex. Экспорт openClaudeMemoryModal сохранён для существующего bootstrap listener, но заголовок теперь «Память агентов» и источник выбирается кнопками Claude/Codex с aria-pressed. Claude читает GET /api/claude-memory?path=<cwd активной tmux-сессии>; Codex читает GET /api/codex-memory без project query, так как показывает общую память CODEX_HOME. DTO Codex: dir, exists, index_name nullable, index, files{name,content}, truncated. Имена Codex относительно CODEX_HOME, например memories/MEMORY.md, memories/rollout_summaries/x.md и agent-memory/run-phase/MEMORY.md. Native и subagent источники выделены отдельными заголовками, отсутствующий native индекс не создаётся искусственно. Каждый файл имеет прежние кнопки правки/сохранения/отмены. PUT отправляется в endpoint, закреплённый за исходным рендером, вместе с file/content и Claude path. Переход между источниками или закрытие отменяет pending GET AbortController; номер ревизии дополнительно блокирует устаревший результат даже при транспорте, проигнорировавшем отмену. Уже отправленный PUT может завершиться, но не перерисует другой источник и не покажет alert в закрытом окне. Markdown рендерится DOM renderer core/markdown.js. Внутренние относительные ссылки разрешаются относительно файла-источника, включая ../ и nested rollout paths; неизвестные .md ссылки блокируются. Ограничение списка сервером заметно через truncated notice. Память читается по запросу открытия/переключения/сохранения, без фонового polling и вызовов моделей.

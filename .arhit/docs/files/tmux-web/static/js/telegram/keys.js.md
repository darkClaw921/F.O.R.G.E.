# tmux-web/static/js/telegram/keys.js

Реестр действий клавиатуры вкладки Telegram и разбор комбинаций. НАМЕРЕННО чистый модуль: ни DOM, ни сети, ни импортов соседних модулей панели (тот же принцип, что у format.js и reply.js), поэтому целиком покрывается node-тестом без фейкового документа. DOM-половина фичи живёт в keynav.js.

СОПОСТАВЛЕНИЕ ПО event.code, А НЕ event.key. Вкладка Telegram — место, где по-русски печатают чаще, чем по-английски. При русской раскладке event.key для физической клавиши J вернёт 'о', и хоткей 'j' перестал бы работать ровно у тех, ради кого фича делается. event.code описывает физическую клавишу и от раскладки не зависит; event.key остаётся фолбэком для клавиш без кода (экранные клавиатуры).

КАНОНИЧЕСКИЙ ВИД КОМБИНАЦИИ: [Ctrl+][Alt+][Shift+][Meta+]<клавиша>, буквы в нижнем регистре — 'j', 'Shift+g', 'Ctrl+Enter', 'Shift+/'. Порядок модификаторов фиксирован, потому что строка служит ключом Map: 'Shift+Ctrl+x' и 'Ctrl+Shift+x' обязаны быть одной записью, иначе конфликт двух действий остался бы незамеченным.

ЭКСПОРТЫ. TG_ACTIONS — реестр из 19 действий {id, title, group, combo, hint, fixed}; TG_ACTION_GROUPS — порядок групп ('Навигация', 'Сообщение', 'Лента', 'Панель'); keyFromEvent(e); comboFromEvent(e); normalizeCombo(raw); formatCombo(combo); findAction(id); defaultBindings(); sanitizeOverrides(raw); resolveBindings(overrides); bindingRows(overrides); overridesFromBindings(bindings); isEditableTarget(el); comboAllowedIn(combo, ctx); actionForEvent(e, resolved, ctx); groupedRows(overrides).

РАЗРЕШЕНИЕ КОНФЛИКТОВ (resolveBindings). Два прохода по реестру: сначала ВСЕ переопределения, затем дефолты нетронутых действий. Один проход дал бы дефолту раннего действия победу над переопределением позднего. Правило: переопределение сильнее дефолта, среди переопределений — то, что раньше в реестре (результат не зависит от порядка ключей в JSON). Проигравшее действие остаётся БЕЗ клавиши (в bindings его нет, id попадает в unbound) и честно показывается таким в настройках: молча вернуть ему дефолт значило бы соврать пользователю, который этот дефолт только что занял.

ЧТО ХРАНИТСЯ НА BACKEND. overridesFromBindings отдаёт ТОЛЬКО отличия от дефолта: полная карта помешала бы смене дефолта в новой версии доехать до пользователей, у которых 'всё как из коробки'. fixed-действия (Escape) не сериализуются никогда.

ПОЛЕ ВВОДА. comboAllowedIn возвращает false для одиночных клавиш и для Shift+буква при editing=true — иначе букву 'j' было бы не набрать в сообщении, а Shift+g это просто заглавная G. Проходят только Ctrl/Alt/Meta-комбинации и Escape.

Потребители: keynav.js (диспетчер нажатий, шпаргалка) и settings/hotkeys-tab.js (таблица переназначений). Тесты: tmux-web/tests/frontend/telegram_keys.test.mjs (139 ассертов).

# tmux-web/static/js/settings/bitrix-visibility-tab.js

Раздел «Видимость диалогов» вкладки «Битрикс24» в модалке настроек (Ф11).

buildBitrixVisibilityForm(settings, onSaved) — фабрика DOM-узла с тумблером режима «показывать только выбранное», списком ВИДОВ диалогов (три чекбокса из VISIBLE_KINDS) и списком отдельных диалогов с поиском. Данные второго списка тянутся ОДИН РАЗ при первом показе: GET /api/bitrix/dialogs?limit=200. Поллинга нет: бюджет портала — 2 запроса в секунду на весь devforge (Р16), и открытая модалка не имеет права его съедать. Своего клиентского планировщика у панели нет (в отличие от VK): троттлинг живёт на сервере.

Поля настроек 1:1 на tmux-web/src/user_settings.rs: bitrix_filter_enabled (bool, дефолт false, читается === true), bitrix_visible_kinds ('user'|'chat'|'task'), bitrix_visible_peers (DIALOG_ID строками). Save шлёт ТОЛЬКО эти три поля — PATCH применяет Some(..)-варианты, поэтому соседние настройки не задеты; списки уходят ЦЕЛИКОМ, иначе снять галочку нечем.

ОТДЕЛЬНЫЙ ФАЙЛ, А НЕ ПАРАМЕТРИЗАЦИЯ СОСЕДНЕЙ ФОРМЫ: у Telegram белый список строится из ПАПОК аккаунта, у VK — из трёх типов peer'а, здесь — из трёх видов диалога портала, и у чатов задач свои пометки (номер задачи). Общего остаётся один тумблер. (У формы ХОТКЕЕВ ситуация обратная — там различий три, и она параметризована.)

ВЫБРАННЫЕ, НО НЕ ЗАГРУЖЕННЫЕ ДИАЛОГИ показываются отдельным блоком «Выбрано вне загруженного списка: N»: /dialogs отдаёт верхушку im.recent.get, и выбор может содержать чат, до которого руки не доходили полгода. Черновик хранит ВСЕ выбранные id — иначе первое же открытие настроек молча вычёркивало бы их. Чистка только по явной кнопке «Убрать несуществующие» (pruneMissingPeers).

После сохранения зовётся window.ForgeApp.b24Filter.refresh() (Р1): сброс кэша разбора + перерисовка колонки + счётчики + бейдж. Через контракт, а не прямым импортом: настройки открываются и без включённого плагина.

CSS — парные селекторы .tg-visibility-*, .vk-visibility-*, .b24-visibility-* в css/settings-modal.css (третья панель ДОПИСАНА в существующие правила, а не скопировала блок).

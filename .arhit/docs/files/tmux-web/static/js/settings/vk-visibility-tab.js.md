# tmux-web/static/js/settings/vk-visibility-tab.js

Форма «Видимость бесед» вкладки VK в модалке настроек. Экспорт: buildVkVisibilityForm(settings, onSaved) → DOM-узел fieldset, константа PEER_LIST_LIMIT = 200.

## Состав формы
Тумблер vk_filter_enabled (инициализация строго === true — дефолт настройки ВЫКЛ), сводка filterSummary с классом-предупреждением vk-visibility-warn при включённом тумблере и пустом выборе, список ТИПОВ из visibility.js::VISIBLE_KINDS (три чекбокса, сети не требуют — рисуются сразу), поиск + список отдельных бесед, кнопки «Снять всё» / «Убрать несуществующие» / «Save».

## Почему отдельный файл, а не параметризация телеграмной формы
У Telegram белый список строится из ПАПОК аккаунта с их правилами, у VK — из трёх типов peer'а. Общего между формами остаётся один тумблер, и параметризация ради него потребовала бы переписать работающую форму Telegram. У формы ХОТКЕЕВ ситуация обратная (различий три) — её параметризуют.

## Данные и лимит 3 rps
GET /api/vk/dialogs?limit=200&filter=all ОДИН раз при первом показе, через общий планировщик js/vk/ratelimit.js с ФОНОВЫМ приоритетом: открытая модалка не должна отодвигать запросы самой панели. Поллинга нет вовсе. Ошибка загрузки (плагин выключен, not_authorized, not_connected) не ломает форму: список заменяется объяснением, поиск отключается, уже сохранённый выбор лежит в черновике и уходит обратно тем же составом.

## Инвариант «выбранный, но не загруженный не вычёркивается молча»
Черновик хранит ВСЕ выбранные id, а не только нарисованные: /dialogs отдаёт верхушку списка, а выбор может содержать беседу, до которой полгода не доходили руки. Такие записи показываются отдельной группой «Выбрано вне загруженного списка: N» с пометкой «не в списке», и убрать их можно только кнопкой «Убрать несуществующие» (visibility.js::pruneMissingPeers) — по решению пользователя, а не автоматически.

## Тип беседы в подписи
Пометка типа берётся из format.js::peerKind(d.id), а не из поля DTO kind — показывается ровно тот тип, по которому будет судить фильтр, иначе подпись и поведение разошлись бы на первой же беседе с неожиданным kind.

## Save
Уходят ТОЛЬКО три своих поля (vk_filter_enabled, vk_visible_kinds, vk_visible_peers): PATCH применяет Some(..)-варианты, поэтому соседние настройки не затираются. Списки уходят ЦЕЛИКОМ — снять галочку иначе нечем. После успеха зовётся window.ForgeApp.vkFilter.refresh (сброс кэша + перерисовка колонки + пересчёт бейджа); отсутствие контракта — норма, когда плагин выключен.

## Интеграция
Импортируется в js/settings/modal.js (вкладка VK, шесть точек: кнопка таба, панель #ps-panel-vk, селектор $vkContent, объект vkTabState, ветка в showTab, whitelist initialTab). CSS-классы vk-visibility-* объявлены в css/settings-modal.css общим правилом с телеграмными. См. [[vk-visibility-model]].

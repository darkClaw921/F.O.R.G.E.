# polza_live.rs

Живые вызовы polza.ai (plugins/meet/tests/polza_live.rs). Включаются переменной FORGE_MEET_POLZA_KEY (ключ в репозиторий не попадает), помечены #[ignore]; без переменной пропускаются, поэтому cargo test в CI не ходит в сеть. Проверяют не наше поведение (его проверяет стенд), а то, что форма ответа сервиса всё ещё та, под которую стенд написан: лимиты ключа, баланс, наличие openai/whisper-1 и google/gemini-3.5-flash в каталоге вместе с ценой в top_provider.pricing, посегментные таймкоды у verbose_json и стрим SSE с несколькими кадрами. Файл окна берётся из FORGE_MEET_POLZA_MP3.
